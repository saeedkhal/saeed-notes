المذكرة دي <Hl c="y">٨ فصول + شيت</Hl>. الأول هنفهم Git بيفكر إزاي: الـ commit والـ branch والـ remote. بعدين أهم سؤال بيتسأل في أي فريق: merge ولا rebase؟ وبعدين إزاي تحل الـ conflicts وترجع في أي غلطة. وآخر حاجة الـ stash والـ cherry-pick والـ worktree.

<Box type="story" icon="📸" title="ألبوم الصور">

Git مش بيحفظ "التعديلات" وبس. كل commit زي صورة كاملة للمشروع في لحظة معينة، ومكتوب وراها مين صوّرها وإمتى، وإيه الصورة اللي قبلها. الـ branch مش نسخة من المشروع، هو ورقة صغيرة لازقها على آخر صورة في سلسلة.

</Box>

<Box type="idea" title="تبدأ منين؟">

لو بتستخدم Git بأوامر محفوظة ومش فاهم بتعمل إيه، ابدأ من الفصل الأول ومتسيبش فصل الـ branches. لو فريقك بيتخانق على merge و rebase، روح لفصل ٤ على طول. ولو عملت مصيبة ومحتاج ترجع، فصل ٦، وأهم أمر فيه `git reflog`.

</Box>
