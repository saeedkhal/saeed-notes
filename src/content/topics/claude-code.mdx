🎥 الكورس الأصلي على YouTube: [Claude Code Crash Course](https://youtu.be/u2QqWkMv3Lg)

المذكرة دي <Hl c="y">١٨ فصل + شيت</Hl>. أول ١٤ فصل ماشيين بنفس ترتيب الكورس، وآخر ٤ فصول (worktrees و MCP و hooks و multi-agent) أنا ضفتهم، لأن الكورس ذكرهم في الآخر من غير ما يشرحهم. الكورس بيبني متجر أونلاين لبراند فخم، وكل ميزة في Claude Code بتظهر في اللحظة اللي بنحتاجها فيها فعلًا. الـ permissions ظهرت لما Claude فضل يسأل على كل حاجة، و plan mode ظهر لما وصلنا للداتابيز، والـ skills ظهرت لما لقينا نفسنا بنكرر نفس الخطوات.

<Box type="story" icon="🔧" title="التليفون والصنايعي">

الشات العادي زي إنك تكلم سبّاك في التليفون: توصفله المشكلة، فيقولك "جرّب تعمل كده". Claude Code زي السبّاك اللي جه البيت بنفسه. بيفتح الدولاب ويبص على الماسورة، ويصلّح، وبعدين يفتح الحنفية يتأكد إن المية نزلت.

</Box>

<Box type="idea" title="تبدأ منين؟">

لو كل اللي بتعمله إنك تكتب "اعمل الـ feature دي" وتدوس Enter، ابدأ من الأول. لو Claude بيكرر نفس الغلطة كل جلسة، روح لفصول `CLAUDE.md`. لو هتعمل حاجة صعب ترجع فيها زي داتابيز أو auth، روح لفصل plan mode. ولو بتكتب نفس التعليمات في كل برومبت، روح للـ skills.

</Box>
