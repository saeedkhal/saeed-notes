المقال بيطبق دايرة Clean Architecture على الواجهة: الـ Entities في القلب، وحواليها الـ Use Cases، وبعدين الـ Adapters، وبره الـ Frameworks والـ Drivers.

الاعتماد يمشي لجوه بس، فمنطق البيزنس ميفضلش متعلق بالـ UI أو الـ framework.
