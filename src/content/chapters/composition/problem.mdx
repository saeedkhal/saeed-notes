تخيل إنك بتعمل متجر وعندك Product Card.

<File name="ProductCard.tsx">

```tsx
function ProductCard({ product }) {
  return (
    <div className="card">
      <img src={product.image} />
      <h3>{product.name}</h3>
      <p>{product.price}</p>
      <button>Add to Cart</button>
    </div>
  );
}
```

</File>

في البداية ده تمام. بعد شوية احتجت:

- Product Card عادية.
- Product Card فيها زرار Favorite.
- Product Card للـ Admin فيها Edit و Delete.
- Product Card للموبايل بتصميم مختلف.

ممكن تبدأ تزود props كتير.

<File name="الاستدعاء">

```tsx
<ProductCard
  product={product}
  showFavorite
  showEdit={isAdmin}
  showDelete={isAdmin}
  showAddToCart
  compact
/>
```

</File>

ومع الوقت المكون يبقى مليان شروط `if`، وصعب تعدّله أو تعيد استخدامه.
