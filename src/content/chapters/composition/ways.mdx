في React فيه أكتر من طريقة لتحقيق الـ Composition. أشهرها تلاتة.

## Children

بتبعت مكونات جوه مكون باستخدام `children`.

<File name="Card.tsx">

```tsx
<Card>
  <h2>Product</h2>
  <button>Buy</button>
</Card>
```

</File>

## Compound Components

مجموعة مكونات بتشتغل مع بعض كأنها واجهة واحدة.

<File name="Tabs.tsx">

```tsx
<Tabs>
  <Tabs.List>
    <Tabs.Trigger value="profile">
      Profile
    </Tabs.Trigger>
  </Tabs.List>

  <Tabs.Content value="profile">
    Profile Content
  </Tabs.Content>
</Tabs>
```

</File>

كل جزء له مسؤولية، وممكن يشتركوا في state واحدة عن طريق Context.

## فتحات بأسماء

بتحدد أماكن للمكونات اللي هتدخلها.

<File name="PageLayout.tsx">

```tsx
<PageLayout
  header={<Header />}
  sidebar={<Sidebar />}
  content={<Dashboard />}
/>
```

</File>

هنا الـ Layout بيتحكم في أماكن الأجزاء، لكن مش لازم يعرف تفاصيل تنفيذها.
