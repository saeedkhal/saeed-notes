## Validation من غير request

الـ component عندها validation في `handleSubmit`. المطلوب نثبت حاجتين: الرسالة ظهرت، والـ backend متضربتش.

```tsx
import { http, HttpResponse } from "msw";
import { server } from "../test/server";
import { API_URL } from "../test/academicYearsMocks";

it("متبعتش لو الاسم فاضي", async () => {
  const received = vi.fn();
  server.use(
    http.post(API_URL, () => {
      received();
      return HttpResponse.json({}, { status: 201 });
    }),
  );

  const user = userEvent.setup();
  render(<AcademicYearForm onCreated={vi.fn()} />);

  await user.click(screen.getByRole("button", { name: "حفظ" }));

  expect(screen.getByRole("status")).toHaveTextContent("اسم السنة مطلوب");
  expect(received).not.toHaveBeenCalled();
});
```

الرسالة synchronous، فـ `getByRole` كفاية. مفيش داعي لـ `waitFor` لمجرد إن test مكتوبة `async`.

## Server error

كل test تقدر تغيّر رد MSW مؤقتًا:

```tsx
it("تعرض خطأ لو السيرفر وقع", async () => {
  server.use(
    http.post(API_URL, () => {
      return HttpResponse.json(
        { message: "database unavailable" },
        { status: 500 },
      );
    }),
  );

  const user = userEvent.setup();
  const onCreated = vi.fn();
  render(<AcademicYearForm onCreated={onCreated} />);

  await user.type(screen.getByLabelText("اسم السنة"), "2027 / 2028");
  await user.click(screen.getByRole("button", { name: "حفظ" }));

  expect(
    await screen.findByRole("status"),
  ).toHaveTextContent("مقدرناش نحفظ السنة");
  expect(onCreated).not.toHaveBeenCalled();
  expect(screen.getByLabelText("اسم السنة")).toHaveValue("2027 / 2028");
});
```

احتفاظ الفورم بالقيمة مهم: لو الحفظ فشل، متجبرش اليوزر يكتب من الأول.

## Loading state

لو عايز تثبت إن الزر بيتقفل أثناء الطلب، خلّي response تستنى Promise أنت متحكم فيها:

```tsx
it("تقفل زر الحفظ أثناء الطلب", async () => {
  let finish!: () => void;
  const gate = new Promise<void>((resolve) => {
    finish = resolve;
  });

  server.use(
    http.post(API_URL, async () => {
      await gate;
      return HttpResponse.json(
        { id: "y3", name: "2027 / 2028" },
        { status: 201 },
      );
    }),
  );

  const user = userEvent.setup();
  render(<AcademicYearForm onCreated={vi.fn()} />);

  await user.type(screen.getByLabelText("اسم السنة"), "2027 / 2028");
  await user.click(screen.getByRole("button", { name: "حفظ" }));

  expect(screen.getByRole("button", { name: "جاري الحفظ…" }))
    .toBeDisabled();

  finish();
  expect(await screen.findByText("اتحفظت السنة")).toBeInTheDocument();
});
```

<Box type="warn" title="متستخدمش sleep">

`setTimeout(500)` يخلي test بطيئة ومتذبذبة. Promise gate تديك تحكم دقيق: افحص loading، وبعدها افتح البوابة.

</Box>
