## اختار الـ query

<Cheat items={[
  ["موجود دلوقتي", "`getByRole` أو `getByLabelText`"],
  ["هيظهر بعد async", "`findByRole` أو `findByText`"],
  ["لازم مش يكون موجود", "`queryByRole` ثم `not.toBeInTheDocument()`"],
  ["عناصر كتير", "`getAllBy` أو `findAllBy`"],
  ["جوه container أو row", "`within(container)`"],
  ["شرط async مركب", "`waitFor(() => expect(...))`"],
]} />
