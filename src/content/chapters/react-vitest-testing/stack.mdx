## مش سبع بدائل

المكتبات دي طبقات فوق بعض. كل واحدة ماسكة جزء مختلف:

| المكتبة | دورها | بنستخدم منها إيه | فين |
| --- | --- | --- | --- |
| `vitest` | يشغّل tests ويقارن ويعمل mocks | `describe`، `it`، `expect`، hooks، `vi.fn`، `vi.mock`، `vi.spyOn` | ملفات الـ test و`setup.ts` و`vitest.config.ts` |
| `jsdom` | متصفح وهمي جوه Node | `document` و`window` من غير import | `environment: "jsdom"` في config |
| `@testing-library/react` | يرسم React والـ hooks | `render`، `renderHook`، `act`، `cleanup`، `screen`، `within`، `waitFor` | helpers والـ setup وكل UI tests |
| `@testing-library/dom` | محرك البحث في الصفحة | مش بنستورده غالبًا | peer dependency لـ React Testing Library وuser-event |
| `@testing-library/user-event` | يقلّد كتابة وضغط اليوزر | `setup`، `click`، `type`، `clear` | تست الفورم والصفحات |
| `@testing-library/jest-dom` | يزوّد `expect` بفحص HTML | `toBeInTheDocument`، `toHaveValue`، `toHaveAttribute` | بيتفعّل مرة في `setup.ts` |
| `msw` | backend وهمية تمسك requests | `setupServer`، `http.get/post/patch/delete`، `HttpResponse` | `server.ts` وملفات handlers والـ overrides |

<Box type="warn" title="الاسم jest-dom مش معناه Jest بس">

مع Vitest استورده مرة في setup من `@testing-library/jest-dom/vitest`. هو بيزوّد `expect` بتاعة Vitest بالـ DOM matchers.

</Box>

## Queries تختارها إزاي؟

الأولوية للحاجة اللي اليوزر أو قارئ الشاشة يعرفها:

```ts
screen.getByRole("button", { name: "حفظ" });
screen.getByLabelText("اسم السنة");
screen.findByRole("status");
```

- `getBy...`: العنصر موجود **دلوقتي**؛ يرمي error لو مش موجود.
- `queryBy...`: بنثبت إن العنصر **مش موجود**؛ يرجع `null`.
- `findBy...`: العنصر هيظهر **بعد async work**؛ بيرجع Promise.

<Hl c="b">لو مش عارف تلاقي الزر بـ role وname، ممكن تكون المشكلة accessibility في الـ UI مش في test.</Hl>

## `user-event` مش `fireEvent`

`user-event` يعمل سلسلة أقرب للمتصفح: focus وkeyboard/input/change، ومعظم أوامره async:

```ts
const user = userEvent.setup();
await user.type(nameInput, "2026 / 2027");
await user.click(saveButton);
```

استخدم `fireEvent` للحالات المنخفضة المستوى اللي فعلًا محتاج تبعت event واحدة بعينها، مش كاختيار أول.
