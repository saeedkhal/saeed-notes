## زوّد الحذف للـ component

جوه `AcademicYearsList`، ضيف function تبعت DELETE وتحدّث القائمة بعد النجاح:

```tsx
async function removeYear(id: string) {
  const response = await fetch(`${API_URL}/${id}`, {
    method: "DELETE",
  });

  if (!response.ok) throw new Error("delete failed");
  setYears((current) => current.filter((year) => year.id !== id));
}
```

وزر كل row يبقى:

```tsx
<button onClick={() => removeYear(year.id)}>
  حذف {year.name}
</button>
```

اسم الزر فيه اسم السنة، فمستخدم قارئ الشاشة والـ test يقدروا يفرقوا الأزرار عن بعض.

## Test كاملة

```tsx
import {
  render,
  screen,
  waitForElementToBeRemoved,
  within,
} from "@testing-library/react";
import userEvent from "@testing-library/user-event";
import { http, HttpResponse } from "msw";
import { expect, it, vi } from "vitest";
import { API_URL } from "../test/academicYearsMocks";
import { server } from "../test/server";
import { AcademicYearsList } from "./AcademicYearsList";

it("تحذف السنة المختارة", async () => {
  const removed = vi.fn();
  server.use(
    http.delete(`${API_URL}/:id`, ({ params }) => {
      removed(params.id);
      return new HttpResponse(null, { status: 204 });
    }),
  );

  const user = userEvent.setup();
  render(<AcademicYearsList />);

  const yearName = await screen.findByText("2025 / 2026");
  const row = yearName.closest("li");
  expect(row).not.toBeNull();

  await user.click(
    within(row!).getByRole("button", {
      name: "حذف 2025 / 2026",
    }),
  );

  await waitForElementToBeRemoved(row);
  expect(removed).toHaveBeenCalledWith("y1");
  expect(screen.getByText("2026 / 2027")).toBeInTheDocument();
});
```

## بنثبت إيه؟

1. البيانات اتحملت فعلًا.
2. اخترنا زر row المطلوبة، مش أول زر وخلاص.
3. URL حملت `id` الصح.
4. الـ row اختفت بعد نجاح الرد.
5. باقي القائمة لسه موجود.

<Box type="warn" title="اختفاء متفائل ولا بعد النجاح؟">

المثال بيحذف من الشاشة بعد response ناجحة. لو UI بتعمل optimistic delete قبل الرد، اختبر كمان rollback لما DELETE ترجع 500. متكتبش test لسلوك مش موجود في المنتج.

</Box>

## PATCH نفس الفكرة

في تعديل السنة، غيّر handler لـ `http.patch`، افحص `params.id` و`request.json()`، وبعد success استنى الاسم الجديد يظهر. المبدأ واحد: تفاعل مستخدم، network contract، ثم نتيجة مرئية.
