## افصل الـ validation عن الـ UI وعن الـ hooks

في React، الأفضل تفصل الـ API validation عن الـ UI وعن الـ Query hooks.

مثال على feature اسمها `users`:

<Tree>

```text
src/
└── features/
    └── users/
        ├── api/
        │   ├── users.api.ts
        │   └── users.schema.ts
        ├── model/
        │   └── users.queries.ts
        └── ui/
            └── UsersList.tsx
```

</Tree>

## مسؤولية كل ملف

- **`users.schema.ts`:** تعريف الـ schemas والـ inferred types.
- **`users.api.ts`:** تنفيذ الـ HTTP request والتحقق من الـ response.
- **`users.queries.ts`:** تعريف `queryKey` و`useQuery` وإعدادات الـ caching.
- **`UsersList.tsx`:** عرض البيانات وحالات الـ loading والـ error.

<Hl c="g">الـ API layer هي المكان المناسب للتحقق من الـ response.</Hl> كده كل المستهلكين للدالة بياخدوا داتا تم التحقق منها، بدل ما كل Component يعمل validation بنفسه.
