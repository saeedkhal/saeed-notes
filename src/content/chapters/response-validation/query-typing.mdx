## النوع يتستنتج من الدالة

<File name="users.queries.ts">

```ts
export const useUserQuery = (id: number) =>
  useQuery({
    queryKey: ["users", id],
    queryFn: () => getUser(id),
  });
```

</File>

طالما `getUser()` بترجع `Promise<User>` بعد الـ validation، فإن TanStack Query هتستنتج إن `data` نوعها `User` تلقائيًا.

<Hl c="b">مش محتاج تكتب `useQuery&lt;User&gt;` إلا لو عندك سبب محدد.</Hl> الأفضل عادةً إن الـ TypeScript inference يشتغل لوحده، وإن الـ API function هي اللي تضمن نوع الداتا.

## الـ generic لوحده مش فحص

أما لو كتبت `useQuery<User>` مع API بترجع JSON غير متحقق منه، فأنت كده بتحدد النوع المتوقع للـ compiler، لكنك لسه ما ضمنتش صحة الـ response الفعلية.
