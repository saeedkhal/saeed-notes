## لأ، مش كل خطأ يظهر بنفس الشكل

دي نقطة مهمة. الـ validation مش معناه إننا لازم نوقف التطبيق كله. القرار بيعتمد على أهمية الداتا وإمكانية التعامل الآمن معاها.

تخيّل Dashboard فيها بيانات الموظفين.

## حالة ١ — فشل تحميل الشاشة بالكامل

اعرض Error State فيها رسالة واضحة، مع زر Retry لو مناسب.

## حالة ٢ — حقل اختياري غير موجود

- **لو الـ API contract بيسمح بغياب الحقل:** عرّفه `optional`.
- **لو غيابه غير متوقع لكن مش مؤثر:** تتعامل معاه حسب أهمية البيانات.

## حالة ٣ — داتا أساسية غير صالحة

<Hl c="o">ما تعرضش الداتا على إنها صحيحة.</Hl> سجّل الخطأ، واعرض رسالة مناسبة، أو امنع العملية لو سلامة الداتا ضرورية.
