بدل ما تقرأ الـ <En>query string</En> كنص، تعرّف شكلها. <En>Zod</En> شائع هنا. ثبّته وراجع أمر التثبيت في الدوكس.

<File name="src/routes/posts/index.tsx">

```tsx
import { createFileRoute } from "@tanstack/react-router";
import { z } from "zod";

const postsSearchSchema = z.object({
  page: z.number().catch(1),
  filter: z.string().catch(""),
});

export const Route = createFileRoute("/posts/")({
  validateSearch: postsSearchSchema,
  component: PostsIndex,
});

function PostsIndex() {
  const { page, filter } = Route.useSearch();

  return (
    <div>
      <p>الصفحة: {page}</p>
      <p>الفلتر: {filter || "مفيش"}</p>
    </div>
  );
}
```

</File>

<En>catch</En> لو القيمة ناقصة أو نوعها غلط: الصفحة تبقى ١، والفلتر نص فاضي. <En>Route.useSearch</En> يرجّع رقم ونص، مش حاجة مجهولة.

اللينك كمان متراجع:

<File name="link.tsx">

```tsx
<Link to="/posts" search={{ page: 2, filter: "react" }}>
  الصفحة 2
</Link>
```

</File>

لو حطيت نص في <En>page</En>، TypeScript يرفض قبل التشغيل. ده الفرق العملي عن راوتر بيسيب الـ <En>search</En> نص حر.
