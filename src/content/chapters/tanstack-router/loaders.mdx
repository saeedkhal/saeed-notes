الـ <En>loader</En> بيشتغل قبل ما الكومبوننت يترسم. الداتا تبقى جاهزة، من غير حالة تحميل تكتبها بإيدك جوه <En>useEffect</En>.

<File name="src/routes/posts/$postId.tsx">

```tsx
import { createFileRoute } from "@tanstack/react-router";

export const Route = createFileRoute("/posts/$postId")({
  loader: async ({ params }) => {
    const res = await fetch(
      `https://jsonplaceholder.typicode.com/posts/${params.postId}`,
    );
    if (!res.ok) throw new Error("Post not found");
    return res.json();
  },
  pendingComponent: () => <p>جاري التحميل...</p>,
  errorComponent: ({ error }) => <p>حصل خطأ: {error.message}</p>,
  component: PostPage,
});

function PostPage() {
  const post = Route.useLoaderData();
  return (
    <div>
      <h1>{post.title}</h1>
      <p>{post.body}</p>
    </div>
  );
}
```

</File>

<En>useEffect</En> بيحصل بعد الرسم، فتشوف «جاري التحميل» كوميض، وبتكتب حالة الخطأ بإيدك، ومفيش كاش جاهز. الـ <En>loader</En> بيحصل قبل الظهور، وفيه كومبوننت انتظار وكومبوننت خطأ، وكاش قريب من فكرة <En>React Query</En>.
