عنوان زي <En>/posts/1</En> و <En>/posts/2</En> ملف واحد. علامة الدولار قبل اسم المعامل في اسم الملف.

<Tree>

```text
src/routes/
  posts.tsx

    index.tsx

```

<File name="src/routes/posts/$postId.tsx">

```tsx
import { createFileRoute } from "@tanstack/react-router";

export const Route = createFileRoute("/posts/$postId")({
  component: PostPage,
});

function PostPage() {
  const { postId } = Route.useParams();
  return <h1>عرض البوست رقم: {postId}</h1>;
}
```

</File>

افتح <En>/posts/5</En>. الرقم يطلع في الصفحة، ونوعه معروف من غير ما تكتب نوع بإيدك.

## الـ layout

ملف <En>posts.tsx</En> جنب المجلد، مش جواه، هو الغلاف لكل حاجة تحت <En>/posts</En>. <En>posts/index.tsx</En> هو <En>/posts</En> نفسه لما مفيش رقم.

<File name="src/routes/posts.tsx">

```tsx
import { createFileRoute, Outlet, Link } from "@tanstack/react-router";

export const Route = createFileRoute("/posts")({
  component: PostsLayout,
});

function PostsLayout() {
  return (
    <div style={{ display: "flex", gap: "2rem" }}>
      <aside>
        <Link to="/posts/1">Post 1</Link>
        <br />
        <Link to="/posts/2">Post 2</Link>
      </aside>
      <main>
        <Outlet />
      </main>
    </div>
  );
}
```

</File>

<File name="src/routes/posts/index.tsx">

```tsx
import { createFileRoute } from "@tanstack/react-router";

export const Route = createFileRoute("/posts/")({
  component: () => <p>اختار بوست من القايمة</p>,
});
```

</File>

<Box type="warn" title="الشرطة في الآخر مهمة">

مسار الغلاف من غير شرطة أخيرة. مسار الـ <En>index</En> بشرطة في الآخر. كده المكتبة تفرّق الغلاف عن صفحة المجلد وهو فاضي.

</Box>

<En>Outlet</En> هنا يرسم يا صفحة الاختيار يا صفحة الرقم، والعمود الجانبي ثابت.
