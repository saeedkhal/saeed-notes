## الـ API اللي Motion اختاره

من الـ docs العامة، الـ Ticker بياخد حاجات قليلة جدًا:

```tsx
<Ticker items={[<Logo1 />, <Logo2 />, "أي نص", 42]} />   // items: أي React nodes
<Ticker items={logos} axis="y" />                          // رأسي
<Ticker items={logos} velocity={-80} />                    // px في الثانية، السالب يعكس، 0 يقف
```

<Hl c="y">prop واحد إجباري بس</Hl>، والباقي defaults معقولة. وفوق كده، بيقبل **motion value** تحرّكه بيه، فتربطه بالـ scroll أو بالسحب. ده درس API مهم: خلّي الحالة البسيطة سطر واحد، والحالات المتقدمة "باب مفتوح" مش props كتير.

## المشكلة: إزاي اللفة متبانش؟

الطريقة الساذجة إنك تكرر الـ items مرتين وتحرّك الشريط لحد النص وترجع. بتشتغل، بس:

- لو الشاشة عريضة والـ items قليلة، نسختين مش كفاية وهتشوف فراغ.
- لو الـ items كتير، نسختين كتير على الفاضي، والـ DOM يتقل.

الـ docs بتقول إن Ticker بيعمل **أقل عدد نسخ يملا الشاشة**. الحسبة بسيطة:

```ts
const copies = Math.ceil(viewportWidth / setWidth) + 1; // + مجموعة كاملة للفّة
```

## اللفة نفسها: wrap

بدل ما نرجّع الشريط بقفزة، بنخلي الـ `x` دايمًا بين `-setWidth` و `0` بـ `wrap`. لما يعدّي الحد، بيرجع للناحية التانية في نفس الفريم، ولأن النسخة اللي بعده شبهه بالظبط، العين مش بتلاحظ.

<File name="Ticker.tsx (تنفيذي، على motion المجانية)">

```tsx
import { motion, useAnimationFrame, useMotionValue, useReducedMotion, wrap } from "motion/react";
import { useLayoutEffect, useRef, useState, type ReactNode } from "react";

export function Ticker({ items, velocity = 60 }: { items: ReactNode[]; velocity?: number }) {
  const box = useRef<HTMLDivElement>(null);
  const set = useRef<HTMLDivElement>(null);
  const [copies, setCopies] = useState(1);
  const [width, setWidth] = useState(0);
  const x = useMotionValue(0);
  const hover = useRef(1);
  const reduced = useReducedMotion();

  useLayoutEffect(() => {
    const measure = () => {
      const w = set.current!.offsetWidth;
      setWidth(w);
      setCopies(Math.ceil(box.current!.offsetWidth / w) + 1);
    };
    measure();
    const ro = new ResizeObserver(measure);
    ro.observe(box.current!);
    return () => ro.disconnect();
  }, [items]);

  useAnimationFrame((_, delta) => {
    if (reduced || !width) return;
    x.set(wrap(-width, 0, x.get() - velocity * hover.current * (delta / 1000)));
  });

  return (
    <div
      ref={box}
      style={{ overflow: "hidden" }}
      onPointerEnter={() => (hover.current = 0.2)}
      onPointerLeave={() => (hover.current = 1)}
    >
      <motion.div style={{ x, display: "flex", width: "max-content" }}>
        <div ref={set} style={{ display: "flex" }}>{items}</div>
        {Array.from({ length: copies - 1 }, (_, i) => (
          // النسخ للعين بس: قارئ الشاشة والكيبورد ميشوفوهاش
          <div key={i} aria-hidden inert style={{ display: "flex" }}>{items}</div>
        ))}
      </motion.div>
    </div>
  );
}
```

</File>

<Box type="warn" title="تلات حاجات بتتنسي">

- **`aria-hidden` و `inert` على النسخ.** من غيرهم قارئ الشاشة بيقرا اللوجوهات ٣ مرات، والـ Tab بيدخل على لينكات مكررة.
- **reduced motion.** Motion بيقول إن Ticker بيدعمه أوتوماتيك. في نسختك: اقف، وخلّي الشريط `overflow-x: auto` يتعمله scroll بالإيد.
- **الـ focus.** لو جوه الـ items لينكات، اقف لما واحد ياخد focus (في الديمو السرعة بتبقى 0 مع `focusin`)، وإلا اللينك يهرب من تحت عين المستخدم.

</Box>

## الهدوء في الـ hover: spring على السرعة

في الديمو، لما تعدّي بالماوس الشريط مش بيقف مرة واحدة. فيه **spring صغيرة على معامل السرعة** (من 1 لـ 0.2). نفس فكرة Filee: <Hl c="b">أي حاجة بتتغير بسبب الماوس، حرّكها بـ spring مش بقفزة</Hl>. في React تقدر تعملها بـ `useSpring(1)` وتقرا قيمتها جوه `useAnimationFrame`.

## RTL

الـ docs بتقول إن Ticker بيشتغل مع RTL. في نسختك، أسهل حاجة: في RTL اعكس إشارة السرعة واعكس `wrap` لـ `0..width`، أو حط `dir="ltr"` على الشريط لو المحتوى لوجوهات مش نص. الديمو هنا عامل التانية.

## الـ Carousel: Ticker + تحكم

الـ Carousel مبني على نفس طريقة Ticker (لفة لا نهائية بأقل نسخ)، بس بيضيف:

| الحاجة | ليه مهمة | إزاي تعملها في نسختك |
| --- | --- | --- |
| سحب بالماوس واللمس | الموبايل | `drag="x"` من motion، وفي الآخر `animate(x, nearestSnap, { type: "spring", velocity })` |
| عجلة الماوس | التاتش باد | `wheel` event، `deltaX` يحرّك الـ x |
| كيبورد | accessibility | الأسهم تروح للي بعده، و `Home`/`End` |
| ARIA أوتوماتيك | قارئ الشاشة | `role="region"` و `aria-roledescription="carousel"` و `aria-label` لكل slide "٣ من ٨" |
| state للأزرار والنقط | تصمم controls بتاعتك | hook يرجّع الصفحة الحالية وعددها و next/prev/goto |
| reduced motion و RTL | الكل | زي الـ Ticker |

<Box type="tip" title="ابدأ بـ CSS scroll-snap">

لو مش محتاج لفة لا نهائية، `scroll-snap-type: x mandatory` على div عادي بيديك سحب و momentum وكيبورد وعجلة **ببلاش** ومن غير JavaScript. استخدم transform والـ spring بس لما تحتاج اللفة أو حركة مش موجودة في الـ scroll العادي. فيه أمثلة snap في مذكرة [Scroll Patterns](../../scroll-patterns/).

</Box>
