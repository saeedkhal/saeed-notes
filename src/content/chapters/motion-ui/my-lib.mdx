## أربع طبقات، زي Motion UI بالظبط

Motion UI نفسه متقسم: Motion (المحرك) ← components (Ticker، Number…) ← sections (hero، pricing). الـ lib بتاعتك تقدر تمشي نفس التقسيمة وتزود عليها طبقة tokens تحت خالص:

<Flow items={[{t:"tokens",s:"منحنيات · مدد · springs",c:1},"→",{t:"primitives",s:"hooks + Ticker · Number · Split",c:2},"→",{t:"components",s:"Button · Tabs · Dialog",c:3},"→",{t:"sections",s:"Hero · Pricing · Logos",c:4}]} />

| الطبقة | فيها إيه | بتعتمد على |
| --- | --- | --- |
| **tokens** | `ease.back` و `dur.press` و `spring.snappy`… رقم واحد لكل حاجة | ولا حاجة |
| **primitives** | `useReducedMotion`، `useFinePointer`، `useInView`، و Ticker و AnimateNumber و splitText بتاعتك | tokens + motion |
| **components** | الحاجات العادية (Button، Tabs، Dialog…) بحركة من الـ tokens | primitives |
| **sections** | بلوكات صفحة جاهزة | components |

<Box type="tip" title="الـ tokens جاهزة">

الأرقام كلها موجودة في مذكرة [أنيميشن Filee](../../filee-motion/cheat-sheet/)، وفي الـ skill اللي عملناها `smoothy-animation-skill` (فيها نفس الـ tokens لـ React و CSS و Flutter و Compose…). ابدأ منها بدل ما تخترع أرقام.

</Box>

كل component في فولدر لوحده فيه الكود والـ CSS والاختبار والـ story. كده لو قررت تنشر بـ shadcn registry، كل فولدر يبقى `registry-item` جاهز.

## الـ hooks الصغيرة اللي كل حاجة محتاجاها

<File name="hooks/use-fine-pointer.ts">

```ts
import { useSyncExternalStore } from "react";

const query = "(pointer: fine)";
const subscribe = (cb: () => void) => {
  const mq = matchMedia(query);
  mq.addEventListener("change", cb);
  return () => mq.removeEventListener("change", cb);
};

/** true لو فيه ماوس. الـ Cursor والـ hover effects بيسألوه قبل ما يشتغلوا */
export function useFinePointer() {
  return useSyncExternalStore(subscribe, () => matchMedia(query).matches, () => false);
}
```

</File>

`useReducedMotion` موجود جاهز في `motion/react`، فاستخدمه بدل ما تكتبه. الـ `() => false` الأخيرة للـ SSR: على السيرفر مفيش ماوس، فالـ Cursor ميترسمش لحد ما الصفحة تشتغل في المتصفح.

## تنشرها إزاي؟

| الطريقة | المستخدم بياخدها إزاي | امتى تختارها |
| --- | --- | --- |
| **npm عام** | `pnpm add @nile/motion-kit` | lib مفتوحة ومستقرة، وعايز تحديثات سهلة |
| **npm خاص بـ token** | `.npmrc` + `${TOKEN}` زي Motion+ | lib لشركتك أو مدفوعة |
| **shadcn registry** | `npx shadcn add @nile/ticker` والكود يتنسخ عنده | عايز الناس تعدّل في الكود براحتها |

<Box type="idea" title="الاتنين مع بعض">

ممكن تعمل الاتنين: الـ **tokens والـ hooks** في npm package (لأنها لازم تبقى نسخة واحدة في المشروع)، والـ **components** في shadcn registry (لأن كل مشروع هيعدّل في شكلها). تفاصيل الـ registry في مذكرة [shadcn Registry](../../shadcn-registry/).

</Box>

## الاختبارات اللي تفرق

الحركة صعب تختبرها بـ unit tests. اللي يفرق فعلًا:

- **Storybook** فيه story لكل component بـ ٣ حالات: عادي، `dir="rtl"`، و reduced motion.
- **Playwright** بـ `page.emulateMedia({ reducedMotion: "reduce" })` يتأكد إن الـ Ticker وقف والرقم اتغير علطول.
- **قارئ الشاشة**: اختبار بسيط إن `aria-label` على الرقم هو القيمة كلها، والنسخ عليها `aria-hidden`.
- **حجم**: `size-limit` في الـ CI، لو component زاد عن حده الـ PR يقع.

```ts
test("Ticker يقف مع reduced motion", async ({ page }) => {
  await page.emulateMedia({ reducedMotion: "reduce" });
  await page.goto("/ticker");
  const t1 = await page.locator(".ticker-track").evaluate((e) => getComputedStyle(e).transform);
  await page.waitForTimeout(500);
  const t2 = await page.locator(".ticker-track").evaluate((e) => getComputedStyle(e).transform);
  expect(t2).toBe(t1);
});
```
