## تلات أسماء شبه بعض

الاسم بيلخبط، فخلّينا نفصلهم من الأول:

<Grid2>
<Card title="Motion (مجانية)" c={1}>

المكتبة اللي كان اسمها **Framer Motion** زمان. `npm i motion`، رخصة <En>MIT</En>، وفيها `motion.div` و `AnimatePresence` و `layout` و `useSpring` و `animate()`. دي اللي هنبني عليها.

</Card>
<Card title="Motion+ (مدفوعة)" c={2}>

عضوية بتدفعها مرة واحدة (Solo) أو اشتراك سنوي (Pro). فيها أمثلة كتير، و **Motion UI**، وأدوات تانية زي AI Kit و Studio. السعر بيتغير، فراجع `motion.dev/plus`.

</Card>
</Grid2>

**Motion UI** نفسه جزء من Motion+. هو حاجتين:

- **Components**: حتت "headless" بتعمل حركة صعبة، زي شريط بيلف (Ticker) أو رقم بيتقلّب (AnimateNumber).
- **Sections**: حوالي ٥٠ section جاهزة لصفحات الـ marketing (hero، pricing، testimonials، bento، footer…) مبنية من الـ components دي، وبتاخد الـ theme بتاعك.

## الـ components بالأسماء

| `Typewriter` | كتابة حرف حرف بسرعة متغيرة ووقفات | React، Vue، JS | — |
| `ScrambleText` | النص يتلخبط ويتفك على جملة جديدة | JS | — |

الأحجام من الـ docs العامة وقت كتابة المذكرة. الشَرطة معناها إن الرقم مش مكتوب في الجزء المفتوح.

<Box type="tip" title="لاحظ حاجة في الجدول">

مفيش Button ولا Dialog ولا Select. Motion UI **مش** component library عادية زي shadcn. هو الحاجات اللي **صعب** تعملها لوحدك: لفة لا نهائية من غير ما تبان، رقم بيتقلّب صح في كل اللغات، cursor بيتمغنط. ده درس أول: الـ lib بتاعتك ممكن يكون ليها طبقة "motion primitives" منفصلة عن الـ components العادية.

</Box>

## بيتنزل إزاي؟

مش copy-paste ومش npm عام. ده **npm registry خاص** بـ token:

<File name=".npmrc">

```ini
@motionplus:registry=https://api.motion.dev/npm/
//api.motion.dev/npm/:_authToken=${MOTION_TOKEN}
```

</File>

<File name="package.json">

```json
{
  "dependencies": {
    "motion-plus": "npm:@motionplus/core@^2.12.0"
  }
}
```

</File>

```bash
export MOTION_TOKEN=xxxx   # من حسابك في Motion+
pnpm install
```

```tsx
import { Ticker, AnimateNumber } from "motion-plus/react";
```

حاجتين حلوين هنا تتعلمهم:

1. الـ `.npmrc` فيه **اسم متغير** مش الـ token نفسه، فتعمله commit عادي. في الـ CI تحط `MOTION_TOKEN` كـ secret.
2. الـ package اسمها الحقيقي `@motionplus/core`، بس بيتنزل باسم `motion-plus` (npm alias). كده الـ imports في كودك مش متربطة باسم الـ scope.

<Box type="interview" title="لو سألوك: ليه private registry مش shadcn؟">

الـ registry الخاص بيخليك تعمل `update` بأمر واحد وتاخد إصلاحات الـ bugs، والكود محمي ورا الـ token. الـ shadcn registry بينسخ الكود جوه مشروعك، فتقدر تعدّل فيه براحتك بس التحديث بقى مسؤوليتك. الصفحة بتقول إن Motion+ بيدعم الطريقتين (فيه كلام عن shadcn)، فراجع docs التثبيت.

</Box>

## أهم سؤال: ينفع أحطه في الـ lib بتاعتي؟

صفحة Motion+ بتقول حاجتين:

- الـ APIs والأمثلة **MIT** "بعد ما تضيف الكود لموقعك، بقى بتاعك". يعني لو اشتريت واستخدمته في **مشروعك**، تمام.
- لو **منتجك بيعيد بيع إمكانيات Motion+ لمستخدمينه**، محتاج **Builder's Licence**.

<Box type="warn" title="الـ component library حالة رمادية">

لو هتعمل lib داخلية لشركتك ومشاريعها، فده استخدام عادي غالبًا. بس لو الـ lib هتبقى **open source** أو هتتباع، وهي جواها كود Motion+، فانت كده بتوزّع كود مدفوع لناس مدفعتش. الصفحة مش بتتكلم عن الحالة دي بالظبط، وبتقول ابعت لـ `support@motion.dev`. **اسألهم قبل ما تنشر.**

</Box>
