- **`add-to-cart`:** الـ Mutation وحالة الطلب ممكن يكونوا داخل الـ Feature. بيانات السلة المحفوظة على السيرفر تظل Server State.
- **`filter-products`:** الفلاتر القابلة للمشاركة تكون في URL.
- **`select-products`:** المنتجات المحددة ممكن تكون Local State أو Store حسب احتياج باقي المكونات.
- **`header`:** يقرأ Cart Query لعرض العدد. مش لازم يحتفظ بعدد منفصل في Zustand.

<Box type="idea" title="الستور مش لازم في shared">

مش معنى إنك استخدمت Zustand إن كل الـ Store لازم يكون في `shared`. لو الـ Store خاص بميزة محددة، خليه في الـ Slice المالكة له، وصدّر الواجهة المطلوبة من `index.ts`.

</Box>
