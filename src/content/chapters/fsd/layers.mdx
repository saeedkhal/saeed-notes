## الست طبقات

<Tree>

```text
src/
├── app/          Application setup — Router · Providers · Global styles · Query Client
├── pages/        Route pages — home · products · product-details · cart · checkout · orders
├── widgets/      Large UI blocks — header · product-grid · cart-summary · product-gallery
├── features/     User actions — add-to-cart · add-to-wishlist · login · apply-coupon · place-order
├── entities/     Business entities — product · cart · user · order · category
└── shared/       Reusable infrastructure — api · ui · lib · config · types
```

</Tree>

الطبقات دي مرتبة من الأعلى للأدنى. الطبقة الأعلى تقدر تعتمد على طبقة أدنى منها. العكس ممنوع.

يعني `features` تقدر تستخدم `entities` و`shared`. لكن `entities` مينفعش تستورد من `features`.
