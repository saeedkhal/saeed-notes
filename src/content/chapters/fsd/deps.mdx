## اتجاه الاعتماد

| الطبقة | دورها |
| --- | --- |
| `app` | Composition و setup |
| `pages` | تجميع أجزاء الصفحة |
| `widgets` | أجزاء UI كبيرة ومتكاملة |
| `features` | أفعال المستخدم والـ Use Cases |
| `entities` | Product و Cart و User و Order |
| `shared` | API client و UI primitives و Utilities |

الأسهم من الأعلى للأدنى بتوضح اتجاه الاعتماد، مش اتجاه انتقال الداتا. الداتا ممكن ترجع من الـ API وتطلع من `entities` للـ `features` والـ `widgets` والـ `pages`.

<Box type="warn" title="نفس الطبقة">

الـ Slices الموجودة في نفس الـ Layer لا تعتمد مباشرة على بعضها في التصميم التقليدي لـ FSD. `add-to-cart` مينفعش يستورد ملفات داخلية من `add-to-wishlist`، ولا العكس.

</Box>
