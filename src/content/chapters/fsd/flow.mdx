## السؤال

عندي Feature اسمها `add-to-cart` بتتعامل مع Product، وفي نفس الوقت محتاجة تضيفه للـ Cart. المسؤوليات تتوزع كده.

<Flow items={[{"t": "Product Card", "s": "ضغط Add to Cart", "c": 1}, "→", {"t": "add-to-cart", "s": "Mutation وحالات التحميل", "c": 2}, "→", {"t": "entities/cart", "s": "طلب الإضافة للـ API", "c": 3}, "→", {"t": "Backend", "s": "حفظ العنصر", "c": 4}, "→", {"t": "Query Cache", "s": "invalidate وإعادة الجلب", "c": 5}, "→", {"t": "Header والصفحة", "s": "العدد والإجمالي", "c": 1}]} />

1. **Product Card:** المستخدم يضغط Add to Cart.
2. **`features/add-to-cart`:** الـ Mutation وحالات التحميل والخطأ.
3. **`entities/cart`:** تنفيذ طلب إضافة المنتج للـ API.
4. **Backend API:** حفظ العنصر في السلة وإرجاع النتيجة.
5. **React Query Cache:** تعطيل استعلام السلة وإعادة جلب الداتا.
6. **Header وصفحة Cart:** عرض العدد والإجمالي والعناصر الجديدة.

<Hl c="g">`add-to-cart` لا تحتاج استيراد `cart-page` أو `header` أو حتى `product-details`.</Hl>

كل جزء مسؤول عن نفسه. التواصل من خلال الـ Entity والـ Query Cache.
