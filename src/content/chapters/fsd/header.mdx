الهيدر فيه Cart Badge، وصفحة Cart، و Cart Summary. كلهم محتاجين نفس بيانات السلة.

بدل ما `add-to-cart` تبعت Props للهيدر والصفحة، كل واحد يقرأ نفس الـ Query Key.

<File name="widgets/header/ui/cart-badge.tsx">

```tsx
import { useQuery } from '@tanstack/react-query';
import { cartQueries } from '@/entities/cart';

export function CartBadge() {
  const { data: cart } = useQuery(
    cartQueries.current()
  );

  const count =
    cart?.items.reduce(
      (total, item) => total + item.quantity,
      0
    ) ?? 0;

  return <span>{count}</span>;
}
```

</File>

لما عملية الإضافة تنجح، `invalidateQueries` بتعلّم بيانات السلة إنها محتاجة تحديث. React Query تعيد جلبها لو الـ Query نشطة، وتحدّث كل المكونات المشتركة في نفس الكاش.

- الهيدر يعرض العدد الجديد.
- صفحة Cart تعرض العناصر الجديدة.
- Cart Summary يعرض الإجمالي المحدّث.

مفيش اعتماد مباشر بين المكونات دي وبين Feature الإضافة.

<Box type="tip" title="مصدر الحقيقة">

المثال يفترض إن الـ Backend هو مصدر الحقيقة للسلة، وإن المكونات بتستخدم نفس Query Client ونفس Query Key. التحديث الفوري قبل رد السيرفر في الفصل الجاي، بـ `setQueryData`.

</Box>
