<Box type="tip" title="كلمة أخيرة">

Git مش محتاج تحفظ مية أمر. محتاج تفهم إن الـ commit صورة، والـ branch اسم عليها، وأي أمر بيعيد كتابة الـ commits (rebase و amend و reset) يتعمل قبل الـ push بس. ولو عملت commit، غالبًا مفيش حاجة هتضيع.

</Box>
