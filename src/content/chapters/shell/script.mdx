## ملف عادي، وأول سطر يقول مين يشغّله

السكربت ملف نص. أول سطر <En>shebang</En> يقول النظام يشغّله بأنهي برنامج:

<File name="count-dir.sh">

```bash
#!/usr/bin/env bash
echo "أنا سكربت"
```

</File>

`env` يلاقي `bash` من `PATH`، فمش مربوط بمسار جهاز واحد. بعدين:

<File name="terminal">

```bash
chmod +x count-dir.sh
./count-dir.sh
```

</File>

`./` مهمة. الفولدر الحالي مش في `PATH` عادة، فـ `count-dir.sh` لوحده مش هيتلاقى. `bash count-dir.sh` يشغّله حتى من غير `chmod`، وبيحترم إنك اخترت bash.

<Box type="warn" title="متشغّلوش بـ sh وأنت كاتبه bash">

`sh script.sh` يتجاهل الـ shebang ويشغّل شيل أضيق. `[[ ]]` و `source` وبعض التوسيع هتقع أو تتغير. شغّله بـ `./script.sh` أو `bash script.sh`.

</Box>

## الحجج مش بتتسأل، بتتبعت

`$1` أول حجة، `$2` التانية. `$#` العدد. `"$@"` كل الحجج، كل واحدة كلمة لوحدها. ده غير `$*` اللي بيلمّهم.

<File name="count-dir.sh">

```bash
#!/usr/bin/env bash
dir="${1:?اكتب مسار الفولدر}"

if [[ ! -d "$dir" ]]; then
  echo "مش لاقي الفولدر: $dir" >&2
  exit 1
fi

count=0
for f in "$dir"/*; do
  [[ -e "$f" ]] || continue
  count=$((count + 1))
done

echo "عدد الحاجات: $count"
```

</File>

`${1:?رسالة}` يوقف السكربت لو الحجة ناقصة، ويطبّع الرسالة على stderr. `[[ -d ]]` اختبار فولدر. `[[ -f ]]` ملف. `[[ -z "$var" ]]` نص فاضي. المسافات جوه `[[ ]]` مش زينة، الاختبار بيبوظ من غيرها.

`exit 1` يطلّع رقم فشل للي شغّلك، عشان `&&` برا السكربت يشتغل صح. رسالة الغلط على stderr (`>&2`) عشان اللي بيعمل pipe على الناتج ماياخدش التحذير كبيانات.

<Hl c="g">الحجة بين تنصيص، والغلط على الباب ٢، والخروج برقم مش بصفر.</Hl>

## القرار والتكرار

`if` / `elif` / `else` / `fi`. `for` على قائمة. `while` طول ما الشرط صح. `break` تخرج من اللوب، `continue` تكمل الدورة الجاية.

<File name="terminal">

```bash
for dish in كشري سلطة; do
  echo "طبق: $dish"
done
```

</File>

متلفّش على ناتج `ls`. لف على النمط `"$dir"/*` أو استخدم `find` لو الشجرة عميقة. الاسم اللي فيه مسافة بيضيع لما `ls` يطبّعه والسكربت يقطّعه تاني.

## دالة عشان متكررش

<File name="lib.sh">

```bash
die() {
  echo "$1" >&2
  exit 1
}

[[ -n "${1:-}" ]] || die "ناقص حجة"
```

</File>

الدالة بتتشاف في نفس الشيل. `$1` جواها حجة **الدالة**، مش حجة السكربت، إلا لو نديتها. `${1:-}` يخلّي الحجة الناقصة نص فاضي بدل ما `set -u` يوقع السكربت. هنفعّل `set -u` في الفصل الجاي.

`read -r line` يقرأ سطر من stdin. `-r` عشان الشيل مايفسّرش الشرطة المقلوبة. في سكربت، مدخل المستخدم مش دايمًا موجود، فالحجج أوضح من سؤال تفاعلي.

<Box type="story" icon="📋" title="ورقة الطلبات">

السكربت ورقة متكتوبة: أول سطر مين الجارسون (bash)، بعد كده الخطوات. الحجج اللي على الأمر زي الملاحظة على الورقة ("الفولدر ده"). `exit 1` الورقة ترجّع للمطبخ تقول الطلبية وقعت، مش تكمّل تقدم طبق فاضي.

</Box>
