## المسافة بتقطّع كلمات، مش أوامر

المسافة (أو التاب) بين الكلمات بتفصل **حجج نفس الأمر**. مش بتشغّل أمر تاني.

<File name="terminal">

```bash
echo hello world
# أمر واحد: echo
# حجتين: hello و world

ls -la /tmp
# أمر واحد، خيار، ومسار
```

</File>

`echo hello` و `echohello` مش نفس الحاجة. الأولى أمر `echo` وحجة. التانية برنامج اسمه `echohello`، وغالبا مش موجود.

المسافات الزيادة بين الكلمات بتتلم. المسافة في الأول والآخر بتتساب. اللي بيفرق هو إن فيه فاصل كلمات ولا لأ.

<Hl c="o">المسافة مش عامل بين أوامر. دي مسافة بين كلمات طلبية واحدة.</Hl>

لو الحجة نفسها فيها مسافة، حطها بين تنصيص. من غيرهم الشيل يفتكرها حجتين:

<File name="terminal">

```bash
mkdir "كشري ستيشن"
# فولدر واحد اسمه فيه مسافة

mkdir كشري ستيشن
# فولدرين: كشري  و  ستيشن
```

</File>

## `;` أمر بعد ما اللي قبله يخلّص

الفاصلة المنقوطة بتفصل **أمرين**. الشيل يشغّل الشمال، يستناه يخلّص، وبعدين يشغّل اليمين. **حتى لو الشمال فشل.**

<File name="terminal">

```bash
mkdir menu; cd menu; pwd
```

</File>

السطر الجديد بيعمل نفس وظيفة `;`. تلات سطور تحت بعض زي ما تحط `;` بينهم. في السكربت بنفضّل سطر لكل أمر عشان يتقرا.

`;` مش محتاج مسافة حواليه، بس المسافة بتخلّي السطر يتقرا: `pwd;ls` و `pwd ; ls` نفس الشغل.

## `&` متستناش. وده مش "و"

`&` كمان بتفصل أوامر، بس الشمال يشتغل **في الخلفية** والشيل يكمل فورًا من غير ما يستناه.

<File name="terminal">

```bash
sleep 30 &
pwd
```

</File>

`pwd` هيطبع دلوقتي، و `sleep` لسه شغال وراه. الشيل يطبّع رقم العملية. `jobs` يورّيك اللي في الخلفية. `fg` يرجّعه قدامك. `wait` في سكربت يستنى الخلفيات تخلّص.

<Box type="warn" title="& مش &&">

`&` وحدها = خلّيه في الخلفية. `&&` = شغّل التاني **بس لو الأول نجح**. الناس بتكتب `&` وهي عايزة "و". دي أشهر لخبطة في السطر.

</Box>

## `&&` و `||` بيعتمدوا على النجاح

صفر = نجح. غير كده = فشل.

<Grid2>
<Card title="&&" c={3}>

`cmd1 && cmd2` — التاني يشتغل لو الأول رجع صفر. زي "اعمل الفولدر وبعدين ادخله". لو `mkdir` فشل، `cd` ميحصلش.

</Card>
<Card title="||" c={5}>

`cmd1 || cmd2` — التاني يشتغل لو الأول **فشل**. بديل: `grep x f || echo مش لاقي`.

</Card>
</Grid2>

سلسلة مفيدة:

<File name="terminal">

```bash
mkdir -p dist && cd dist && pwd
```

</File>

لو حطيت `;` بدل `&&`، `cd` هيحصل حتى لو الفولدر ما تعملش، وهتلاقي نفسك في حتة تانية وانت فاكر إنك جوه `dist`.

## `|` مش فاصل أوامر عادي

الـ <En>pipe</En> ياخد مخرج الأمر الشمال ويدخّله مدخل للي يمينه. الاتنين بيشتغلوا مع بعض، مش واحد بعد ما التاني يخلّص ويكتب ملف.

<File name="terminal">

```bash
grep -R "TODO" src | wc -l
```

</File>

`grep` يطلّع السطور، و `wc` يعدّها. مفيش ملف في النص.

<Flow items={[{"t": "grep", "c": 1, "s": "يطلّع سطور"}, "→", {"t": "|", "c": 4, "s": "الماسورة"}, "→", {"t": "wc -l", "c": 3, "s": "يعد"}]} />

<Box type="story" icon="🍽️" title="الطلبية على المنيو">

المسافة: "كشري زيادة بصل" طلبية واحدة.

`;` : "هات كشري. وبعدين هات شاي" حتى لو الكشري خلّص.

`&&` : "لو الكشري موجود، هات شاي".

`||` : "لو الكشري خلّص، هات كفتة".

`|` : الشيف يسلّم الطبق للجارسون على طول، من غير ما يحطه على الرخام.

`&` : "ابدأ الكشري ومتستناش، أنا هكمّل أكلم".

</Box>

## جدول تقفل بيه الفصل

| الكتابة | بيفصل إيه؟ | يستنى؟ | لو الأول فشل |
| --- | --- | --- | --- |
| مسافة | كلمات نفس الأمر | أمر واحد | مفيش أمر تاني |
| `;` أو سطر جديد | أمرين ورا بعض | أيوه | التاني يشتغل برضه |
| `&&` | أمرين | أيوه | التاني مايشتغلش |
| علامة أو `\|\|` | أمرين | أيوه | التاني يشتغل |
| ماسورة | مخرج في مدخل | مع بعض | شوف pipefail في فصل السكربت |
| `&` | أمر في الخلفية | لأ | التاني يشتغل فورًا |

<Box type="tip" title="أقواس">

`{ mkdir a; cd a; }` تجمّع أوامر في نفس الشيل. `(mkdir a; cd a)` تجمّعهم في شيل ابن: `cd` جواه مش هيغيّر فولدرك أنت. القوس المفتوح `{` لازم قبله مسافة، والآخر `;` قبل القفل.

</Box>
