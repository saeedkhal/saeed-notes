## اتجاهين مختلفين

| الاتجاه | مين بيتكلم | الشهادة بتاعة مين | السطر يأثر؟ |
| --- | --- | --- | --- |
| داخل | المتصفح أو التطبيق بيتصل بالـ API | شهادتك إنت | لأ |
| خارج | الـ backend بيتصل بـ SMTP أو الدفع أو Firebase | شهادة السيرفر التاني | أيوه |

<Hl c="b">ملفات `SSL_PUBLIC_KEY` و`SSL_CERT_KEY` في `bin/www` هي البطاقة اللي سيرفرك بيوريها للزوار.</Hl> السطر مش بيعدّل الملفات دي، وHTTPS على الـ API يفضل زي ما هو.

الاتصال الخارج هو اللي بيتفحص: Node بيبص في شهادة SMTP أو MyFatoorah أو Firebase. السطر بيطفّي البصة دي.
