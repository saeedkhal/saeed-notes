## rc-select وعيلة rc-\*

**المميزات:** فيها components تقيلة مش موجودة في الـ headless libraries: virtual list جوه الـ select، و `TreeSelect`، و `Cascader`، و table معقد.

**العيوب:**

- مش headless بالمعنى الحقيقي. معمولة على مقاس antd، فبتيجي بـ classNames وبنية DOM ثابتة. <Hl c="o">انت بتعمل override للـ CSS بدل ما تبني الشكل من الأول.</Hl>
- الـ animation ماشية بـ `rc-motion` اللي بيعتمد على classes بأسماء معينة (`motionName`). تقدر تغيّرها، بس هتفضل جوه نظامها.
- الـ accessibility أضعف من Base UI و React Aria.
- الـ API والـ docs متوجهين لفريق antd.

<Box type="warn" title="ماتبنيش الـ lib عليها">

استخدمها بس لـ component واحد أو اتنين تقال (TreeSelect، Cascader). وللجداول والـ lists الطويلة، **TanStack Table** و **TanStack Virtual** أنضف من rc-table.

</Box>

## Base UI

- **المميزات:** headless بجد، `render` prop للـ composition، سهلة مع Tailwind، ووراها community وأمثلة كتير لأن shadcn بيستخدمها.
- **العيوب:** جديدة نسبيًا، وبعض الـ components المعقدة (زي date picker) لسه مش كاملة زي React Aria.
- **مناسبة لـ:** design system عام بـ Tailwind وعايز توازن بين السرعة والجودة.

## React Aria

- **المميزات:**
  - أقوى accessibility حاليًا، متختبرة على screen readers وأجهزة كتير.
  - <Hl c="g">دعم RTL و i18n ممتاز</Hl>: الكيبورد والـ positioning بيتعكسوا صح. مهم جدًا لـ UI عربي.
  - أقوى date picker و calendar، وبيدعموا تقاويم مختلفة زي الهجري.
  - مستويين: hooks زي `useButton` و `useComboBox`، أو `react-aria-components` جاهزة headless.
- **العيوب:** الكود verbose، الـ learning curve أعلى، والـ bundle أكبر.
- **مناسبة لـ:** products جدية لازم تكون accessible وبأكتر من لغة، وفيها forms وتواريخ كتير.

## Radix

ناضجة ومستخدمة في production كتير. بس نفس الصناع ركزوا على Base UI، والـ RTL فيها أضعف. <Hl c="b">لو هتبدأ من الصفر النهارده، مفيش سبب قوي تختارها بدل Base UI.</Hl>

## الـ Hybrid: تخلط عادي

<Box type="story" icon="🍲" title="زي طبق كشري">

الرز من محل، والصلصة من بيتك، والتقلية من عند الجيران… بس كله في **طبق واحد** والزبون بياكله على إنه طبق واحد. المهم الطعم يبقى متناسق.

</Box>

مثلًا: Base UI أساس الـ lib، و DatePicker و Calendar من React Aria، و rc-\* بس لو احتجت component تقيل مش موجود في غيرها.

<Box type="interview" title="القاعدة الذهبية">

المستخدم يشوف **API واحد موحّد بتاعك انت**، مش API كل مكتبة تحت. اعمل wrap لكل component بحيث الـ props والأسماء والـ data attributes متسقة.

</Box>

```tsx
// المستخدم مش عارف ولا يهمه إن ده React Aria تحت
export function DatePicker({ value, onChange, label }: DatePickerProps) {
  return (
    <AriaDatePicker value={value} onChange={onChange} className="ui-datepicker">
      {/* ... الشكل بتاعك ... */}
    </AriaDatePicker>
  );
}
```
