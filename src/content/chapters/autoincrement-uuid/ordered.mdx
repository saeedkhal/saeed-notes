## ترتيب جوه نفس الميلي ثانية

لو حاطط الوقت بس والباقي عشوائي، رقمين اتولدوا في نفس الميلي ثانية مش مضمون مين فيهم الأول. عشان كده المولّد الجاد بيحط عدّاد صغير بعد الوقت، ويزوّده لو لسه في نفس اللحظة. لو العدّاد خلّص، يتحرك للميلي ثانية اللي بعدها حتى لو الساعة لسه هناك.

لو ساعة السيرفر رجعت لورا، العدّاد لوحده مش هينقذك إلا لو فاكر آخر وقت استخدمته ومش راضي ترجع قبله. الساعات المتظبطة مهمة. متبنيش مولّد موزع من غير ما تقول الجملة دي.

<File name="src/uuidv7.js">

```js
import { randomBytes } from "node:crypto";

let lastMs = 0;
let seq = 0;

export function uuidv7(now = Date.now()) {
  if (now > lastMs) {
    lastMs = now;
    seq = 0;
  } else {
    seq += 1;
    if (seq > 0xfff) {
      seq = 0;
      lastMs += 1;
    }
  }

  const bytes = randomBytes(16);
  const ts = BigInt(lastMs);
  bytes[0] = Number((ts >> 40n) & 0xffn);
  bytes[1] = Number((ts >> 32n) & 0xffn);
  bytes[2] = Number((ts >> 24n) & 0xffn);
  bytes[3] = Number((ts >> 16n) & 0xffn);
  bytes[4] = Number((ts >> 8n) & 0xffn);
  bytes[5] = Number(ts & 0xffn);
  bytes[6] = 0x70 | ((seq >> 8) & 0x0f);
  bytes[7] = seq & 0xff;
  bytes[8] = (bytes[8] & 0x3f) | 0x80;

  const hex = bytes.toString("hex");
  return `${hex.slice(0, 8)}-${hex.slice(8, 12)}-${hex.slice(12, 16)}-${hex.slice(16, 20)}-${hex.slice(20)}`;
}
```

</File>

البايت ٦ فيه النسخة ٧، والبايت ٨ فيه شكل الـ UUID القياسي. الباقي وقت وعدّاد ١٢ بت وعشوائي. الدالة دي كويسة لعملية Node واحدة. عمليتين على ماكينتين مختلفين ممكن يطلعوا نفس الرقم لو الوقت والعدّاد والعشوائي اتقابلوا، والاحتمال ضئيل، والـ unique index هو اللي يمنع الكارثة. لو محتاج ضمان أقوى بين الماكينات، حط رقم الماكينة في الحشو زي Snowflake.

<Box type="warn" title="متولّدش v4 وتسميه v7">

`randomUUID()` في Node نسخة ٤. الوقت مش في الأول، فالإندكس مش هيستفيد. لو المكتبة أو الدالة مش مكتوب عليها v7، افترض إنها عشوائية.

</Box>
