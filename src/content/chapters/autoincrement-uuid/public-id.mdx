## الصورة بتخلط حاجتين

اللينك اللي اليوزر يشوفه مش لازم يكون المفتاح اللي الجداول التانية بتشاور عليه. لما تخلطهم، يا بتكبر كل foreign key عشان اللينك يبقى صعب يتخمّن، يا بتحط الرقم المتسلسل قدام الناس.

```sql
CREATE TABLE users (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  public_id uuid NOT NULL UNIQUE,
  name text NOT NULL
);

CREATE TABLE orders (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  user_id bigint NOT NULL REFERENCES users (id),
  total_cents integer NOT NULL
);
```

</File>

`id` صغير ومتسلسل. كل أوردر بيشاور عليه بـ ٨ بايت، والإندكسات الداخلية مرتاحة. `public_id` هو اللي في اللينك، والأفضل يكون UUIDv7 مش v4، عشان إندكسه هو كمان يكتب ناحية الآخر. الرد للبرا يرجع `public_id` بس. الرقم الداخلي ميعبرش الـ JSON.

## امتى المفتاح الواحد يكفي

مفتاحين ليهم تمن: عمود زيادة، وإندكس unique، وتفتكر إنك متبحثش بالرقم الغلط. متدفعوش بالعادة.

<Grid2>
<Card title="bigint واحد يكفي" c={2}>

أداة داخلية، قاعدة واحدة، والـ id مش في لينك عام. أو جدول أحداث مش هيظهر لليوزر.

</Card>
<Card title="uuid واحد يكفي" c={4}>

تطبيق أصغر، والـ UUID هو المفتاح، ويفضل v7. لسه بدري على تعقيد مفتاحين.

</Card>

المفتاحين يبقوا يستاهلوا لما يبقى عندك foreign keys كتير وعايزها صغيرة، واللينك العام لازم يبقى مش متسلسل. ده التصميم اللي ينفع تقف جنبه في الإنترفيو لما النظام مش "جدول واحد".

## الصلاحية خطوة تانية

الدوران بـ `public_id` بيجيب الصف. بعد كده تسأل: الطالب ده يشوفه؟ جلسة، أو عضوية، أو إن البروفايل عام. لو الخطوة دي مش موجودة، UUID بس بيأجّل أول شخص يخمن أو يلاقي اللينك في لوج.

لو المورد خاص، رجّع نفس الرد لو الصف مش موجود أو مش مسموح، عشان وجود الرقم نفسه متتسربش. البروفايل العام شيء تاني: ٤٠٤ لما المستخدم مش موجود تكفي.

التصفح بالصفحات لجدول كبير يبقى بمفتاح مرتب (`created_at` مع `id` الداخلي)، مش بـ `OFFSET` بيكبر. الـ public_id مش لازم يكون أداة التصفح.

<Box type="interview" title="الإجابة اللي تقفل السؤال">

"الـ GET بالاتنين مش هو اللي بيكبر. على قاعدة واحدة هبدأ بـ bigint identity. لو الكتاب كتير، هولّد UUIDv7 أو Snowflake من غير عدّاد مركزي. في اللينك هحط المعرّف العام، والجداول الداخلية تفضل على bigint. والتخمين مش صلاحية."

</Box>
