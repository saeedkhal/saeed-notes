## الفكرة

السيرفر **مبيلمسش الملف**. هو بيعمل حاجة واحدة: يتأكد إن المستخدم ده مسموحله، ويولّد **URL مؤقت متوقّع** (pre-signed URL). الـ client يرفع أو ينزّل بيه من S3 مباشرة.

الخطوة ٤ (مش في الرسمة): الـ client يقول للسيرفر "خلصت". والسيرفر **ميصدقش** على طول: يتأكد من S3 إن الملف موجود فعلًا (٥) قبل ما يكتب الـ metadata (٦). هنرجعلها في فصل الأمان.

## السيرفر: يولّد URL للرفع

<File name="uploads.ts">

```ts
import { S3Client, PutObjectCommand } from "@aws-sdk/client-s3";
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";
import { randomUUID } from "node:crypto";

const s3 = new S3Client({ region: process.env.AWS_REGION });
const ALLOWED = new Set(["image/png", "image/jpeg", "application/pdf"]);

app.post("/uploads", requireAuth, async (req, res) => {
  const { contentType, folderId } = req.body;
  if (!ALLOWED.has(contentType)) return res.status(400).json({ error: "type not allowed" });
  if (!(await canUploadTo(req.user.id, folderId))) return res.sendStatus(403);

  // اسم بنولّده إحنا، مش اسم الملف بتاع المستخدم
  const key = `uploads/${req.user.id}/${randomUUID()}`;
  const url = await getSignedUrl(
    s3,
    new PutObjectCommand({ Bucket: process.env.BUCKET, Key: key, ContentType: contentType }),
    { expiresIn: 300 }, // ٥ دقايق
  );

  await db.upload.create({ data: { key, ownerId: req.user.id, folderId, status: "pending" } });
  res.json({ url, key });
});
```

</File>

## الـ client: يرفع مباشرة

<File name="uploadFile.ts">

```ts
export async function uploadFile(file: File, folderId: string) {
  const { url, key } = await api.post("/uploads", { contentType: file.type, folderId });

  const put = await fetch(url, {
    method: "PUT",
    body: file,
    headers: { "Content-Type": file.type }, // لازم نفس اللي اتوقّع، وإلا S3 يرفض
  });
  if (!put.ok) throw new Error(`upload failed: ${put.status}`);

  // نقول للسيرفر خلصنا، وهو يتأكد بنفسه
  return api.post(`/uploads/${encodeURIComponent(key)}/complete`, { name: file.name });
}
```

</File>

<Box type="warn" title="الـ Content-Type جزء من التوقيع">

لو السيرفر حط `ContentType` في الـ command، الـ client **لازم** يبعت نفس الـ header بالظبط، وإلا S3 يرد `403 SignatureDoesNotMatch`. أشهر error في أول مرة تجرّب. وكمان الـ bucket محتاج **CORS** يسمح بـ `PUT` من الدومين بتاعك.

</Box>

## التنزيل: pre-signed GET

نفس الفكرة بالعكس: السيرفر يتأكد من الصلاحية، ويرجّع URL مؤقت، والمتصفح ينزّل من S3 على طول.

<File name="downloads.ts">

```ts
import { GetObjectCommand } from "@aws-sdk/client-s3";

app.get("/files/:id/download", requireAuth, async (req, res) => {
  const file = await db.file.findFirst({ where: { id: req.params.id, ownerId: req.user.id } });
  if (!file) return res.sendStatus(404);

  const url = await getSignedUrl(
    s3,
    new GetObjectCommand({
      Bucket: process.env.BUCKET,
      Key: file.key,
      // الاسم اللي يظهر للمستخدم وهو بينزّل، مش الـ key
      ResponseContentDisposition: `attachment; filename="${encodeURIComponent(file.name)}"`,
    }),
    { expiresIn: 300 },
  );
  res.redirect(302, url);
});
```

</File>
