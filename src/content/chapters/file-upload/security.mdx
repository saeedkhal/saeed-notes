## الـ pre-signed URL مفتاح، مش لينك

<Hl c="p">أي حد معاه الـ URL يقدر يستخدمه طول ما هو صالح</Hl>. مفيش login، ومفيش cookie. اللينك نفسه هو الإذن. يعني لو:

<Chips items={["اتكتب في logs السيرفر أو الـ proxy", "اتبعت بالغلط في شات", "اتنسخ من الـ Network tab", "اتحفظ في history المتصفح"]} />

…حد تاني يقدر يرفع أو ينزّل بيه. عشان كده **العمر لازم يبقى قصير**: ٥ لـ ١٠ دقايق كفاية يبدأ فيهم الـ client الرفع أو التنزيل.

<Box type="story" icon="🔑" title="مفتاح الشقة المستأجرة">

إنك تدّي السبّاك مفتاح ينفع لحد العصر حاجة، وإنك تدّيه نسخة من مفتاحك تفضل معاه للأبد حاجة تانية خالص. الـ pre-signed URL اللي عمره أسبوع هو النسخة اللي بتفضل معاه.

</Box>

## النقطة الأولى: متصدقش الـ client لما يقول "رفعت"

الـ client ممكن ينادي `/complete` من غير ما يرفع حاجة، أو يرفع ملف أكبر أو بنوع غير اللي قاله. اتأكد من S3 نفسه:

<File name="complete.ts">

```ts
import { HeadObjectCommand } from "@aws-sdk/client-s3";

app.post("/uploads/:key/complete", requireAuth, async (req, res) => {
  const upload = await db.upload.findFirst({
    where: { key: req.params.key, ownerId: req.user.id, status: "pending" },
  });
  if (!upload) return res.sendStatus(404);

  let head;
  try {
    head = await s3.send(new HeadObjectCommand({ Bucket: process.env.BUCKET, Key: upload.key }));
  } catch {
    return res.status(409).json({ error: "file not found in storage" });
  }
  if ((head.ContentLength ?? 0) > MAX_BYTES) return res.status(413).json({ error: "too large" });

  const file = await db.file.create({
    data: {
      key: upload.key,
      ownerId: req.user.id,
      name: req.body.name,
      size: head.ContentLength,
      contentType: head.ContentType,
    },
  });
  await db.upload.update({ where: { key: upload.key }, data: { status: "done" } });
  res.status(201).json({ id: file.id });
});
```

</File>

الـ size والـ content type جايين من **S3** مش من الـ body اللي الـ client باعته.

## النقطة التانية: pre-signed PUT مش بيحدد الحجم

الـ pre-signed PUT في S3 مفيهوش حد أقصى للحجم: أي حد معاه اللينك يقدر يرفع ملف ٥ جيجا. لو عايز max size، استخدم **pre-signed POST** بـ policy فيها `content-length-range`:

<File name="presignedPost.ts">

```ts
import { createPresignedPost } from "@aws-sdk/s3-presigned-post";

const { url, fields } = await createPresignedPost(s3, {
  Bucket: process.env.BUCKET!,
  Key: key,
  Conditions: [
    ["content-length-range", 1, 10 * 1024 * 1024], // من ١ بايت لـ ١٠ ميجا
    ["eq", "$Content-Type", contentType],
  ],
  Fields: { "Content-Type": contentType },
  Expires: 300,
});
```

</File>

<File name="client.ts">

```ts
const form = new FormData();
Object.entries(fields).forEach(([k, v]) => form.append(k, v));
form.append("file", file); // لازم يبقى آخر حاجة في الفورم
await fetch(url, { method: "POST", body: form });
```

</File>

لو الملف أكبر من الحد، S3 هو اللي يرفضه، قبل ما يتخزن.
