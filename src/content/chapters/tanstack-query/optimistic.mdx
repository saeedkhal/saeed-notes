اللايك لو مستني السيرفر، الزرار يبان متأخر. التحديث المتفائل يغيّر الشاشة الأول، والطلب يمشي وراها.

<File name="optimistic-student.jsx">

```jsx
const mutation = useMutation({
  mutationFn: updateStudent,
  onMutate: async (newStudent) => {
    await queryClient.cancelQueries({ queryKey: ["student", newStudent.id] });
    const previous = queryClient.getQueryData(["student", newStudent.id]);

    queryClient.setQueryData(["student", newStudent.id], newStudent);

    return { previous };
  },
  onError: (err, newStudent, context) => {
    queryClient.setQueryData(["student", newStudent.id], context.previous);
  },
  onSettled: (newStudent) => {
    queryClient.invalidateQueries({ queryKey: ["student", newStudent.id] });
  },
});
```

</File>

الترتيب:

1. <En>onMutate</En> يوقف الطلبات اللي لسه بتجيب نفس الطالب، عشان رد قديم ما يمسحش الكتابة الجديدة.
2. تاخد نسخة القديم من <En>getQueryData</En>.
3. <En>setQueryData</En> يحط الشكل الجديد في الكاش فورًا.
4. ترجع القديم في السياق، عشان لو حصل تراجع.
5. <En>onError</En> يرجّع النسخة دي.
6. <En>onSettled</En> يبطل المفتاح بعد النجاح أو الفشل، والسيرفر يبقى مصدر الحقيقة.

لما الإحساس بالزرار أهم من إنك تستنى الشبكة: لايك، تعليم كمقروء، تبديل حالة صغيرة. لو الكتابة معقّدة وسهل تتعارض، الإبطال بعد النجاح أهدى من التخمين.
