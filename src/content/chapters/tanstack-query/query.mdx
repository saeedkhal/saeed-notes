<En>useQuery</En> للقراءة. بتديله مفتاح، ودالة بترجع الطلب.

<File name="StudentsList.jsx">

```jsx
import { useQuery } from "@tanstack/react-query";

function getStudents() {
  return fetch("/api/students").then((res) => res.json());
}

function StudentsList() {
  const { data, isPending, isError, error } = useQuery({
    queryKey: ["students"],
    queryFn: getStudents,
  });

  if (isPending) return <p>جاري التحميل...</p>;
  if (isError) return <p>خطأ: {error.message}</p>;

  return (
    <ul>
      {data.map((s) => (
        <li key={s.id}>{s.name}</li>
      ))}
    </ul>
  );
}
```

</File>

## المفتاح هو عنوان الرف

<Hl c="p">queryKey معرّف الداتا دي في الكاش</Hl>. لو مكوّنين نادوا نفس المفتاح، المكتبة تشاركهم الداتا ونفس الجلب. مش طلب مرتين.

المفتاح مصفوفة. حط جواها اللي بيغيّر النتيجة.

<File name="one-student.jsx">

```jsx
useQuery({
  queryKey: ["student", studentId],
  queryFn: () => getStudent(studentId),
});
```

</File>

كل ما <En>studentId</En> يتغير، دي استعلام تاني، وجلب جديد. الداتا القديمة تفضل تحت مفتاحها.

<Box type="warn" title="اللي بيتغير لازم يدخل المفتاح">

لو بعت معامل لدالة الجلب ومتحطّوش في <En>queryKey</En>، الكاش يفضل شايف نفس الرف. المعامل يتبدل والنتيجة المعروضة لأ. أي حاجة بتفرّق الطلب، حطها في المصفوفة.

</Box>
