ساعات الطلب التاني محتاج ناتج الأول. تجيب الطالب، وبعدين درجاته برقمه.

<File name="grades-after-student.jsx">

```jsx
const { data: student } = useQuery({
  queryKey: ["student", studentId],
  queryFn: () => getStudent(studentId),
});

const { data: grades } = useQuery({
  queryKey: ["grades", student?.id],
  queryFn: () => getGrades(student.id),
  enabled: !!student?.id,
});
```

</File>

<Hl c="b">enabled هو مفتاح التشغيل</Hl>. طالما رقم الطالب مش موجود، الاستعلام التاني ما يبدأش. أول ما الرقم ييجي، المفتاح يتكمّل والدرجات تتجاب.

من غيره، دالة الجلب تنادي وهي لسه من غير رقم، والطلب يروح ناقص أو يقع.

نفس العلم ينفع لأي شرط: المستخدم مسجّل، الفلتر اتكتب، الصفحة ظاهرة. الاستعلام موجود في الكود، بس واقف لحد ما الشرط يصح.
