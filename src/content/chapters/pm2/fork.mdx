## الفكرة

في fork، كل instance بتبقى **process مستقلة**: ليها memory لوحدها، وevent loop لوحده، وفي الغالب **port لوحده**. مفيش أي حاجة مشتركة بين الـ processes.

<Hl c="p">الـ processes مش بتتقاسم port، فلازم حد قدامهم يوزّع الطلبات عليهم.</Hl> والحد ده غالبًا Nginx.

## بإيدك: سكريبت بيشغّل 3 processes

<File name="fork-launcher.js">

```js
const { fork } = require("node:child_process");

const ports = [3001, 3002, 3003];

for (const port of ports) {
  // كل واحدة process جديدة تمامًا، وبناخد الـ port من env
  const child = fork("./server.js", [], {
    env: { ...process.env, PORT: String(port) },
  });
  child.on("exit", (code) => console.log(`port ${port} exited with ${code}`));
}
```

</File>

السكريبت ده بيعمل fork وبس: مش بيرجّع process لو وقعت، ومش بيوزّع طلبات. وعشان العميل يكلم port واحد، محتاج Nginx:

<File name="/etc/nginx/conf.d/app.conf">

```nginx
upstream app {
  server 127.0.0.1:3001;
  server 127.0.0.1:3002;
  server 127.0.0.1:3003;
}

server {
  listen 80;
  location / {
    proxy_pass http://app;
  }
}
```

</File>

## نفس الكلام بـ PM2

بدل السكريبت، PM2 بيشغّل الـ processes ويرجّع أي واحدة تقع. والمشكلة إن كلهم هيقروا نفس `PORT`، فنستخدم `increment_var`:

<File name="ecosystem.config.js">

```js
module.exports = {
  apps: [
    {
      name: "api-fork",
      script: "./server.js",
      exec_mode: "fork",
      instances: 3,
      increment_var: "PORT", // 3001، 3002، 3003
      env: { PORT: 3001 },
    },
  ],
};
```

</File>

<File name="terminal">

```bash
pm2 start ecosystem.config.js
pm2 list                         # عمود mode = fork
curl localhost:3001; curl localhost:3002; curl localhost:3003
```

</File>

- PM2 بيزوّد `PORT` بواحد لكل instance جديدة.
- لو نسيت `increment_var`، كلهم هيحاولوا يفتحوا 3001، والتانية والتالتة هيقعوا بـ `EADDRINUSE`.
- Nginx لسه مطلوب قدامهم. PM2 في fork مش بيوزّع ترافيك.

<Box type="idea" title="إمتى fork هو الصح؟">

- لما التطبيق مش Node، زي Python أو bash أو binary.
- لما التطبيق Node بس مش HTTP server، زي worker بيسحب jobs من queue أو cron runner. في الحالة دي مفيش port يتقسم أصلًا.
- لما عايز instance واحدة بس. ساعتها مفيش فرق، وfork أبسط.

</Box>
