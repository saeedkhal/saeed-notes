## إزاي نفس الـ port مش بيتخانق؟

Node `cluster` يعمل primary process ويفرّع workers. الـ workers processes منفصلة، لكن cluster ينسّق بينهم ويشارك server handle؛ عشان كده كل worker تقدر تعمل `listen(3000)`.

على الأنظمة المدعومة، Node غالبًا يخلي الـ primary يوزع connections على workers بـ round-robin. Windows له سلوك وقيود مختلفة، فمتبنيش توقعات production من تجربة على نظام تاني.

## Cluster من غير PM2

<File name="cluster.js">

```js
import cluster from "node:cluster";
import os from "node:os";

if (cluster.isPrimary) {
  const count = os.availableParallelism();
  console.log(`primary ${process.pid}: ${count} workers`);

  for (let i = 0; i < count; i++) cluster.fork();

  cluster.on("exit", (worker, code) => {
    console.error(`worker ${worker.process.pid} exited: ${code}`);
    if (!worker.exitedAfterDisconnect) {
      setTimeout(() => cluster.fork(), 1000);
    }
  });
} else {
  await import("./server.js");
}
```

</File>

<File name="terminal">

```bash
node cluster.js

for i in {1..8}; do
  curl --no-keepalive http://localhost:3000
done
```

</File>

الـ PID المفروض يتغير بين responses. `--no-keepalive` يساعد التجربة تعمل connections جديدة؛ connection واحدة persistent مش لازم تتنقل بين workers.

## وبـ PM2

مش محتاج تكتب `cluster.js`. ادّي PM2 ملف السيرفر العادي:

<File name="ecosystem.cluster.config.cjs">

```js
module.exports = {
  apps: [{
    name: "api-cluster",
    script: "server.js",
    exec_mode: "cluster",
    instances: "max",
    env: { PORT: 3000 },
  }],
};
```

</File>

<File name="terminal">

```bash
pm2 start ecosystem.cluster.config.cjs
pm2 list
pm2 scale api-cluster 6
```

</File>

`max` أو `0` معناهم عدد الـ CPUs المتاحة، و`-1` يعني العدد ناقص واحد. العدد الأكبر مش دايمًا أسرع؛ سيب مساحة للـ OS والـ database والـ reverse proxy، واعمل load test.

## `cluster.fork()` مبنية على إيه؟

هي نفسها تستخدم `child_process.fork()` لتكوين Node processes وقناة IPC. القيمة المضافة من cluster هي إدارة workers ومشاركة server handles وسياسة توزيع connections.

<Hl c="g">Cluster يوزع requests على processes؛ مش بيقسم request واحدة تقيلة على cores.</Hl>
