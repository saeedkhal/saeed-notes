## المشكلة

PM2 بيكتب الـ logs في `~/.pm2/logs`، ملف للـ out وملف للـ error لكل app. ولو التطبيق بيطبع كتير، الملفات دي بتكبر لحد ما الهارد يتملي والسيرفر كله يقف.

<Hl c="o">الحل مش إنك تمسح الملفات بإيدك، الحل rotation.</Hl> يعني الملف الحالي يتقفل ويتسمى بالتاريخ، ويبدأ ملف جديد، والقديم يتمسح بعد عدد معين.

## التثبيت

`pm2-logrotate` ده PM2 module، فبيتسطب بـ `pm2 install` مش بـ npm أو pnpm:

<File name="terminal">

```bash
pm2 install pm2-logrotate
```

</File>

## الإعداد

<File name="terminal">

```bash
pm2 set pm2-logrotate:max_size 1G
pm2 set pm2-logrotate:retain 7
pm2 set pm2-logrotate:compress false
pm2 set pm2-logrotate:dateFormat YYYY-MM-DD_HH-mm-ss
pm2 set pm2-logrotate:workerInterval 30
pm2 set pm2-logrotate:rotateInterval '0 0 * * *'
pm2 set pm2-logrotate:TZ Asia/Kuwait

pm2 conf pm2-logrotate   # راجع القيم
```

</File>

## كل سطر معناه إيه؟

- **`max_size 1G`:** لما الملف يعدّي 1G، يتعمله rotate. وممكن يعدّي الرقم شوية، لأن الفحص بيحصل كل فترة مش مع كل سطر.
- **`retain 7`:** يحتفظ بآخر 7 ملفات قديمة، والملف الحالي فوقهم. يعني مش 7 إجمالي.
- **`compress false`:** الضغط **مقفول**. لو عايز الملفات القديمة تتضغط بـ gzip وتاخد مساحة أقل، خليها `true`.
- **`dateFormat`:** شكل التاريخ اللي بيتحط في اسم الملف القديم.
- **`workerInterval 30`:** كل كام ثانية يفحص حجم الملفات.
- **`rotateInterval '0 0 * * *'`:** cron بيعمل rotate كل يوم الساعة 12 بالليل، حتى لو الملف لسه موصلش للحجم. والـ quotes مهمة عشان الـ shell ميفسّرش النجوم كأسماء ملفات.
- **`TZ Asia/Kuwait`:** التوقيت اللي الـ cron والتاريخ بيمشوا عليه. ولو مش محطوطة، بياخد توقيت السيستم.

<Box type="tip" title="حسبة الهارد">

الأسوأ تقريبًا = `max_size` × (`retain` + 1) لكل ملف. يعني 1G × 8 = حوالي 8G للـ out، ومثلهم للـ error، لكل app. ولو الهارد صغير، قلّل الرقمين أو فعّل `compress`.

</Box>

## شكل الملفات

<Tree>

```text
~/.pm2/logs/
├── LMS--backend-out.log                          ← الحالي
├── LMS--backend-out__2026-10-12_00-00-00.log     ← قديم
├── LMS--backend-out__2026-10-11_00-00-00.log
├── LMS--backend-error.log
└── LMS--backend-error__2026-10-12_00-00-00.log
```

</Tree>

الاسم الفعلي بيختلف حسب اسم الـ app والإصدار، والرموز زي `:` في الاسم بتتحوّل لـ `-`. اعتمد على اللي عندك في `ls ~/.pm2/logs`.

## متمسحش log شغال بـ `rm`

لو عملت `rm` على ملف الـ app لسه فاتحه، الملف هيختفي من الفولدر، لكن الـ app هيفضل يكتب فيه، والمساحة **مش هترجع** لحد ما الـ process تقفل. وده اللي بيخلي `df` يقول الهارد مليان و`du` مش لاقي حاجة.

<File name="terminal">

```bash
pm2 flush                  # يفضّي كل ملفات الـ logs من غير ما يمسحها
pm2 flush "LMS::backend"   # app واحد بس

# لو مسحت بـ rm خلاص، خلي الـ app يفتح ملف جديد:
pm2 reload all             # في cluster من غير downtime
pm2 restart all            # في fork
```

</File>
