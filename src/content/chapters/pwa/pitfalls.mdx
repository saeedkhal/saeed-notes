## أدوات التشخيص

<Grid2>
<Card title="🛠️ Application tab" c={1}>

**Service workers**: الحالة، Update، Unregister، و **Offline**. و **Bypass for network** وإنت بتطوّر عشان الكاش ميلخبطكش. و **Cache storage** تشوف وتمسح منه.

</Card>
<Card title="📡 Network tab" c={5}>

الرد اللي جه من الـ SW مكتوب جنبه `(ServiceWorker)`. لو مش شايفه، يبقى الـ SW مش ماسك الصفحة.

</Card>
</Grid2>

<Box type="warn" title="لما تختبر بـ Playwright أو Puppeteer">

`context.setOffline(true)` مش بيأثر على الـ fetch اللي جوه الـ Service Worker، فهتلاقي كل حاجة "شغالة" وإنت فاكر النت مقطوع. الأضمن تقفل السيرفر نفسه. (ده اللي حصل معانا وإحنا بنختبر الموقع ده.)

</Box>

## رسالة "في تحديث جديد"

<File name="main.js">

```js
const reg = await navigator.serviceWorker.register("/sw.js");

reg.addEventListener("updatefound", () => {
  const next = reg.installing;
  next?.addEventListener("statechange", () => {
    // اتسطّب وفي SW قديم ماسك الصفحة = في نسخة جديدة مستنية
    if (next.state === "installed" && navigator.serviceWorker.controller) {
      showToast("في نسخة جديدة", () => next.postMessage("SKIP_WAITING"));
    }
  });
});

// لما الجديد يمسك، اعمل reload مرة واحدة
let reloaded = false;
navigator.serviceWorker.addEventListener("controllerchange", () => {
  if (!reloaded) { reloaded = true; location.reload(); }
});
```

</File>

<File name="sw.js">

```js
self.addEventListener("message", (event) => {
  if (event.data === "SKIP_WAITING") self.skipWaiting();
});
```

</File>

<Box type="interview" title="سؤال إنترفيو">

"إزاي تعمل unregister لـ Service Worker بايظ عند كل المستخدمين؟" — انشر `sw.js` جديد بيمسح الكاش وينادي `self.registration.unregister()` في activate. مينفعش تمسح الملف بس، لأن الـ SW القديم ممكن يفضل يخدم من الكاش. عشان كده **الـ SW لازم يتصمم من الأول إنه يتحدث**.

</Box>
