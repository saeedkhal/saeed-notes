لو الملف في الكاش، **مفيش نت خالص**. أسرع حاجة ممكنة، بس لو الملف اتغير على السيرفر مش هتعرف.

**مناسبة لـ:** ملفات اسمها فيه hash (`app.3f9a1c.js`)، والخطوط، والصور اللي مبتتغيرش.

<File name="sw.js">

```js
async function cacheFirst(request) {
  const cached = await caches.match(request);
  if (cached) return cached;
  const response = await fetch(request);
  if (response.ok) {
    const cache = await caches.open("assets-v1");
    cache.put(request, response.clone()); // clone: الـ body بيتقري مرة واحدة بس
  }
  return response;
}
```

دايمًا بتحاول تجيب الأحدث، والكاش احتياطي. العيب: على نت بطيء المستخدم **بيستنى** لحد ما الشبكة ترد أو تفشل. حط timeout عشان متستناش للأبد.

المستخدم بياخد رد **فوري** من الكاش، وفي نفس اللحظة بنحدّث الكاش من النت. يعني بيشوف الجديد **المرة الجاية**، مش دلوقتي.

**مناسبة لـ:** حاجات مش مشكلة لو اتأخرت مرة: الـ avatar، فهرس البحث، الـ config.

<File name="sw.js">

```js
async function staleWhileRevalidate(event, request) {
  const cache = await caches.open("static-v1");
  const cached = await cache.match(request);
  const network = fetch(request).then((res) => {
    if (res.ok) cache.put(request, res.clone());
    return res;
  });
  if (cached) {
    event.waitUntil(network.catch(() => {})); // كمّل التحديث حتى بعد ما رديت
    return cached;
  }
  return network;
}
```

</File>

## إزاي تختار؟

| نوع الملف | الاستراتيجية | ليه |
| --- | --- | --- |
| JS و CSS باسم فيه hash | Cache First | الاسم بيتغير لو المحتوى اتغير |
| صفحات HTML لمحتوى | Cache First بصلاحية، أو Network First | محتاجة تتحدث بس تفتح offline |
| API داتا متغيرة | Network First + timeout | الأحدث أهم، والكاش احتياطي |
| صور المستخدمين والـ config | Stale-While-Revalidate | السرعة أهم من الحداثة اللحظية |
| POST والدفع | Network Only | ميتكاشش أبدًا |
