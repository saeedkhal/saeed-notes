## التسجيل

الصفحة هي اللي بتقول للمتصفح "في Service Worker هنا":

<File name="main.js">

```js
if ("serviceWorker" in navigator) {
  navigator.serviceWorker.register("/sw.js", { scope: "/" });
}
```

</File>

الـ `scope` هو المسارات اللي الـ SW هيمسكها. ملف في `/app/sw.js` مش هيقدر يمسك `/` إلا لو السيرفر سمح بـ header خاص، فالأسهل تحطه في جذر المسار اللي عايزه.

<File name="sw.js">

```js
const SHELL = "shell-v2";

self.addEventListener("install", (event) => {
  // waitUntil: متعتبرش الـ install خلص غير لما الـ promise يخلص
  event.waitUntil(caches.open(SHELL).then((c) => c.addAll(["/offline.html"])));
});

self.addEventListener("activate", (event) => {
  event.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(keys.filter((k) => k.startsWith("shell-") && k !== SHELL).map((k) => caches.delete(k))),
    ),
  );
});

self.addEventListener("fetch", (event) => {
  // هنا بنقرر نرد منين (الفصل الجاي)
});
```

</File>

## ليه في مرحلة waiting؟

لو عندك تابة مفتوحة شغالة بالـ SW القديم، والنسخة الجديدة مسكت فجأة، ممكن الصفحة القديمة تطلب ملف مبقاش موجود في الكاش الجديد. عشان كده المتصفح بيخلّي الجديد **مستني** لحد ما كل التابات القديمة تتقفل.

<Box type="story" icon="👮" title="تسليم الوردية">

العسكري الجديد وصل، بس مش هياخد البوابة غير لما القديم يمشي. ولو الظابط قاله "استلم دلوقتي" (`skipWaiting`)، يستلم على طول. و `clients.claim()` معناها إنه يمسك كمان الناس اللي دخلوا قبل ما ييجي، مش اللي جايين بعده بس.

</Box>

<Box type="warn" title="skipWaiting مش ببلاش">

لو الصفحة المفتوحة متوقعة ملفات معينة والنسخة الجديدة غيّرتها، ممكن حاجة تبوظ لحد ما المستخدم يعمل refresh. في موقع محتوى (زي ده) آمن. في تطبيق معقد، الأحسن تعرض رسالة "في تحديث، اعمل refresh" وتنادي `skipWaiting` لما المستخدم يوافق.

</Box>

## المتصفح بيعرف إن في نسخة جديدة إزاي؟

لما تفتح صفحة في الـ scope، المتصفح بيجيب `sw.js` من السيرفر ويقارنه **بايت ببايت** باللي عنده. أي فرق، حتى حرف في تعليق، يبدأ install للنسخة الجديدة.

<Box type="tip" title="متخليش sw.js يتكاش">

لو السيرفر بيدّي `sw.js` بـ `Cache-Control` طويل، زمان كان ممكن المتصفح ميشوفش التحديث. المتصفحات الحديثة بتتجاهل الـ HTTP cache وهي بتعمل update check للـ `sw.js` نفسه (افتراضي `updateViaCache: "imports"`)، بس خليه يتخدم من غير cache طويل برضه. ولو التنقل بيحصل من غير reload (SPA)، تقدر تنادي `registration.update()` بنفسك.

</Box>
