## مش وثيقة، برنامج

الاختبار برنامج صغير يستدعي كودك ويقارن الناتج بحاجة أنت كاتبها. لو مفيش مقارنة، التشغيل الأخضر مش معناه إن السلوك صح. معناه إن الملف خلّص من غير ما يقع.

<Box type="story" icon="🧾" title="امتحان الفصل">

لو الامتحان من غير إجابات، أي ورقة بتعدي. الاختبار الحقيقي يقول: القائمة الفاضية ترجع صفر. غيّرت الدالة ورجّعت واحد، الامتحان يرسب. الرسب ده هو الفايدة.

</Box>

Node جاي مع مشغّل اختبار من غير حزمة زيادة. الملفين امتدادهما `mjs` عشان `import` يشتغل حتى لو المشروع مش معلّم إنه ES modules.

<File name="total.mjs">

```js
export function total(prices) {
  return prices.reduce((sum, n) => sum + n, 0);
}
```

</File>

<File name="total.test.mjs">

```js
import test from "node:test";
import assert from "node:assert/strict";
import { total } from "./total.mjs";

test("قائمة فاضية", () => {
  assert.equal(total([]), 0);
});

test("يجمع رقمين", () => {
  assert.equal(total([10, 5]), 15);
});
```

</File>

<File name="terminal">

```bash
node --test
```

</File>

`assert.equal` يقارن بـ `===`. لو مختلف، الاختبار يرسب والأمر يطلع بغير صفر. الـ CI مش بيقرا جملة "كل حاجة تمام". بيبص على رقم الخروج.

<Hl c="b">اختبار من غير assert زي بوابة مفتوحة. الأمر أخضر والسلوك ممكن يكون أي حاجة.</Hl>

## إيه اللي يستاهل اختبار هنا؟

مش كل سطر. ابدأ بحاجة لو اتغيرت هتكسر حد: حساب، شرط، تحويل بيانات. شكل الزر ومسافة Prettier مش اختبار. ESLint مش بديل عن اختبار: اللينتر مش هيشوف إن الجمع رجّع رقم غلط.

<Grid2>
<Card title="Jest و Vitest" c={3}>

نفس الفكرة: ملفات اختبار، تأكيدات، وأمر يفشل لو واحد رسب. الفرق واجهة والأدوات اللي حواليها. الفريق يختار واحد ويثبّت أمره في `package.json` عشان الـ CI مناديهوش من الذاكرة.

</Card>
<Card title="الأمر في السكربت" c={5}>

حط `"test": "node --test"` في `scripts`. بعد كده `npm test` على جهازك وعلى السيرفر. تغيير المشغّل يبقى تغيير السكربت، مش تغيير عشرين ملف CI.

</Card>
</Grid2>

<Box type="tip" title="في الـ hook ولا في الـ CI؟">

الاختبار السريع ممكن يخش `pre-commit`، بس مجموعة كبيرة هتخلّي كل commit تقيل والناس تعدّيه بـ `--no-verify`. الفحص الإلزامي للاختبارات مكانه الـ CI. الـ hook يفضل للتنسيق واللنت على الملفات المتعلّمة.

</Box>
