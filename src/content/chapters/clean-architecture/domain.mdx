## إيه اللي يدخل هنا؟

القواعد اللي لو سألت عنها حد في البيزنس (مش developer) هيفهمها:

ومش هيدخل هنا: شكل الـ JSON اللي راجع من الـ API، ولا اسم الـ endpoint، ولا الـ state بتاع الفورم.

## الكود

<File name="src/domain/job.ts">

```ts
export type JobStatus = "draft" | "published" | "closed";

export type SalaryRange = { min: number; max: number; currency: "EGP" | "USD" };

export type JobPosting = {
  id: string;
  title: string;
  description: string;
  salary: SalaryRange | null;
  deadline: Date;
  status: JobStatus;
};

export type JobProblem = "missing-title" | "short-description" | "bad-salary" | "past-deadline" | "closed";

/** بترجع كل المشاكل، مش أول واحدة بس، عشان الفورم يعرض كله مرة واحدة */
export function publishProblems(job: JobPosting, now: Date): JobProblem[] {
  const problems: JobProblem[] = [];
  if (job.status === "closed") problems.push("closed");
  if (job.title.trim().length === 0) problems.push("missing-title");
  if (job.description.trim().length < 50) problems.push("short-description");
  if (job.salary && job.salary.min > job.salary.max) problems.push("bad-salary");
  if (job.deadline.getTime() <= now.getTime()) problems.push("past-deadline");
  return problems;
}

export const canPublish = (job: JobPosting, now: Date) => publishProblems(job, now).length === 0;

export const publish = (job: JobPosting): JobPosting => ({ ...job, status: "published" });
```

</File>

لاحظ:

- **مفيش ولا `import`** من بره. TypeScript عادي.
- **دوال pure**: نفس الـ input بيدّي نفس الـ output. حتى الوقت داخل كـ parameter (`now`) بدل `new Date()` جوّاها، عشان التيست يتحكم فيه.
- `publish` بترجع object جديد بدل ما تعدّل القديم. ده بيريّح React والـ stores بعدين.

<Box type="tip" title="ليه مش class؟">

ممكن تكتب الـ entity كـ class فيها methods، وده تمام. الـ types والدوال الصغيرة أخف في الفرونت، وبتتنقل بين الـ worker والسيرفر والـ store من غير مشاكل serialization. اختار اللي يناسب الفريق، المهم إن مفيش اعتماد على حاجة بره.

</Box>

## 🧪 Lab: اختبار من غير متصفح

<File name="src/domain/job.test.ts">

```ts
import { describe, expect, it } from "vitest";
import { publishProblems, type JobPosting } from "./job";

const now = new Date("2026-10-01");
const job: JobPosting = {
  id: "j1",
  title: "Senior Front-End Engineer",
  description: "x".repeat(60),
  salary: { min: 40000, max: 60000, currency: "EGP" },
  deadline: new Date("2026-11-01"),
  status: "draft",
};

describe("publishProblems", () => {
  it("accepts a complete job", () => {
    expect(publishProblems(job, now)).toEqual([]);
  });

  it("reports every problem at once", () => {
    const bad = { ...job, title: " ", salary: { ...job.salary!, min: 90000 } };
    expect(publishProblems(bad, now)).toEqual(["missing-title", "bad-salary"]);
  });
});
```

</File>

التيست ده بيخلص في **ميلي ثانية**: مفيش jsdom، ولا render، ولا mock لـ `fetch`. ده أول مكسب حقيقي من الفصل.

<Box type="warn" title="الـ domain مش مكان لكل الـ validation">

"الإيميل لازم فيه @" ده validation شكلي، مكانه الفورم أو schema زي zod عند الحدود. "المرشح مينفعش يتنقل لمرحلة الإنترفيو قبل ما الـ CV يتراجع" دي قاعدة بيزنس، ومكانها الـ domain.

</Box>
