## الـ adapter بيترجم

الـ API بيكلمك بلغته: `snake_case`، وتواريخ كـ string، و `salary_min` و `salary_max` مفرودين. الـ domain بيتكلم بلغته. الـ adapter هو **المترجم** في النص.

```ts
import type { JobPosting } from "../domain/job";
import type { JobRepository } from "../application/ports";

/** شكل الرد زي ما الـ backend بيبعته: ده سر الـ adapter، محدش بره يعرفه */
type JobDto = {
  id: string;
  title: string;
  description: string;
  salary_min: number | null;
  salary_max: number | null;
  currency: "EGP" | "USD";
  deadline_at: string;
  state: "DRAFT" | "LIVE" | "CLOSED";
};

const STATUS = { DRAFT: "draft", LIVE: "published", CLOSED: "closed" } as const;
const STATE = { draft: "DRAFT", published: "LIVE", closed: "CLOSED" } as const;

function toJob(dto: JobDto): JobPosting {
  return {
    id: dto.id,
    title: dto.title,
    description: dto.description,
    salary: dto.salary_min !== null && dto.salary_max !== null
      ? { min: dto.salary_min, max: dto.salary_max, currency: dto.currency }
      : null,
    deadline: new Date(dto.deadline_at),
    status: STATUS[dto.state],
  };
}

function toDto(job: JobPosting): JobDto {
  return {
    id: job.id,
    title: job.title,
    description: job.description,
    salary_min: job.salary?.min ?? null,
    salary_max: job.salary?.max ?? null,
    currency: job.salary?.currency ?? "EGP",
    deadline_at: job.deadline.toISOString(),
    state: STATE[job.status],
  };
}

export class HttpJobRepository implements JobRepository {
  constructor(private baseUrl: string) {}

  async getById(id: string) {
    const res = await fetch(`${this.baseUrl}/jobs/${id}`);
    if (res.status === 404) return null;
    if (!res.ok) throw new Error(`GET /jobs/${id} failed: ${res.status}`);
    return toJob(await res.json());
  }

  async save(job: JobPosting) {
    const res = await fetch(`${this.baseUrl}/jobs/${job.id}`, {
      method: "PUT",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(toDto(job)),
    });
    if (!res.ok) throw new Error(`PUT /jobs/${job.id} failed: ${res.status}`);
  }
}
```

</File>

<Box type="tip" title="الـ mapper هو صمام الأمان">

لما الـ backend يغيّر `state` لـ `status`، أو يرجّع التاريخ بـ timestamp، التعديل في **ملف واحد** هو الـ adapter. الـ domain والـ use cases والشاشات مش هيحسوا. ولو عايز تتأكد من شكل الرد وقت التشغيل، حط zod هنا عند الحدود.

</Box>

## نفس الـ port، adapters مختلفة

<File name="src/infrastructure/inMemoryJobRepository.ts">

```ts
import type { JobPosting } from "../domain/job";
import type { JobRepository } from "../application/ports";

export class InMemoryJobRepository implements JobRepository {
  private jobs: Map<string, JobPosting>;

  constructor(seed: JobPosting[] = []) {
    this.jobs = new Map(seed.map((j) => [j.id, j]));
  }

  async getById(id: string) {
    return this.jobs.get(id) ?? null;
  }

  async save(job: JobPosting) {
    this.jobs.set(job.id, job);
  }
}
```

<Box type="story" icon="🧑‍💼" title="المترجم في الاجتماع">

الشركة (الـ domain) بتتكلم عربي. العميل (الـ API) بيتكلم ألماني. المترجم (الـ adapter) واقف في النص. لو جه عميل فرنساوي، بتجيب مترجم فرنساوي، والشركة متتعلمش لغة جديدة.

</Box>

<Box type="warn" title="الـ adapter ميتخذش قرارات بيزنس">

لو لقيت نفسك كاتب `if (job.salary.min > job.salary.max)` جوه الـ adapter، يبقى القاعدة دي هربت من الـ domain. الـ adapter بيترجم ويتعامل مع الشبكة والأخطاء التقنية بس.

</Box>
