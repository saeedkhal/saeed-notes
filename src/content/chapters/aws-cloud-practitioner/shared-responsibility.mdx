## 🧠 افهم: «إحنا على AWS، يبقى الأمان عليهم»؟

عم حسن قرا إن AWS عندها شهادات أمان عالمية، فافتكر إن دُكّان بقى آمن أوتوماتيك. بعد أسبوع، bucket فيه فواتير الزباين بقى مفتوح للإنترنت لأن حد اختار `public` بالغلط.

مين الغلطان؟ **دُكّان.** AWS أمّنت المبنى والأجهزة والشبكة اللي تحت، لكن **إعدادات الـ bucket** دي شغل العميل.

<Hl c="b">AWS مسؤولة عن أمان الـ cloud نفسها (Security OF the cloud). وإنت مسؤول عن أمان اللي إنت حاطه جوه الـ cloud (Security IN the cloud).</Hl>

<Box type="story" icon="🏢" title="شقة في كومباوند">

إدارة الكومباوند مسؤولة عن **السور والبوابة والأمن على الباب والكهربا والأسانسير**. إنت مسؤول عن **قفل باب شقتك، ومين معاه نسخة من المفتاح، والحاجات اللي جوه**.

لو سبت الباب مفتوح والحاجة اتسرقت، الكومباوند مش غلطان. ولو السور وقع، دي مش غلطتك.

</Box>

## 👀 تخيّل: الخط بيتحرك حسب الخدمة

كل ما الخدمة تبقى «مُدارة» (managed) أكتر، AWS بتشيل طبقات أكتر، والخط بيطلع لفوق:

| الطبقة | EC2 | RDS | Lambda |
| --- | --- | --- | --- |
| المباني والأجهزة والشبكة العالمية | AWS | AWS | AWS |
| الـ virtualization | AWS | AWS | AWS |
| نظام التشغيل وpatches | **إنت** | AWS | AWS |
| الـ database engine وpatches | **إنت** (لو ركّبتها) | AWS | — |
| الـ runtime | **إنت** | — | AWS |
| كود التطبيق | **إنت** | **إنت** | **إنت** |
| الداتا والتشفير | **إنت** | **إنت** | **إنت** |
| IAM ومين يدخل | **إنت** | **إنت** | **إنت** |
| الـ firewall (Security Groups) | **إنت** | **إنت** | **إنت** (لو جوه VPC) |

## 🔍 من جوه: التلات أنواع controls

### Inherited controls — بتورثها من AWS

حاجات AWS بتعملها كاملة وإنت بتستفيد منها: الأمن الفعلي للمباني، الكهربا، التبريد، تدمير الهاردات القديمة.

### Shared controls — كل واحد في طبقته

نفس الموضوع، بس كل طرف ليه حتة:

- **Patch management:** AWS بتصلّح الـ infrastructure، وإنت بتصلّح نظام التشغيل والتطبيقات اللي عليك (في EC2).
- **Configuration management:** AWS بتظبط أجهزتها، وإنت بتظبط الـ OS والـ databases والتطبيقات بتاعتك.
- **Awareness & training:** AWS بتدرّب موظفينها، وإنت بتدرّب موظفينك.

### Customer-specific — عليك إنت بس

حاجات AWS متقدرش تعملها عنك لأنها متعرفش شغلك: مين من الموظفين يشوف الداتا، تصنيف الداتا (حساسة ولا عادية)، الـ network zones جوه شبكتك.

### إزاي تثبت إن AWS عاملة اللي عليها؟

**AWS Artifact**: بوابة مجانية في الـ console فيها تقارير الـ compliance بتاعة AWS (زي SOC وISO وPCI) واتفاقيات زي BAA. لو مراجع حسابات سألك «إثبت إن الداتا سنتر آمن»، بتنزّل التقرير من هنا.

<Box type="warn" title="Artifact مش بيفحص تطبيقك">

تقرير SOC بيقول إن **AWS** عاملة شغلها. مش بيقول إن **دُكّان** آمن. أمان دُكّان عليك إنت تثبته.

</Box>

## 🛠️ طبّق: قسّم مسؤوليات دُكّان

الـ Lab ورقي. دُكّان بيستخدم: EC2 للموقع، RDS للطلبات، S3 للصور، Lambda لإرسال إيميلات.

لكل مشكلة، اكتب **مين مسؤول** و**أول خطوة**:

| المشكلة | المسؤول | أول خطوة |
| --- | --- | --- |
| ثغرة في Linux على سيرفر الموقع | دُكّان (EC2 = IaaS) | patch، أو استخدم Systems Manager Patch Manager (فصل ٣٢) |
| ثغرة في PostgreSQL engine على RDS | AWS بتعمل الـ patch | دُكّان بيختار maintenance window مناسب |
| bucket الفواتير مفتوح للعامة | دُكّان | فعّل Block Public Access |
| هارد قديم في الداتا سنتر محتاج يتدمّر | AWS | — (inherited) |
| مكتبة npm فيها ثغرة في كود الـ Lambda | دُكّان | حدّث المكتبة |
| موظف ساب الشغل ولسه عنده access | دُكّان | امسح الهوية أو عطّلها |
| مراجع عايز تقرير PCI للداتا سنتر | AWS تقدّمه | نزّله من AWS Artifact |

**قاعدة تحل بيها أي سؤال:** اسأل «الحاجة دي **أنا** اللي بظبطها ولا AWS؟». لو إنت اللي بتختار الإعداد أو بتكتب الكود أو بتحط الداتا، يبقى عليك.

## ⚖️ قارن: AWS ولا العميل؟

| AWS (OF the cloud) | العميل (IN the cloud) |
| --- | --- |
| المباني والأمن الفعلي | الداتا وتصنيفها |
| الهاردوير والشبكة العالمية | IAM: users وroles وpolicies |
| الـ virtualization (hypervisor) | تشفير الداتا (تفعيله واختيار المفاتيح) |
| الـ Regions والـ AZs والـ edge | Security Groups وإعدادات الشبكة |
| نظام التشغيل في الخدمات المُدارة (RDS، Lambda) | نظام التشغيل في EC2 |
| تقارير compliance للبنية | compliance للتطبيق بتاعك |

<Box type="interview" title="كلمات تمسكها في السؤال">

«physical»، «hardware»، «facilities»، «hypervisor»، «global infrastructure» ← **AWS**.
«customer data»، «IAM»، «guest OS على EC2»، «security group»، «encryption settings»، «application» ← **العميل**.

</Box>
