## المثال الأول: متجر في 3 قارات

الـ origin في Frankfurt، وصورة المنتج حجمها `1.8 MB`. مستخدم القاهرة يشوف أول تحميل في `420 ms`، والمطلوب أقل من `150 ms` للصور المتكررة، مع تحويل لو الـ Region الأساسية فشلت.

١. `Route 53` يحل `shop.example.com` إلى CloudFront distribution.
٢. CloudFront edge تستقبل الطلب؛ cache hit ترجع الصورة من مكان قريب.
٣. cache miss تذهب للـ origin، تحفظ response حسب cache policy، ثم ترجعها.
٤. health/routing strategy تتعامل مع origin أو Region failure حسب architecture.

## Route 53: DNS وقرارات توجيه

Route 53 تدير records وhealth checks وسياسات:

- Simple لوجهة عادية.
- Weighted لتوزيع `95/5` في canary مثلًا.
- Latency-based لاختيار Region بأقل latency قياسية.
- Failover لـ primary/secondary مع health evaluation.
- Geolocation لقرار حسب موقع المستخدم.

DNS لا ينقل ملف ولا يضمن instant failover؛ resolvers قد تحتفظ بالإجابة حسب TTL، والـ health check لازم يقيس حاجة تمثل صحة التطبيق.

## CloudFront: cache وسياسة محتوى

`CloudFront` CDN للـ HTTP/HTTPS. cache key وTTL وheaders/cookies/query strings بيحددوا hit ratio وصحة المحتوى. لو ضفت user token كامل للـ cache key بلا داعٍ، hit ratio ممكن ينهار؛ ولو cached response خاص غلط، ممكن تعمل data exposure.

Edge location نقطة حضور لخدمات edge، مش Region كاملة لتشغيل أي AWS service.

## Global Accelerator

`AWS Global Accelerator` يوفّر static anycast IPs ويوجه TCP/UDP إلى healthy regional endpoints عبر شبكة AWS العالمية. لا يعمل content cache.

## Production incident

- `18:00`: release تضبط TTL للصورة على `24 ساعة` رغم إن الأسعار مضمّنة داخل الصورة.
- `18:20`: origin اتصلح، لكن edge ما زالت تعرض النسخة القديمة.
- الحل: versioned filenames أفضل للمحتوى المتغير، أو invalidation مدروسة؛ invalidations والـ cache policy لهم تكلفة وأثر تشغيل.

<Hl c="y">Route 53 يحل الاسم، CloudFront يكيّش ويوزع HTTP، وGlobal Accelerator يحسن مسار TCP/UDP.</Hl>

## 🧪 تمرين: اختار واثبت

عندك static images، API personalized لا تُكيّش، ولعبة realtime UDP في Regions متعددة. ارسم flow لكل واحد، وحدد TTL/cache key، وفشل Region الساعة `10:00`. اكتب إمتى المستخدمين يتحولوا، وإيه اللي ممكن يتأخر بسبب DNS caching.
