## 🧠 افهم: من الاسم للصورة

الزبون بيكتب `dukkan.example` في المتصفح. علشان الصفحة تفتح بسرعة لازم حاجتين:

1. **حد يترجم الاسم لعنوان:** المتصفح مش فاهم أسامي، فاهم IPs. ده شغل **DNS**، وعلى AWS اسمه **Amazon Route 53**.
2. **المحتوى يبقى قريب من الزبون:** لو الصور في فرانكفورت والزبون في أسوان، كل صورة بتسافر. **Amazon CloudFront** بيحتفظ بنسخ في **edge locations** قريبة من الناس.

<Hl c="g">Route 53 = دليل التليفونات: بيقول الاسم ده عنوانه إيه، وممكن يختار العنوان حسب مكان الزبون أو صحة السيرفر. CloudFront = فروع صغيرة قريبة من الزبون فيها نسخ من المحتوى.</Hl>

<Box type="story" icon="📞" title="دليل التليفونات والكشك">

- **Route 53** زي **الاستعلامات**: تسأله «رقم دُكّان كام؟» فيديك الرقم. والاستعلامات الشاطرة تقولك «فرع مدينة نصر أقرب ليك» أو «فرع المعادي مقفول النهارده، كلّم الزمالك».
- **CloudFront** زي إن دُكّان يحط **كشك صغير في كل حي** فيه أكتر الحاجات اللي بتتطلب. لو طلبت حاجة مش في الكشك، الكشك يجيبها من المخزن الكبير ويحتفظ بنسخة للي بعدك.

</Box>

## 🔍 من جوه: Route 53 وCloudFront وGlobal Accelerator

### Route 53

- **Domain registration:** تشتري الدومين نفسه.
- **Hosted zone:** المكان اللي فيه records الدومين.
- **Records:** `A` (اسم ← IPv4)، `AAAA` (← IPv6)، `CNAME` (اسم ← اسم تاني)، و**Alias** (خاص بـ AWS: يشاور على ALB أو CloudFront أو S3، وينفع على الدومين الرئيسي).
- **Health checks:** بيراقب الـ endpoint، ولو وقع يبطّل يرجّعه.

### Routing policies

| الـ policy | بتختار إزاي | مثال لدُكّان |
| --- | --- | --- |
| Simple | عنوان واحد | موقع صغير |
| Weighted | نسب | ١٠٪ من الزباين على النسخة الجديدة (canary) |
| Latency | الـ Region الأسرع للزبون | نسخة في أوروبا ونسخة في الخليج |
| Failover | primary، ولو وقع secondary | موقع احتياطي في Region تانية |
| Geolocation | حسب بلد أو قارة الزبون | محتوى وأسعار مختلفة لكل بلد |
| Geoproximity | حسب المسافة مع إمكانية تحريك الحدود | توزيع حمل بين Regions |
| Multivalue answer | كذا عنوان سليم | توزيع بسيط مع health checks |

### CloudFront

- **CDN** بيستخدم مئات الـ edge locations.
- **Origins:** S3، ALB، EC2، أو أي HTTP server.
- **Cache behaviors:** قواعد حسب الـ path (`/images/*` يتكيّش يوم، `/api/*` ميتكيّشش).
- **OAC (Origin Access Control):** يخلّي الـ S3 bucket **private**، وCloudFront بس هو اللي يقرا منه.
- HTTPS مجاني بشهادة من **AWS Certificate Manager**، وحماية **Shield Standard** تلقائي، وتقدر تربط **WAF** (فصل ٣١).
- **CloudFront Functions** و**Lambda@Edge** لكود صغير بيشتغل على الـ edge.

### AWS Global Accelerator

بيديك **٢ static IPs (anycast)** ثابتين عالميًا، والترافيك بيدخل شبكة AWS من أقرب edge ويمشي جواها لحد الـ Region. **مبيعملش caching.** مناسب لـ TCP/UDP (ألعاب، VoIP)، أو لما محتاج IPs ثابتة، أو failover سريع بين Regions.

## 🛠️ طبّق: CloudFront قدام صور دُكّان

⚠️ CloudFront ليه Free Tier شهري للـ data transfer والطلبات، والتجربة دي صغيرة. الـ distribution بياخد دقايق عشان يتعمل ويتمسح.

1. **عندك bucket** من فصل ١٧ فيه `products/bread.jpg`، والـ Block Public Access **مفعّل**.
2. **`CloudFront` ← `Create distribution`:**
   - Origin: الـ S3 bucket.
   - Origin access: **Origin access control settings (recommended)** ← `Create new OAC`.
   - Viewer protocol policy: `Redirect HTTP to HTTPS`.
3. بعد الإنشاء، CloudFront هيقولك **انسخ الـ bucket policy** وحطها في الـ bucket. الـ policy دي بتسمح لـ CloudFront (الـ distribution دي بس) يقرا.
4. افتح `https://<xxxx>.cloudfront.net/products/bread.jpg`.
   **المتوقع:** الصورة تفتح. ولو فتحت لينك S3 المباشر: `AccessDenied`.
5. **شوف الـ cache:** افتح Developer Tools ← Network ← اعمل refresh مرتين. في الـ response header `x-cache` هتلاقي أول مرة `Miss from cloudfront`، وبعدها `Hit from cloudfront`.

🧹 **تنضيف:** `Disable` للـ distribution، استنى لحد ما تخلص، وبعدين `Delete`. ورجّع الـ bucket policy زي ما كانت.

## ⚖️ قارن: التلاتة اللي بيتلخبطوا

| | Route 53 | CloudFront | Global Accelerator |
| --- | --- | --- | --- |
| بيعمل إيه | DNS: اسم ← عنوان | CDN: caching على الـ edge | static IPs + طريق سريع في شبكة AWS |
| بيكيّش؟ | لأ | **أيوه** | لأ |
| Protocols | DNS | HTTP/HTTPS | TCP/UDP |
| مناسب لـ | دومينات، توجيه بين Regions، failover | مواقع وصور وفيديو وAPIs | ألعاب، IoT، IPs ثابتة، failover سريع |

<Box type="interview" title="الكلمات المفتاحية">

«domain registration»، «DNS»، «routing policy»، «latency-based routing» ← **Route 53**.
«CDN»، «cache static content at edge locations»، «reduce latency for global users» ← **CloudFront**.
«static IP addresses»، «non-HTTP (UDP)»، «improve availability & performance using AWS global network» ← **Global Accelerator**.

</Box>
