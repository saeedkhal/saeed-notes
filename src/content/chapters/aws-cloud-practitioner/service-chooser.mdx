## Requirement كامل قبل اسم الخدمة

E-commerce محتاج 3,000 requests/sec، p95 أقل من 300ms، RTO 30m، RPO 5m، PCI scope محدود، وbudget `$25k/month`.

1. `Route 53` للـ DNS وhealth routing.
2. `CloudFront + WAF` للـ cache وحماية web patterns.
3. `ALB` يوزع على `ECS/Fargate` متعدد AZs.
4. `Aurora/RDS Multi-AZ` للـ relational data والتوفر؛ read replicas لو القراءة bottleneck.
5. `SQS` يفصل order intake عن workers؛ `SNS` لو event لازم يروح لعدة subscribers.
6. `Secrets Manager + KMS` للأسرار والمفاتيح.
7. `CloudWatch` للمراقبة، `CloudTrail` للـ API audit، وConfig للحالة والcompliance.

الاختيار ينجح لو يحقق latency والتوفر والاسترجاع والتكلفة. إضافة خدمات أكتر من غير requirement تزود complexity ومش تعتبر إجابة أحسن.

## أسئلة الاختيار

### Compute

تحكم في OS → `EC2`. Function قصيرة event-driven → `Lambda`. Containers AWS-native → `ECS`، Kubernetes → `EKS`، compute بلا إدارة nodes → `Fargate`. نشر app مُدار → `Elastic Beanstalk` أو `App Runner` حسب القيود.

### Storage وdatabase

Object → `S3`؛ block لـ EC2 → `EBS`؛ shared Linux files → `EFS`؛ specialized/Windows files → `FSx`. Relational → `RDS/Aurora`؛ key-value/document low latency → `DynamoDB`؛ cache → `ElastiCache`؛ warehouse → `Redshift`.

Multi-AZ للتوفر/failover؛ read replica للتوسع في القراءة. S3 مش POSIX file system، وRedshift مش OLTP database.

### Networking وintegration

DNS → Route 53؛ CDN → CloudFront؛ load distribution → ELB؛ managed API front door → API Gateway. VPN اتصال encrypted عبر الإنترنت؛ Direct Connect وصلة private dedicated. SQS queue، SNS pub/sub، EventBridge event routing.

### Security وoperations

IAM للـ workforce/AWS access، Cognito لمستخدمي التطبيق. KMS keys، Secrets Manager secrets، ACM certificates. WAF web attacks، Shield DDoS، GuardDuty threats، Inspector vulnerabilities، Macie sensitive S3 data، Security Hub aggregation.

CloudWatch metrics/logs/alarms؛ CloudTrail API actions؛ Config configuration/compliance؛ Systems Manager fleet؛ Health AWS events؛ Trusted Advisor recommendations؛ Organizations accounts/SCPs؛ Control Tower landing zone.

### Data وmigration والتكلفة

Athena SQL على S3؛ Glue catalog/ETL؛ EMR Spark؛ Kinesis streaming؛ QuickSight BI؛ OpenSearch search. Bedrock foundation models؛ SageMaker AI custom ML.

Evaluator assessment؛ AWS Transform planning الحالي؛ MGN rehost؛ DMS database/CDC؛ Schema Conversion schema؛ DataSync files؛ Transfer Family SFTP؛ Storage Gateway hybrid.

Calculator estimate؛ Explorer analysis؛ Budgets alerts؛ CUR 2.0 details. راجع caveats أكتوبر ٢٠٢٦: Migration Hub للعملاء الحاليين، Snow Family غير متاح تجاريًا لعملاء جدد، وخطط Support القديمة في انتقال.

## Incident لاختبار الاختيار

CPU طبيعي لكن latency 4s: ابدأ CloudWatch ثم X-Ray، مش تزود EC2 تلقائيًا. مين غيّر SG: CloudTrail، مش Config وحده. SG كان compliant إمتى: Config. نفس كلمة "monitor" لا تكفي؛ حدد السؤال.

## 🧪 Lab ورقي

صمم media upload: 5 GB files، processing async، global download، metadata relational، RTO ساعة. اختار خدمة لكل hop واكتب بديل قريب وليه اترفض.
