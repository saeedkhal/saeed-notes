## 🧠 افهم: السؤال بيديك الإجابة

أغلب أسئلة CLF-C02 شكلها: «شركة عايزة X. أنسب خدمة؟». والـ ٤ اختيارات غالبًا خدمات **حقيقية وقريبة من بعض**. يعني الحفظ لوحده مش كفاية، لازم **تفرّق**.

السؤال دايمًا فيه **كلمة أو اتنين** بيحسموا: «serverless»، «audit»، «stateless»، «SQL على S3»، «dedicated»، «DDoS». لو مسكتهم، الإجابة بتبان.

<Hl c="y">٣ خطوات: (١) لاقي الكلمة اللي بتحسم، (٢) حدد الفئة (compute، storage، security…)، (٣) استبعد الخدمات اللي بتحل سؤال تاني.</Hl>

<Box type="story" icon="🔎" title="المحقق">

المحقق مش بيخمّن المجرم من الأول. بيدوّر على **دليل** (الكلمة المفتاحية)، يحدد **الدايرة** (أهل البيت ولا الجيران؟)، وبعدين **يستبعد** اللي كان في مكان تاني وقت الحادثة.

</Box>

## 🔍 من جوه: الخريطة بالفئات

### Compute

| لو السؤال بيقول | الخدمة |
| --- | --- |
| تحكم كامل في الـ OS، سيرفر افتراضي | EC2 |
| كود من غير سيرفرات مع events، أقل من ١٥ دقيقة | Lambda |
| containers من غير سيرفرات | Fargate |
| Kubernetes | EKS |
| ارفع الكود والمنصة تعمل الباقي | Elastic Beanstalk |
| سعر شهري ثابت وبسيط | Lightsail |
| batch jobs كتير | AWS Batch |

### Storage

| لو السؤال بيقول | الخدمة |
| --- | --- |
| objects، صور، backups، data lake، static website | S3 |
| أرشيف رخيص جدًا | S3 Glacier (Deep Archive) |

| فولدر مشترك Linux | EFS |
| file share Windows/SMB | FSx for Windows |
| HPC file system | FSx for Lustre |

### Databases

| لو السؤال بيقول | الخدمة |
| --- | --- |
| relational مُدارة | RDS |

| NoSQL key-value serverless | DynamoDB |
| cache | ElastiCache |
| data warehouse | Redshift |
| graph | Neptune |
| MongoDB compatible | DocumentDB |

### Networking

## ⚖️ قارن: أشهر ١٠ أزواج بتتلخبط

| الزوج | افتكر |
| --- | --- |
| CloudWatch ↔ CloudTrail | **صحة** ← Watch. **مين عمل** ← Trail |
| Security Group ↔ NACL | instance + **stateful** ← SG. subnet + **stateless** + deny ← NACL |
| SQS ↔ SNS | **طابور** يسحب منه واحد ← SQS. **ميكروفون** للكل ← SNS |
| Multi-AZ ↔ Read replica | **availability** ← Multi-AZ. **scale قراية** ← replica |
| WAF ↔ Shield | **محتوى HTTP** ← WAF. **حجم DDoS** ← Shield |
| GuardDuty ↔ Inspector | **سلوك** ← GuardDuty. **ثغرة** ← Inspector |
| Athena ↔ Redshift | **SQL على S3 متقطع** ← Athena. **warehouse** ← Redshift |
| VPN ↔ Direct Connect | **إنترنت مشفّر وسريع التجهيز** ← VPN. **خط خاص ثابت** ← DX |
| Polly ↔ Transcribe | **نص ← صوت** ← Polly. **صوت ← نص** ← Transcribe |
| Savings Plans ↔ Capacity Reservation | **خصم** ← SP. **ضمان سعة** ← CR |
