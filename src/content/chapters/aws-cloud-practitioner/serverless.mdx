## 🧠 افهم: ليه أدفع على سيرفر صاحي ونايم؟

دُكّان محتاج يصغّر كل صورة منتج بعد ما تترفع. ده بيحصل ٢٠٠ مرة في اليوم، وكل مرة ٢ ثانية. يعني **٧ دقايق شغل في اليوم**. لو حطيته على EC2 شغال ٢٤ ساعة، هتدفع على ٢٣ ساعة و٥٣ دقيقة فاضيين، وهتعمل patches لسيرفر مبيعملش حاجة.

**AWS Lambda** بتقلب الفكرة: إنت بترفع **function**، وAWS بتشغّلها **بس لما حدث يحصل** (صورة اترفعت، request جه، رسالة وصلت)، وبعدين بتنام. بتدفع على **عدد المرات** و**مدة التشغيل** بالمللي ثانية.

<Hl c="o">Serverless مش معناها مفيش سيرفرات. معناها إن السيرفرات مش شغلتك: AWS بتجهّزها وتعملها scale وpatches، وإنت بتكتب الكود وبتدفع على الاستخدام.</Hl>

<Box type="story" icon="🔔" title="الجرس والجرسون">

مطعم فيه **جرسون واقف جنب كل ترابيزة طول اليوم** حتى لو فاضية: ده EC2.
مطعم فيه **جرس على كل ترابيزة**: لما الزبون يضغط، جرسون ييجي، ياخد الطلب، ويمشي. لو ١٠٠ زبون ضغطوا مع بعض، ييجي ١٠٠ جرسون. ولو محدش ضغط، محدش بيقبض: ده Lambda.

بس أول مرة الجرس يرن في الصبح، الجرسون بياخد ثانية زيادة عشان يلبس: ده الـ **cold start**.

</Box>

1. الموبايل بيبعت request لـ **API Gateway**: الباب الأمامي اللي بيستقبل HTTP، ويتأكد من الـ auth، ويحدد عدد الطلبات المسموح (throttling).
2. API Gateway بيحوّل الـ request لـ **event** ويصحّي **Lambda**.
3. الـ function بتكتب الطلب في الـ database بصلاحيات الـ **execution role** بتاعتها.
4. أي `console.log` بيروح لـ **CloudWatch Logs** أوتوماتيك.

## 🔍 من جوه: إزاي Lambda بتشتغل

### الحاجات الأساسية

- **Event source:** مين بيصحّي الـ function؟ API Gateway، S3، SQS، EventBridge (جدول زمني)، DynamoDB Streams، وغيرهم.
- **Execution role:** الـ IAM role اللي الـ function بتشتغل بيها. least privilege هنا مهم.
- **Memory:** من `128 MB` لحد `10 GB`، والـ CPU بيزيد مع الـ memory.
- **Timeout:** أقصى مدة للتشغيل الواحد **١٥ دقيقة**.
- **Runtimes:** Node.js، Python، Java، .NET، Ruby، أو container image، أو custom runtime.

### Scaling والـ concurrency

كل request في نفس اللحظة بياخد نسخة منفصلة من الـ function. ١٠٠ طلب مع بعض = ١٠٠ نسخة شغالة. في حد للحساب (account concurrency quota) قابل للزيادة، وتقدر تحجز concurrency لـ function مهمة.

### Cold start

أول مرة (أو بعد فترة سكون) AWS بتجهّز بيئة جديدة وتحمّل الكود، فالطلب ده بياخد وقت زيادة. للحالات الحساسة في **Provisioned Concurrency** بيخلّي نسخ جاهزة دايمًا (وبتدفع عليها).

### بتدفع على إيه؟

**عدد الـ requests** + **المدة × الـ memory** (GB-seconds). في Free Tier شهري لـ Lambda بعدد requests ومدة. راجع صفحة الأسعار للأرقام الحالية.

<Box type="warn" title="Lambda مش لكل حاجة">

شغل أطول من ١٥ دقيقة، أو process لازم يفضل صاحي ومحتفظ بحالة في الذاكرة، أو حمل ثابت عالي جدًا ٢٤ ساعة، غالبًا هيبقى أنسب وأرخص على containers أو EC2.

</Box>

## 🛠️ طبّق: endpoint يرجّع منتجات دُكّان

⚠️ Lambda وAPI Gateway ليهم Free Tier شهري، والـ Lab ده هيستهلك كام request بس.

1. **`Lambda` ← `Create function`** ← `Author from scratch` ← الاسم `dukkan-products` ← Runtime `Node.js` (أحدث إصدار متاح).
2. الصق الكود ده في `index.mjs` واضغط **Deploy**:

<File name="index.mjs">

```js
// الـ handler بيستقبل الـ event وبيرجّع response
export const handler = async (event) => {
  const products = [
    { id: 1, name: "عيش بلدي", price: 5 },
    { id: 2, name: "جبنة رومي", price: 120 },
  ];
  console.log("request جه", event.requestContext?.http?.method);
  return {
    statusCode: 200,
    headers: { "content-type": "application/json; charset=utf-8" },
    body: JSON.stringify(products),
  };
};
```

</File>

3. **اربط API Gateway:** `Add trigger` ← `API Gateway` ← `Create a new API` ← `HTTP API` ← Security: `Open` (للتجربة بس).
4. افتح الـ **API endpoint** اللي ظهر. **المتوقع:** JSON بالمنتجين.
5. **شوف الـ logs:** تبويب `Monitor` ← `View CloudWatch logs`. هتلاقي سطر «request جه» وكمان سطر `REPORT` فيه `Duration` و`Billed Duration` و`Init Duration` (ده الـ cold start، بيظهر في أول request بس).

🧹 **تنضيف:** امسح الـ API من `API Gateway`، والـ function من `Lambda`، والـ log group من `CloudWatch` لو عايز.

## ⚖️ قارن: Lambda ضد الباقي

| | Lambda | Fargate | EC2 |
| --- | --- | --- | --- |
| بتدير سيرفرات؟ | لأ | لأ | أيوه |
| بيشتغل إمتى؟ | مع الحدث بس | طول ما الـ task شغال | طول ما الـ instance شغالة |
| أطول تشغيل | ١٥ دقيقة | مفيش حد | مفيش حد |
| بتدفع على | requests + مدة × memory | CPU + memory في الثانية | وقت الـ instance |
| بيكبر إزاي؟ | أوتوماتيك لكل request | بالـ service scaling | Auto Scaling group |
| مناسب لـ | events، APIs متقطعة، automation | services دايمة في containers | تحكم كامل |

| API Gateway | Application Load Balancer |
| --- | --- |
| API management: auth، throttling، API keys، stages | توزيع ترافيك HTTP على targets |
| بيتحاسب بالـ request | بيتحاسب بالساعة + الاستخدام |
| مثالي قدام Lambda | مثالي قدام EC2 وcontainers (وممكن Lambda) |
