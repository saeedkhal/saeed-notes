## 🧠 افهم: «عندي شغال، عندك مش شغال»

سارة كتبت موقع دُكّان على Node 22، وعلى اللابتوب بتاعها شغال تمام. على السيرفر Node 18، فالموقع وقع. المشكلة إن **البيئة مختلفة**.

الـ **container** بيحل ده: بتحط التطبيق **ومعاه** كل اللي محتاجه (الـ runtime، المكتبات، الإعدادات) في علبة واحدة اسمها **image**. العلبة دي بتشتغل بنفس الشكل على اللابتوب أو على AWS.

بس لما يبقى عندك ٢٠ container، محتاج حد **يرتبهم**: يشغّلهم، يعيد تشغيل اللي يقع، يوزعهم على الأجهزة، ويزوّدهم وقت الزحمة. ده اسمه **orchestration**.

<Hl c="u">Image بتتخزن في ECR. والـ orchestrator (ECS أو EKS) بيقرر يشغّل كام نسخة وفين. وبتشتغل يا إما على Fargate (من غير سيرفرات) يا إما على EC2 بتديرها إنت.</Hl>

<Box type="story" icon="🚢" title="الحاويات في الميناء">

- **الـ image** = الحاوية المقفولة، جواها البضاعة متغلفة بنفس الشكل. أي مركب يقدر يشيلها.
- **ECR** = المخزن في الميناء اللي الحاويات مستنية فيه.
- **ECS / EKS** = مدير الميناء اللي بيقرر أنهي حاوية تطلع على أنهي مركب، وكام واحدة.
- **Fargate** = إنك تأجر مكان على مركب حد تاني ومتشغلش بالك بالمركب. **EC2** = إنك عندك المراكب بتاعتك وبتصونها.

</Box>

## 🔍 من جوه: المصطلحات بالترتيب

### Amazon ECR (Elastic Container Registry)

مخزن private للـ images، شبه Docker Hub بس جوه حسابك وبصلاحيات IAM. بيعمل **scan** للـ images يدوّر على ثغرات معروفة، وفيه **lifecycle policies** تمسح الـ images القديمة.

### Amazon ECS (Elastic Container Service)

الـ orchestrator بتاع AWS، أبسط لو مش محتاج Kubernetes. مصطلحاته:

- **Task definition:** الوصفة (JSON): أنهي image، كام CPU وmemory، أنهي port، أنهي IAM role، متغيرات البيئة.
- **Task:** نسخة شغالة من الوصفة.
- **Service:** بيقول «عايز دايمًا ٣ tasks شغالين»، ولو واحد وقع بيطلّع بداله، وبيربطهم بالـ Load Balancer.
- **Cluster:** المجموعة المنطقية اللي الـ tasks بتشتغل فيها.

### Amazon EKS (Elastic Kubernetes Service)

**Kubernetes** مُدار. AWS بتدير الـ control plane. مناسب لو الفريق بيستخدم Kubernetes أصلًا أو محتاج يشتغل بنفس الأدوات على أكتر من cloud. أعقد من ECS.

### Fargate ولا EC2؟

<Grid2>
<Card title="Fargate" c={3}>

مفيش سيرفرات تديرها. بتحدد CPU وmemory للـ task وبتدفع عليهم بالثانية. أبسط وأأمن (عزل لكل task).

</Card>
<Card title="EC2 launch type" c={4}>

إنت بتدير الـ instances اللي الـ containers شغالة عليها. تحكم أكتر، ممكن أرخص لحمل كبير وثابت، وتقدر تختار GPU مثلًا.

</Card>
</Grid2>

وفي خدمات أبسط من كده لو عايز ترفع container وبس، زي **AWS App Runner** (راجع الـ docs لحالتها الحالية) أو **Elastic Beanstalk** بيدعم Docker.

## 🛠️ طبّق: شغّل دُكّان في container على Fargate

⚠️ Fargate بيتحاسب بالثانية على الـ CPU والـ memory، والـ ALB بالساعة. خلّص وامسح في نفس القعدة.

1. **ابني الـ image واعمل push لـ ECR:**

```bash
# اعمل repository
aws ecr create-repository --repository-name dukkan-web

# سجّل دخول Docker على ECR (استبدل الـ account والـ region)
aws ecr get-login-password --region eu-central-1 | \
  docker login --username AWS --password-stdin <ACCOUNT_ID>.dkr.ecr.eu-central-1.amazonaws.com

# ابني واعمل tag وpush
docker build -t dukkan-web:1.0 .
docker tag dukkan-web:1.0 <ACCOUNT_ID>.dkr.ecr.eu-central-1.amazonaws.com/dukkan-web:1.0
docker push <ACCOUNT_ID>.dkr.ecr.eu-central-1.amazonaws.com/dukkan-web:1.0
```

لو معندكش تطبيق، اعمل `Dockerfile` فيه سطر واحد `FROM nginx:alpine`.

2. **اعمل cluster:** `ECS` ← `Clusters` ← `Create` ← infrastructure: `AWS Fargate`.
3. **Task definition:** `Create new` ← Fargate ← `0.25 vCPU / 0.5 GB` ← container بالـ image URI من ECR ← port `80`.
4. **Service:** جوه الـ cluster ← `Create service` ← الـ task definition ← desired tasks `2` ← (اختياري) Application Load Balancer جديد.
5. **المتوقع:** في تبويب `Tasks` تلاقي ٢ بحالة `RUNNING`. افتح الـ DNS بتاع الـ ALB (أو الـ public IP للـ task لو مفيش ALB وفاتح port 80).
6. **جرّب:** اعمل `Stop` لـ task يدويًا. الـ service هيطلّع بداله، لأنه وعد بـ ٢.

🧹 **تنضيف:** خلّي الـ service `desired = 0` وامسحه، امسح الـ ALB والـ target group، امسح الـ cluster، وامسح الـ ECR repository (`--force` لو فيه images).

## ⚖️ قارن: مين بيعمل إيه في عالم الـ containers؟

| الخدمة | دورها | سؤالها |
| --- | --- | --- |
| ECR | تخزين الـ images | «الـ image محفوظة فين؟» |
| ECS | orchestration بتاع AWS | «مين بيشغّل ويرتب الـ containers؟» (بسيط) |
| EKS | Kubernetes مُدار | «مين بيشغّل ويرتب؟» (لو Kubernetes) |
| Fargate | مكان تشغيل serverless | «بتشتغل على إيه من غير سيرفرات؟» |
| EC2 | مكان تشغيل تديره | «بتشتغل على سيرفرات بتاعتي» |

| | Containers على Fargate | Lambda |
| --- | --- | --- |
| وحدة النشر | image فيها أي حاجة | function (أو image) |
| المدة | مفيش حد | ١٥ دقيقة |
| شغال إمتى | طول ما الـ service شغال | مع الحدث |
| مناسب لـ | مواقع وservices دايمة | events وشغل متقطع |
