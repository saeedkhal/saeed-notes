## هجرة e-commerce في 90 يوم

الشركة عندها 80 VM وOracle وfile server، والـ checkout لازم downtime أقل من 20 دقيقة.

1. أيام 1–14: `Migration Evaluator` يجمع inventory وutilization ويبني TCO.
2. أيام 15–30: dependencies، landing zone، security وnetworking.
3. يوم 35: pilot من 5 low-risk servers.
4. أيام 40–75: waves من 10–15 server مع test وrollback.
5. يوم 80: database cutover مع replication وvalidation.
6. يوم 90: decommission بعد قبول business، مش فور أول boot.

نسخ كل VM يحقق deadline، لكنه ممكن ينقل waste والمشاكل. إعادة كتابة الكل تقلل legacy لكن غالبًا تفشل deadline. الاختيار workload-by-workload.

## CAF والـ 7 Rs

`AWS CAF` يراجع التحول عبر Business وPeople وGovernance وPlatform وSecurity وOperations. هو framework، مش migration tool.

- **Rehost**: انقل تقريبًا كما هو؛ أسرع، modernization أقل.
- **Replatform**: تعديل محدود، زي database على RDS.
- **Refactor**: redesign cloud-native؛ قيمة أعلى ووقت/مخاطر أكبر.
- **Repurchase**: استبدل بـ SaaS.
- **Relocate**: انقل environment متوافق من غير redesign كبير.
- **Retain**: سيبه مؤقتًا لسبب قانوني أو dependency.
- **Retire**: اقفله بعد إثبات عدم الاستخدام.

مثال: web VM بـ MGN = rehost؛ Oracle إلى RDS بتعديل محدود = replatform؛ monolith إلى event-driven = refactor.

## الأدوات

`Migration Evaluator` للتقييم والـ business case، مش النسخ. `Application Migration Service (MGN)` يعمل continuous block-level replication وtest launch وcutover للـ rehost.

من **٧ نوفمبر ٢٠٢٥**، Migration Hub لا يقبل عملاء جدد؛ العملاء الحاليون يستمروا. `AWS Transform` هو الاتجاه الحالي للتخطيط والتنفيذ والتحديث بقدرات AI، واسم `AWS Transform MGN` قد يظهر. CLF-C02 قد يستخدم الاسم التاريخي؛ راجع docs في أكتوبر ٢٠٢٦.

## نجاح وفشل الـ cutover

لو freeze بدأ 01:00، آخر sync 01:06، validation 01:14، وDNS تحول 01:17، downtime 17 دقيقة: نجح requirement 20m. لو dependency غير مكتشفة عطلت payment لساعة، migration تقنيًا booted لكن business migration فشلت.

لازم acceptance criteria: data reconciliation، latency، security، monitoring، owner sign-off، وrollback deadline.

## 🧪 Lab ورقي

صنف CRM، payroll legacy، web farm، system بلا users، وdatabase حرجة على 7 Rs. اكتب deadline وdowntime وrollback لكل واحد.
