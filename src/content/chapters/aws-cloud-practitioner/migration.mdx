## 🧠 افهم: سلسلة «الأمانة» عايزة تنقل

عم حسن اشترى سلسلة سوبر ماركت قديمة اسمها «الأمانة». عندها data center صغير فيه ٤٠ سيرفر: سيستم مخزون، موقع قديم، إيميل، برنامج حسابات Oracle، وسيرفرات محدش فاكر بتعمل إيه.

النقل لـ AWS مش «انسخ كل حاجة». فيه سؤالين:

1. **الشركة نفسها جاهزة؟** الناس متدربة؟ مين يوافق على الصرف؟ مين مسؤول عن الأمان؟ ← **CAF**
2. **كل تطبيق هنعمل فيه إيه؟** ننقله زي ما هو؟ نحسّنه؟ نرميه؟ ← **الـ 7 Rs**

<Hl c="y">الـ CAF بيجهّز الشركة من ٦ زوايا. والـ 7 Rs بيدّوا كل تطبيق قرار، من «ارميه» لحد «اكتبه من الأول».</Hl>

<Box type="story" icon="📦" title="نقل الشقة">

لما بتنقل شقة، مش كل حاجة بتتنقل زي ما هي:

- **Retire:** الكنبة القديمة؟ ارميها.
- **Retain:** دولاب جدتك؟ يفضل في البيت القديم دلوقتي.
- **Rehost:** التلاجة؟ شيلها زي ما هي وحطها في المطبخ الجديد.
- **Relocate:** نقل كامل للأوضة بنفس الترتيب بالظبط لنفس النوع من الشقق.
- **Replatform:** البوتاجاز؟ غيّر الخرطوم عشان يناسب الغاز الطبيعي، بس هو نفس البوتاجاز.
- **Repurchase:** التلفزيون القديم؟ بيعه واشتري Smart TV.
- **Refactor:** المطبخ كله؟ صممه من الأول بشكل جديد.

</Box>

## 🔍 من جوه: CAF والـ 7 Rs والأدوات

### AWS Cloud Adoption Framework: ٦ perspectives

| الـ perspective | بيسأل | مين بيهتم |
| --- | --- | --- |
| **Business** | الـ cloud هيخدم أهداف الشركة إزاي؟ | الإدارة، المالية |
| **People** | الناس هتتدرب وتتغير أدوارها إزاي؟ | HR، المديرين |
| **Governance** | هنتحكم في المخاطر والصرف إزاي؟ | المخاطر، المالية |
| **Platform** | البنية والمعمارية هتبقى شكلها إيه؟ | المهندسين المعماريين |
| **Security** | هنحمي الداتا والحسابات إزاي؟ | الأمن |
| **Operations** | هنشغّل ونراقب إزاي؟ | فريق التشغيل |

**أول تلاتة (Business، People، Governance) = جانب الأعمال. آخر تلاتة (Platform، Security، Operations) = الجانب التقني.**

### الـ 7 Rs بتعريف سطر

| الـ R | المعنى | مثال |
| --- | --- | --- |
| **Retire** | امسحه، محدش محتاجه | ٦ سيرفرات محدش بيستخدمها |
| **Retain** | خليه مكانه دلوقتي | سيستم هيتغير السنة الجاية، أو قانون |
| **Rehost** (lift-and-shift) | انقله لـ EC2 زي ما هو | سيستم المخزون |
| **Relocate** | انقل الـ virtualization كلها (VMware مثلًا) لـ AWS من غير شراء أجهزة | VMs كتير مرة واحدة |
| **Repurchase** | سيبه واشتري SaaS | الإيميل ← خدمة إيميل SaaS |
| **Replatform** (lift-tinker-and-shift) | تعديل بسيط يكسب ميزة managed | Oracle على سيرفر ← RDS |
| **Refactor / Re-architect** | أعد التصميم cloud-native | الموقع القديم ← containers وserverless |

### أدوات الهجرة

- **Migration Evaluator:** يجمع بيانات السيرفرات واستخدامها، ويعمل **business case** و**TCO** (هنوفر قد إيه).
- **AWS Application Discovery Service:** يكتشف السيرفرات واستخدامها والـ dependencies بينها.
- **AWS Application Migration Service (MGN):** الأداة الأساسية لـ **rehost**: بيعمل replication مستمر للسيرفر، تجرب نسخة test، وبعدين cutover بأقل downtime.
- **AWS Transform:** الاتجاه الحالي من AWS للتخطيط والهجرة والتحديث بمساعدة AI (Windows/.NET، mainframe، VMware…). **Migration Hub** وقف استقبال عملاء جدد من **٧ نوفمبر ٢٠٢٥**، بس ممكن الاسم يظهر في أسئلة الامتحان. راجع الـ docs.
- لنقل الـ databases والملفات: **الفصل الجاي**.

## 🛠️ طبّق: خطة نقل «الأمانة»

الـ Lab ورقي. لكل سيستم اختار R واكتب السبب:

| السيستم | الـ R | السبب |
| --- | --- | --- |
| ٦ سيرفرات مفيش عليها ترافيك من ٦ شهور | **Retire** | توفير فوري |
| سيستم الكاشير في الفروع | **Retain** | لازم يشتغل لو النت فصل |
| سيستم المخزون (Linux قديم) | **Rehost** بـ MGN | سريع، ونحسّنه بعدين |
| ٢٠ VM على VMware | **Relocate** | ننقل كتير بسرعة بنفس الإدارة |
| Mail server | **Repurchase** | ندير إيميل ليه؟ |
| Oracle الحسابات | **Replatform** ← RDS (أو Aurora PostgreSQL لو هنحوّل) | AWS تشيل الـ backups والـ patches |
| الموقع القديم | **Refactor** | محتاج scale رمضان وتطوير سريع |

**بعدين رتّبهم في موجات (waves):** الموجة الأولى Retire وRepurchase (مكسب سريع وتجربة للفريق)، بعدين Rehost، وآخر حاجة Refactor.

**ومن ناحية CAF:** اكتب سؤال واحد لكل perspective لازم يتجاوب قبل ما تبدأ. (People: مين هيتدرب على AWS؟ Governance: مين يوافق على الميزانية؟ …)

## ⚖️ قارن: الـ Rs اللي بتتلخبط

| بيتلخبطوا | الفرق |
| --- | --- |
| Rehost ↔ Replatform | Rehost = **ولا تغيير**. Replatform = **تغيير بسيط** يكسب managed service (DB ← RDS) |
| Replatform ↔ Refactor | Replatform = التطبيق نفسه تقريبًا زي ما هو. Refactor = **إعادة كتابة/تصميم** |
| Rehost ↔ Relocate | Rehost = سيرفرات لـ EC2. Relocate = منصة virtualization كاملة لـ AWS (زي VMware) |
| Retire ↔ Retain | Retire = **امسح**. Retain = **سيب دلوقتي** |
| Repurchase | الوحيد اللي بتسيب فيه التطبيق وتشتري **منتج تاني** (غالبًا SaaS) |

| بيتلخبطوا | الفرق |
| --- | --- |
| CAF ↔ Well-Architected | CAF = جاهزية **الشركة** للتحول. Well-Architected = جودة **workload** معين |
| Migration Evaluator ↔ MGN | Evaluator = **يقيّم** ويعمل business case. MGN = **ينقل** فعلًا |
