## الهجرة برنامج مش زرار

نقل servers من الداتا سنتر لـ AWS جزء واحد. لازم تعرف الهدف، الناس، الحوكمة، الأمان، التشغيل، والتكلفة قبل موجات التنفيذ.

<Box type="story" title="نقل المدرسة">

لو المدرسة هتنقل مبنى، مش هتشيل الديسكات وخلاص. هتعمل جرد، تحدد اللي هيتصلح واللي هيترمي، تجرب فصل واحد، وبعدين تنقل على دفعات. دي روح cloud migration.

</Box>

## الـ 7 Rs

- **Rehost**: lift and shift؛ انقل التطبيق تقريبًا زي ما هو.
- **Replatform**: تعديلات محدودة للاستفادة من خدمة managed.
- **Refactor / re-architect**: غيّر التصميم للاستفادة من cloud-native.
- **Repurchase**: استبدل التطبيق بمنتج SaaS أو منتج مختلف.
- **Relocate**: انقل environment متوافق على مستوى البنية من غير redesign كبير.
- **Retain**: سيبه مكانه دلوقتي لسبب تقني أو قانوني أو تجاري.
- **Retire**: اقفله لأنه ملوش لازمة.

<Box type="idea" title="مثال portal المدرسة">

نقل VM كما هي `rehost`. نقل database من على VM إلى RDS `replatform`. تقسيم التطبيق لخدمات serverless `refactor`. استبداله بمنصة مدارس SaaS `repurchase`.

</Box>

## Migration Evaluator

`Migration Evaluator` يساعد في discovery وassessment وبناء business case وTCO من بيانات البيئة الحالية. يجمع inventory وutilization عشان متقارنش cloud بسعر server مبالغ في حجمه.

هو للتقييم والتخطيط، مش الأداة اللي تنسخ workload النهائي.

## Migration Hub والواقع الحالي

قديمًا، `AWS Migration Hub` كان مكان مركزي لتتبّع الهجرات وأدواتها. من **٧ نوفمبر ٢٠٢٥**، AWS Migration Hub وقف قبول عملاء جدد؛ العملاء الحاليين يقدروا يكملوا.

`AWS Transform` هو الاتجاه الحالي للعملاء الجدد، وبيوفر تخطيط وتنفيذ وتحديث migration بقدرات AI، ومنها توصيات 7 Rs.

<Box type="warn" title="المنهج ممكن يقول الاسم القديم">

CLF-C02 اتكتب قبل تغيير ٢٠٢٥، فممكن مواد الدراسة تقول Migration Hub. افهم وظيفته التاريخية، لكن في قرار حقيقي جديد راجع AWS Transform والـ docs. الخدمات السحابية بتتغير أسرع من بنوك الأسئلة.

</Box>

## Application Migration Service

`AWS Application Migration Service`، واختصارها `MGN`، مخصصة غالبًا لـ rehost servers إلى AWS. تعمل continuous block-level replication لمنطقة staging، تقدر تعمل test launch، وبعد التحقق تعمل cutover.

هي application-agnostic نسبيًا: بتنقل server workload بدل ما تعيد كتابة التطبيق. اسم `AWS Transform MGN` ممكن يظهر في صفحات AWS الأحدث.
