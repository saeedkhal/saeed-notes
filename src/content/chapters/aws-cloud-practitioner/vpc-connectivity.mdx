## Internet Gateway

الـ <En>Internet Gateway (IGW)</En> بيتوصل بالـ VPC ويديها طريق للإنترنت. الـ public subnet تحط في route table بتاعتها `0.0.0.0/0 → IGW`.

ده طريق، مش تصريح شامل. المورد محتاج public IPv4 أو IPv6 مناسب، والـ Security Group لازم تسمح.

## NAT Gateway

سيرفر الـ app في private subnet محتاج ينزّل تحديث، بس مش عايزين الإنترنت يبدأ اتصال ناحيته. <En>NAT Gateway</En> تسمح باتصال خروج وتستقبل الرد المرتبط به.

الـ public NAT Gateway بتتحط في public subnet ولها Elastic IP، والـ private subnet توجه الطريق الافتراضي لها.

</Box>

## Security Group ضد NACL

<Grid2>
<Card title="Security Group" c={3}>

- على مستوى resource أو network interface.
- قواعد **allow فقط**.
- <Hl c="g">Stateful</Hl>: لو الطلب مسموح، الرد مسموح تلقائيًا.
- كل القواعد تتقيّم مع بعض.

</Card>
<Card title="Network ACL" c={4}>

- على مستوى subnet.
- قواعد allow وdeny.
- <Hl c="o">Stateless</Hl>: لازم تسمح للذهاب والرد منفصلين.
- أول rule مطابقة حسب الرقم هي اللي تكسب.

</Card>
</Grid2>

<Box type="story" icon="🛂" title="بواب الفصل وبواب الدور">

Security Group بواب فاكر إن الطالب دخل بإذن، فيسيبه يخرج. NACL بواب الدور مش بيفتكر؛ لازم ورقة للدخول وورقة للخروج.

</Box>

استخدم Security Groups كتحكم أساسي دقيق، وNACL كحاجز subnet إضافي. متتعاملش مع NACL كبديل دائم للـ SG.

## VPC Endpoints

الـ <En>VPC endpoint</En> يخلي مواردك توصل لخدمة مدعومة من غير المرور بالـ public internet أو NAT.

- Gateway endpoints لـ S3 وDynamoDB، ومش مبنية على PrivateLink.
- Interface endpoints بتعمل private network interfaces وبتستخدم AWS PrivateLink.

الـ endpoint مش معناه سماح تلقائي؛ راجع endpoint policy وIAM والـ Security Groups حسب النوع.

## 🧪 تمرين ورقي آمن

ارسم private app عايز S3 وتحديثات عامة. حط طريق S3 على Gateway endpoint، والطريق العام على NAT. اكتب SG تسمح HTTPS خروج، واكتب جنب NACL: "الرد لازم rule".

لو جرّبت في حساب فعلي، راجع تكلفة NAT والـ interface endpoint وامسحهم بعد التجربة. Gateway endpoints لـ S3 وDynamoDB لا تحمل رسمًا بحد ذاتها حاليًا، لكن راجع الـ docs وبيانات الخدمة.

الفصل الجاي هنطلع من حدود الـ VPC للـ DNS والـ edge العالمي.
