## 🧠 افهم: «عندي مشكلة، أكلّم مين؟»

دُكّان قابل مواقف مختلفة في شهر واحد:

1. سؤال عام: «إزاي أعمل Lambda تقرا من SQS؟»
2. الفاتورة فيها رسوم مش فاهمها.
3. **الساعة ٢ الفجر، الـ checkout واقف** والزباين مش عارفين يدفعوا.
4. البنك طلب **تقرير compliance** بتاع AWS.
5. محتاجين **firewall** من شركة معينة.
6. محتاجين **شركة** تساعد في نقل «الأمانة».

كل موقف ليه باب مختلف. ولو استنيت رد مجاني على re:Post والموقع واقف، هتخسر فلوس.

<Hl c="p">مجتمع وdocs = re:Post وKnowledge Center. مشكلة في حسابك = AWS Support (حسب خطتك). تقارير compliance = Artifact. software جاهز = Marketplace. شركة تساعدك = Partner Network أو Professional Services.</Hl>

<Box type="story" icon="🏥" title="لو تعبت">

- **re:Post** = تسأل **صحابك** في الجروب. مجاني، وممكن حد خبير يرد.
- **Knowledge Center** = **الكتيب** اللي فيه أشهر المشاكل وحلولها.
- **Basic Support** = **الاستقبال**: بيساعدك في الحجز والفلوس، مش بيكشف.
- **Business Support+** = **دكتور على التليفون ٢٤ ساعة**.
- **Enterprise** = **دكتور العيلة (TAM)** اللي عارف تاريخك وبيتابعك قبل ما تتعب.

</Box>

## 🔍 من جوه: الخطط والمصادر

### خطط الدعم (نوفمبر ٢٠٢٦)

| الخطة | لمين | أهم حاجة |
| --- | --- | --- |
| **Basic** | كل العملاء، مجانية | دعم الحساب والفواتير وزيادة الـ quotas، الـ docs وre:Post، وفحوصات Trusted Advisor الأساسية، وAWS Health |
| **Business Support+** | production workloads | دعم فني **٢٤/٧**. الحد الأدنى المنشور `$29` للحساب في الشهر أو نسبة من الاستهلاك، أيهما أكبر |
| **Enterprise** | workloads حساسة | **TAM** (Technical Account Manager) مخصص، استجابة أسرع للحالات الحرجة. الحد الأدنى المنشور `$5,000` في الشهر أو نسبة |
| **Unified Operations** | عمليات ضخمة ومعقدة | أعلى مستوى. الحد الأدنى المنشور `$50,000` في الشهر أو نسبة |

<Box type="warn" title="الأسماء القديمة لسه في الامتحان">

الخطط القديمة **Developer** و**Business** و**Enterprise On-Ramp** مقرر ينتهي دعمها **١ يناير ٢٠٢٧** في الـ commercial Regions. امتحان CLF-C02 ممكن يسأل بالأسماء القديمة: **Developer** = ساعات العمل وبالإيميل للتجربة، **Business** = ٢٤/٧ لـ production، **Enterprise On-Ramp** = pool of TAMs، **Enterprise** = TAM مخصص. الأسعار والـ response times بتتغير، فقرار الشراء من الصفحة الرسمية.

</Box>

### مصادر المساعدة

- **AWS re:Post:** مجتمع أسئلة وأجوبة، فيه خبراء من AWS والمجتمع. **متحطش داتا حساسة.**
- **AWS Knowledge Center:** مقالات لأشهر الأسئلة (جوه re:Post).
- **Documentation، Whitepapers، Prescriptive Guidance، Architecture Center:** مراجع رسمية.
- **AWS Skill Builder / Training and Certification:** كورسات وتحضير امتحانات.

### المصادر التانية

- **AWS Artifact:** تقارير **compliance** بتاعة AWS (SOC، ISO، PCI) واتفاقيات (زي BAA). مجاني (فصل ٩).
- **AWS Marketplace:** كتالوج **software** وdata وخدمات من شركات تانية، تشتريه وتشغّله على AWS وفاتورته مع فاتورة AWS.
- **AWS Partner Network (APN):** **شركات** consulting وsoftware معتمدة تساعدك تبني أو تنقل.
- **AWS Professional Services:** فريق من **AWS نفسها** بيشتغل معاك على مشاريع كبيرة.
- **TAM:** في خطة Enterprise، مرشد فني مخصص بيساعدك استباقيًا.
- **AWS Trust & Safety:** لو حد بيستخدم موارد AWS في abuse (spam، هجوم عليك).

## 🛠️ طبّق: افتح case صح

⚠️ فتح case للحساب والفواتير متاح في Basic مجانًا. الـ technical cases محتاجة خطة مدفوعة.

1. **`Support Center` ← `Create case`.** شوف الأنواع المتاحة لخطتك (Account and billing، Service limit increase، Technical).
2. **اكتب case فاتورة نموذجية** (متبعتهاش لو مفيش مشكلة حقيقية):
   - **العنوان:** «رسوم NAT Gateway غير متوقعة في eu-central-1».
   - **التفاصيل:** الفترة، الـ Region، الـ resource IDs، اللي جربته، والـ screenshots. **من غير** باسوردات أو secrets.
3. **حدد الـ severity بأمانة:** «production system down» بس لما يكون فعلًا واقف. الـ response time **هدف للرد الأول**، مش وعد بالحل.
4. **صنّف المواقف الست** من أول الفصل:

| الموقف | الباب |
| --- | --- |
| سؤال Lambda + SQS | re:Post / Knowledge Center / docs |
| رسوم مش مفهومة | Support case (Account and billing)، حتى في Basic |
| الـ checkout واقف ٢ الفجر | Support case حرجة (محتاج Business Support+ أو أعلى) |
| تقرير compliance للبنك | AWS Artifact |
| firewall من شركة معينة | AWS Marketplace |
| شركة تساعد في الهجرة | AWS Partner Network (أو Professional Services) |

## ⚖️ قارن: اللي بيتلخبط

| بيتلخبطوا | الفرق |
| --- | --- |
| re:Post ↔ AWS Support | re:Post = **مجتمع عام** مجاني. Support = **case خاص بحسابك** |
| Artifact ↔ Audit Manager | Artifact = تقارير **AWS** عن نفسها. Audit Manager = يجمع أدلة **لتطبيقك** إنت |
| Marketplace ↔ APN | Marketplace = **منتجات** تشتريها. APN = **شركات** تشتغل معاك |
| APN ↔ Professional Services | APN = شركاء **برّه** AWS. Professional Services = فريق **AWS** |
| TAM ↔ Support engineer | TAM = **مرشد مستمر واستباقي** (Enterprise). المهندس = بيحل **case** معينة |
| Basic ↔ مدفوع | Basic = حساب وفواتير وquotas. **دعم فني** = خطة مدفوعة |
