## 🧠 افهم: سيرفر من غير ما تشتري سيرفر

برنامج المحاسبة بتاع دُكّان محتاج Windows، وإعدادات خاصة، وتحكم كامل. ده محتاج «جهاز». **Amazon EC2 (Elastic Compute Cloud)** بيديك جهاز افتراضي (اسمه **instance**) في دقايق، على أجهزة AWS الحقيقية، وتدفع على وقت تشغيله.

إنت اللي بتختار المواصفات، ونظام التشغيل، ومين يقدر يكلمه. وإنت برضه اللي **مسؤول** عن الـ OS والـ patches والـ software (IaaS، فاكر؟).

<Hl c="p">EC2 instance = جهاز افتراضي. بتطلّعه من قالب (AMI)، بمقاس (instance type)، ورا firewall (Security Group)، وبتدفع طول ما هو شغال.</Hl>

<Box type="story" icon="🚗" title="تأجير عربية">

- **الـ AMI** = موديل العربية بالتجهيزات اللي جواها (نظام التشغيل والبرامج).
- **الـ instance type** = حجم العربية: ملاكي صغيرة ولا ميكروباص ولا نقل.
- **الـ Security Group** = مين مسموحله يركب: بوابة بتسمح لناس معينة.
- **الـ user data** = ورقة تعليمات بتسيبها للسواق: «أول ما تطلع، روح هات كذا».
- **العداد** شغال من ما تستلم لحد ما ترجّع.

</Box>

## 🔍 من جوه: الخمس قرارات

### ١. AMI (Amazon Machine Image)

القالب اللي الـ instance بتطلع منه: نظام التشغيل وأي برامج متركبة. ممكن تاخدها من AWS (Amazon Linux، Ubuntu، Windows)، أو من **AWS Marketplace**، أو تعمل AMI بتاعتك من instance جاهزة عشان تكرّرها. الـ AMI مربوطة بـ Region، وتقدر تنسخها لـ Region تانية.

### ٢. Instance type

الاسم زي `t3.micro` معناه: العائلة `t`، الجيل `3`، الحجم `micro`.

| العائلة | متخصصة في | مثال استخدام |
| --- | --- | --- |
| `T`, `M` | general purpose، متوازنة | مواقع وتطبيقات عادية |
| `C` | compute optimized، CPU قوي | معالجة فيديو، ألعاب، حسابات |
| `R`, `X` | memory optimized، RAM كبيرة | databases في الذاكرة، caches |
| `I`, `D` | storage optimized، هاردات سريعة محلية | databases بتقرا وتكتب كتير |
| `P`, `G`, `Inf`, `Trn` | accelerated computing، GPU أو chips خاصة | machine learning، graphics |

الحرف `g` بعد الرقم (زي `t4g`) معناه معالج **Graviton** بتاع AWS (ARM)، غالبًا أرخص لنفس الأداء لو البرنامج بيدعم ARM.

### ٣. Security Group

firewall افتراضي على مستوى الـ instance. بتكتب قواعد **allow** بس (مفيش deny). وهو **stateful**: لو سمحت بطلب داخل، الرد بيطلع لوحده من غير قاعدة.

### ٤. الدخول للسيرفر

- **Key pair (SSH):** مفتاح بتحمّله مرة، ولازم تفتح port `22`.
- **EC2 Instance Connect** أو **Systems Manager Session Manager:** تدخل من الـ console أو CLI من غير ما تفتح port 22 خالص. Session Manager هو الأأمن عادةً.

### ٥. User data

script بيشتغل أول ما الـ instance تقوم (مرة واحدة افتراضيًا). بتستخدمه تركّب برامج وتنزل الكود. **متحطش فيه باسوردات أو access keys**، لأن أي حد عنده صلاحية يقرا إعدادات الـ instance هيشوفها. ادّي الـ instance **IAM role** بدلها.

- **Reboot:** نفس الجهاز بيعمل restart، مفيش حاجة بتتغير.
- **Stop → Start:** ممكن تتنقل لجهاز تاني، والـ public IP العادي **بيتغير**. لو محتاج IP ثابت استخدم **Elastic IP**.
- **Terminate:** نهائي. والهارد الأساسي بيتمسح معاها لو `DeleteOnTermination = true` (الافتراضي للـ root volume).

## 🛠️ طبّق: سيرفر ويب لدُكّان في ١٠ دقايق

⚠️ `t3.micro` أو `t4g.micro` ممكن تدخل في الـ Free Tier حسب حسابك. كمّل الـ Lab وامسح في نفس القعدة.

1. **`EC2` ← `Launch instance`**، الاسم `dukkan-web`، وضيف tag `Project=dukkan-lab`.
2. **AMI:** Amazon Linux 2023. **Type:** `t3.micro`.
3. **Key pair:** `Proceed without a key pair` (هندخل بـ Session Manager أو مش هندخل خالص).
4. **Network settings:** اعمل Security Group جديد، اسمح بـ `HTTP (80)` من `Anywhere`. **متفتحش SSH.**
5. **Advanced details ← User data:** الصق ده:

```bash
#!/bin/bash
# بيشتغل مرة واحدة أول ما السيرفر يقوم
dnf install -y nginx
echo "<h1>أهلًا من دُكّان 🏪</h1>" > /usr/share/nginx/html/index.html
systemctl enable --now nginx
```

6. **Launch**، واستنى الـ `Instance state` يبقى `Running` والـ status checks يعدّوا.
7. انسخ الـ **Public IPv4 address** وافتحه في المتصفح بـ `http://` (مش https).

**المتوقع:** صفحة مكتوب فيها «أهلًا من دُكّان».

**جرّب:** امسح قاعدة HTTP من الـ Security Group وحدّث الصفحة. هتلاقيها مبتفتحش (بتلف لحد ما تفشل). رجّع القاعدة. كده شفت الـ firewall بعينك.

🧹 **تنضيف:** `Instance state` ← `Terminate`. وبعدين اتأكد في `Volumes` إن مفيش volume فاضل، وفي `Elastic IPs` إن مفيش IP محجوز. امسح الـ Security Group لو مش محتاجه.

## ⚖️ قارن: الحاجات اللي بتتلخبط في EC2

| الحاجة | بتحدد إيه؟ | مش بتحدد إيه |
| --- | --- | --- |
| AMI | الـ OS والبرامج المبدئية | المقاس ولا السعر |
| Instance type | CPU وRAM والشبكة | الـ OS |
| Security Group | مين يكلم الـ instance على أنهي port | مين يدخل الـ AWS console (ده IAM) |
| IAM role على الـ instance | الـ instance تكلم أنهي خدمات AWS | الترافيك الداخل |
| Purchase option (فصل ٣٧) | طريقة الدفع (On-Demand، Spot…) | المواصفات |

| | Stop | Terminate |
| --- | --- | --- |
| تقدر ترجعها؟ | أيوه، Start | لأ |
| الـ compute بيتحاسب؟ | لأ | لأ |
| الـ EBS volume؟ | موجود وبيتحاسب | بيتمسح لو `DeleteOnTermination` |
| الـ public IP العادي؟ | بيتغير بعد Start | بيروح |
