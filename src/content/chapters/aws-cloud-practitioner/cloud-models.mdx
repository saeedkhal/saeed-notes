## 🧠 افهم: إنت عايز تمسك قد إيه بإيدك؟

دُكّان محتاج ٣ حاجات: موقع، ومكان يخزن فيه الطلبات، وإيميل للموظفين. لكل حاجة فيهم السؤال مش «نستخدم Cloud ولا لأ»، السؤال: **عايزين نتحكم في قد إيه، ونشيل هم قد إيه؟**

كل ما تاخد تحكم أكتر، بتاخد شغل ومسؤولية أكتر. وكل ما تسيب للمزود، بتتحكم أقل بس بترتاح أكتر.

<Hl c="p">نموذج الخدمة (IaaS / PaaS / SaaS) بيحدد مين بيدير إيه. ومكان الاستضافة (cloud / on-premises / hybrid) بيحدد الأجهزة قاعدة فين.</Hl>

<Box type="story" icon="🏠" title="شقة فاضية، شقة مفروشة، فندق">

- **شقة فاضية (IaaS):** المالك مديك الحيطان والكهربا والمية. العفش والدهان والتكييف عليك. حرية كاملة، وشغل كتير.
- **شقة مفروشة (PaaS):** العفش موجود ومتظبط. إنت بتجيب هدومك وتعيش. مش هتغير مكان المطبخ، بس مش هتشتري تلاجة.
- **فندق (SaaS):** بتدخل تنام وخلاص. مش بتختار لون الملاية، بس مش بتغسلها برضه.

</Box>

## 👀 تخيّل: مين شايل أنهي طبقة؟

كل مربع في الرسمة طبقة من طبقات أي نظام. الفرق بين النماذج هو **الخط اللي بيفصل بين شغلك وشغل المزود**:

<Flow items={[
  { t: "On-premises", s: "إنت شايل كل الطبقات", c: 5 },
  "→",
  { t: "IaaS", s: "إنت: OS + runtime + app + data", c: 1 },
  "→",
  { t: "PaaS", s: "إنت: app + data", c: 2 },
  "→",
  { t: "SaaS", s: "إنت: الداتا والإعدادات", c: 3 },
]} />

| الطبقة | On-prem | IaaS (EC2) | PaaS (Elastic Beanstalk) | SaaS (Gmail مثلًا) |
| --- | --- | --- | --- | --- |
| المبنى والكهربا والأجهزة | إنت | AWS | AWS | المزود |
| الـ virtualization | إنت | AWS | AWS | المزود |
| نظام التشغيل والـ patches | إنت | **إنت** | AWS | المزود |
| الـ runtime (Node، Java…) | إنت | **إنت** | AWS | المزود |
| كود التطبيق | إنت | **إنت** | **إنت** | المزود |
| الداتا ومين يشوفها | إنت | **إنت** | **إنت** | **إنت** |

لاحظ آخر سطر: **الداتا والصلاحيات عليك في كل الحالات**. حتى في SaaS، إنت اللي بتحدد مين من الموظفين ياخد access.

## 🔍 من جوه: النماذج دي على AWS شكلها إيه؟

### نماذج الخدمة

<Grid2>
<Card title="IaaS — بنية أساسية" c={1}>

بتاخد سيرفر افتراضي أو network أو storage وتظبط الباقي. على AWS: `EC2`، `EBS`، `VPC`. مناسب لو محتاج نظام تشغيل معيّن أو software قديم.

</Card>
<Card title="PaaS — منصة" c={2}>

بترفع الكود والمنصة بتشغّله وتعمله scale. على AWS: `Elastic Beanstalk`، وبشكل قريب `Lambda` و`RDS` (AWS بتدير الـ database engine، وإنت بتدير الـ schema والداتا).

</Card>
<Card title="SaaS — برنامج جاهز" c={3}>

برنامج كامل بتستخدمه من المتصفح. أمثلة: إيميل، CRM، أو `Amazon Connect` لخدمة العملاء. إنت مش بتشوف السيرفرات خالص.

</Card>
<Card title="الفكرة الواحدة" c={4}>

مش في نموذج «أحسن». في نموذج **مناسب** لكل جزء. دُكّان ممكن يستخدم التلاتة في نفس الوقت.

</Card>
</Grid2>

### أماكن الاستضافة (Deployment models)

- **Cloud (public cloud):** كل حاجة على مزود زي AWS. أسرع بداية وأقل هم أجهزة.
- **On-premises (private cloud):** الأجهزة في الـ data center بتاعك، وممكن تستخدم virtualization وأدوات تخليها تتصرف زي cloud داخلية. تحكم كامل وتكلفة ومسؤولية كاملة.
- **Hybrid:** جزء عندك وجزء على AWS، ومتوصلين ببعض. شائع لما في سيستم قديم مينفعش يتنقل دلوقتي، أو قانون بيلزمك تخلي داتا معينة عندك.
- **Multicloud:** بتستخدم أكتر من مزود cloud. بيزوّد التعقيد، فاستخدمه لسبب واضح مش موضة.

## 🛠️ طبّق: وزّع أجزاء دُكّان على النماذج

الـ Lab ورقي. لكل جزء من دُكّان اختار النموذج واكتب السبب في سطر:

| الجزء | النموذج المقترح | ليه؟ |
| --- | --- | --- |
| إيميل الموظفين | SaaS | محدش في الفريق عايز يدير mail server |
| موقع دُكّان (Node.js) | PaaS | الفريق صغير، عايز يرفع الكود بس |
| برنامج المحاسبة القديم (Windows فقط) | IaaS | محتاج نظام تشغيل معين وإعدادات خاصة |
| ماكينة الكاشير في المحل | On-premises | لازم تشتغل لو النت فصل |

**جرّب بنفسك:** لو عم حسن قال «عايز أتحكم في إصدار Node.js بالظبط وأركّب مكتبة نظام نادرة»، هل PaaS لسه مناسب؟ غالبًا هتنقل للـ IaaS أو containers، وهتدفع التمن في صيانة أكتر.

**المرحلة التانية:** دلوقتي الكاشير on-prem والموقع على AWS. ده بقى **hybrid**. ارسم سهم بينهم واكتب إيه الداتا اللي بتعدي (مثلًا المخزون).

## ⚖️ قارن: الأسئلة اللي بتفرز النماذج

| لو السؤال بيقول… | الإجابة غالبًا |
| --- | --- |
| «عايز تحكم كامل في نظام التشغيل» | IaaS |
| «المطورين عايزين يركزوا على الكود بس» | PaaS |
| «مش عايزين ندير أي حاجة، عايزين البرنامج يشتغل» | SaaS |
| «جزء في الـ data center وجزء في AWS ومتوصلين» | Hybrid |
| «كل workloads الشركة على AWS» | Cloud |
| «لازم كل حاجة جوه مبنى الشركة» | On-premises |

<Box type="warn" title="الغلطة المشهورة">

«اخترنا PaaS أو SaaS، يبقى الأمان كله على المزود». **غلط.** المزود بيأمّن طبقاته، لكن لو إديت كل الموظفين صلاحية admin، أو سبت داتا العملاء مفتوحة، ده عليك.

</Box>
