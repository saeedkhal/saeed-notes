## على باب الويب

<Grid2>
<Card title="AWS WAF" c={1}>

Web application firewall يفحص HTTP/S requests ويطبق rules على أنماط زي IPs أو paths أو SQL injection وXSS.

</Card>
<Card title="AWS Shield" c={2}>

حماية DDoS لخدمات مدعومة. Shield Standard موجود تلقائيًا، وShield Advanced اشتراك بقدرات ودعم أوسع.

</Card>
</Grid2>

<Hl c="y">WAF يفلتر طلبات الويب حسب قواعد؛ Shield يركز على هجمات DDoS. ممكن تستخدمهم مع بعض.</Hl>

<Box type="story" icon="🏟️" title="بوابة الاستاد">

WAF يفتش التذكرة والشنطة ويمنع طلب مشبوه. Shield ينظم ويحمي البوابة لما حشد ضخم مزيف يحاول يغرقها.

</Box>

## كشف التهديدات والثغرات

<En>Amazon GuardDuty</En> threat detection مستمر يحلل مصادر وإشارات مدعومة لاكتشاف نشاط مشبوه في الحسابات والـ workloads والبيانات.

<En>Amazon Inspector</En> vulnerability management يفحص workloads مدعومة، زي EC2 وcontainer images وLambda، بحثًا عن ثغرات برمجية وexposure حسب الخدمة.

GuardDuty يسأل "هل فيه سلوك تهديد؟". Inspector يسأل "هل عندي software vulnerable أو exposure؟".

## البيانات الحساسة

<En>Amazon Macie</En> يكتشف ويصنّف بيانات حساسة في Amazon S3 باستخدام machine learning وpattern matching، ويساعد يكشف مخاطر الوصول.

هو مش antivirus لكل storage service، وتركيزه الأساسي S3.

## نجمع ونحقق

<En>AWS Security Hub CSPM</En> يجمع ويرتب findings من خدمات أمان ويفحص posture مقابل controls ومعايير مدعومة، عشان تشوف الحالة مركزيًا.

<En>Amazon Detective</En> يساعد التحقيق وتحليل العلاقات والسياق للوصول لسبب نشاط مشبوه أو finding.

Security Hub مش بديل لكل detector، وDetective مش firewall يمنع request عند الحافة.

## خريطة اختيار الامتحان

- SQL injection على بوابة المدرسة: WAF.
- flood ضخم موزع: Shield.
- API calls أو نشاط runtime مشبوه: GuardDuty.
- package عليها CVE في workload مدعوم: Inspector.
- أرقام هوية في S3: Macie.
- لوحة findings وsecurity posture: Security Hub.
- تحقيق في علاقات finding: Detective.

## 🧪 تمرين ورقي آمن

اكتب السيناريوهات السبعة على كروت، واكتب الخدمة خلف كل كارت. بعدين قسمها: حماية عند الباب، كشف، تجميع، تحقيق. متعملش هجوم فعلي.

الخدمات والـ tiers تختلف في التسعير وفترات التجربة. Shield Advanced خصوصًا اشتراك مدفوع؛ متفعّلوش للتجربة قبل فهم الالتزام والتكلفة، وراجع Pricing.

الفصل الجاي هنحكم حسابات المدرسة وندير التشغيل والحصص الخدمية.
