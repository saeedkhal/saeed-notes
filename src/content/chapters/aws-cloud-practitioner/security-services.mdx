## Incident على e-commerce

الساعة 18:00 بدأ campaign، والـ traffic الطبيعي 8,000 request/min. الساعة 18:07 وصل 90,000 request/min، ومعاه SQL injection patterns وcredential abuse.

1. `Shield` امتص جزء من volumetric DDoS على الخدمات المدعومة.
2. `AWS WAF` منع requests اللي طابقت managed وcustom rules، وعمل rate limiting.
3. `GuardDuty` أصدر finding عن credentials بتستخدم من location غير معتاد.
4. `Inspector` كان مبلّغ قبلها إن container image فيها critical CVE.
5. `Security Hub` جمع findings ورتبها حسب severity.
6. المحلل استخدم `Detective` يربط principal والـ IP والـ activity في التحقيق.

الـ incident اتوقف، لكن النجاح مش معناه إن خدمة واحدة عملت كل حاجة: prevention عند edge غير threat detection غير vulnerability management.

## WAF ولا Shield؟

`AWS WAF` يفحص HTTP/S requests ويطبق rules على IPs وpaths وheaders وأنماط زي SQL injection وXSS. `AWS Shield` يركز على DDoS؛ Shield Standard تلقائي، وShield Advanced اشتراك بقدرات ودعم أوسع.

لو 100,000 request شرعية من campaign، WAF rule سيئة ممكن تمنع عملاء حقيقيين. ابدأ بـ count mode، راقب false positives، وبعدها فعّل block. Shield مش بديل لقواعد التطبيق.

## GuardDuty ولا Inspector؟

`GuardDuty` يسأل: "هل فيه behavior أو signals تدل على threat دلوقتي؟" ويحلل مصادر مدعومة على مستوى accounts وworkloads وdata.

`Inspector` يسأل: "هل workload مدعوم فيه CVE أو exposure؟" ويفحص EC2 وcontainer images وLambda حسب التغطية الحالية.

Image vulnerable من غير exploitation = Inspector finding. Access key بتعمل calls مشبوهة = GuardDuty finding. ممكن الاتنين يظهروا في نفس incident.

## Macie: الداتا الحساسة في S3

Media platform اكتشفت إن export فيه 2 مليون customer records اتحط في S3 prefix واسع الصلاحيات. `Macie` يستخدم pattern matching وML لاكتشاف وتصنيف sensitive data في S3 ويساعد يكشف access risks.

Macie مش antivirus لكل storage، والـ scanning الواسع له تكلفة. ابدأ بالـ buckets الأعلى خطورة وحدد sampling أو jobs حسب المتطلبات.

## Security Hub وDetective

`Security Hub CSPM` يجمع findings ويفحص security posture ضد controls مدعومة. `Detective` يساعد يحقق في العلاقات والسياق.

<Flow items={[{t:"WAF / Shield",s:"حماية edge",c:1},"→",{t:"GuardDuty / Inspector / Macie",s:"findings",c:2},"→",{t:"Security Hub",s:"تجميع وأولوية",c:3},"→",{t:"Detective",s:"تحقيق",c:5}]} />

Security Hub مش detector بديل، وDetective مش firewall. Remediation ممكن يبقى يدوي أو automation محسوبة؛ auto-isolation السريع يقلل الضرر لكنه ممكن يوقف production بالغلط.

## قرار سريع

- malicious web pattern → WAF.
- DDoS volume → Shield.
- suspicious activity → GuardDuty.
- vulnerable software → Inspector.
- sensitive S3 data → Macie.
- central findings/posture → Security Hub.
- investigate relationships → Detective.
