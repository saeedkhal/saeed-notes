## 🧠 افهم: ليلة هجوم على دُكّان

ليلة ٢٧ رمضان، في نفس الساعة حصل كذا حاجة:

- سيل طلبات وهمية بيحاول يوقّع الموقع.
- حد بيجرب SQL injection في خانة البحث.
- access key قديمة لموظف ساب الشغل بتعمل calls غريبة من بلد تانية.
- container image فيها مكتبة قديمة بثغرة معروفة.
- ملف CSV فيه أرقام تليفونات الزباين اتحط في bucket بالغلط.

مفيش خدمة واحدة بتشوف كل ده. كل خدمة **حارس متخصص** في نوع معين.

<Hl c="p">WAF وShield بيمنعوا عند الباب. GuardDuty بيكشف سلوك مريب. Inspector بيفحص ثغرات. Macie بيلاقي داتا حساسة في S3. Security Hub بيجمّع كل ده في مكان واحد. Detective بيساعدك تحقق.</Hl>

<Box type="story" icon="🏦" title="أمن البنك">

- **Shield** = الحواجز قدام البنك اللي بتمنع الزحمة تقتحم الباب (DDoS).
- **WAF** = الأمن على الباب بيفتش الشنط ويمنع اللي معاه حاجة ممنوعة (طلبات خبيثة).
- **GuardDuty** = كاميرات بتحلل السلوك: «الموظف ده بيفتح الخزنة الساعة ٣ الفجر من فرع غريب».
- **Inspector** = مهندس بيلف يفحص الأقفال والشبابيك: «القفل ده موديل قديم فيه عيب».
- **Macie** = مراجع بيدوّر على أوراق سرية متسابة في أماكن غلط.
- **Security Hub** = غرفة التحكم اللي فيها كل التقارير.
- **Detective** = المحقق اللي بيربط الخيوط بعد الحادثة.

</Box>

## 🔍 من جوه: كل حارس بيعمل إيه بالظبط

### المنع

- **AWS Shield Standard:** حماية DDoS على طبقة الشبكة (Layer 3/4) **تلقائية ومجانية** لكل العملاء.
- **AWS Shield Advanced:** اشتراك مدفوع: حماية أوسع، فريق AWS للاستجابة (SRT) وقت الهجوم، وحماية من زيادة الفاتورة بسبب الهجوم.
- **AWS WAF:** firewall للـ **HTTP/HTTPS** (Layer 7) على CloudFront وALB وAPI Gateway وغيرها. قواعد ضد SQL injection وXSS، **rate limiting**، منع IPs أو دول، وmanaged rules جاهزة.
- **AWS Network Firewall:** firewall مُدار على مستوى الـ **VPC** لفحص الترافيك.
- **AWS Firewall Manager:** يطبّق قواعد WAF وShield وSecurity Groups على **كل الحسابات** في الـ Organization من مكان واحد.

### الكشف والفحص

- **Amazon GuardDuty:** **threat detection**. بيحلل CloudTrail وVPC Flow Logs وDNS logs وغيرها بالـ ML، ويطلع findings زي «credentials بتستخدم من IP مشبوه» أو «instance بتكلم سيرفر تعدين». **مبيمنعش لوحده.**
- **Amazon Inspector:** **vulnerability scanning** أوتوماتيك لـ EC2 وcontainer images في ECR وLambda: CVEs معروفة، ومنافذ مفتوحة على الشبكة.
- **Amazon Macie:** بيدوّر على **داتا حساسة (PII)** في **S3** (أرقام كروت، تليفونات، أسماء)، وبيكشف الـ buckets المكشوفة.

### التجميع والتحقيق

- **AWS Security Hub:** بيجمّع findings من GuardDuty وInspector وMacie وغيرهم، ويفحص الحساب ضد معايير (زي CIS وAWS Foundational Security Best Practices)، ويديك score. (الجزء ده اسمه حاليًا **Security Hub CSPM**، راجع الـ docs للتسميات الحالية.)
- **Amazon Detective:** بعد ما finding يظهر، بيربط الداتا (مين، منين، إمتى، عمل إيه قبل وبعد) عشان تفهم القصة كاملة.

## 🛠️ طبّق: شغّل الحراس على حساب دُكّان

⚠️ GuardDuty وInspector وMacie وSecurity Hub كلهم ليهم **فترة تجربة مجانية** (غالبًا ٣٠ يوم) وبعدها بيتحاسبوا. فعّلهم للتجربة، وعطّلهم بعدها لو مش هتكمل.

1. **فعّل GuardDuty:** `GuardDuty` ← `Get started` ← `Enable`.
2. **ولّد findings تجريبية** عشان تشوف شكلها من غير هجوم حقيقي:

```bash
DETECTOR=$(aws guardduty list-detectors --query 'DetectorIds[0]' --output text)
aws guardduty create-sample-findings --detector-id $DETECTOR
```

**المتوقع:** في صفحة `Findings` هتلاقي عشرات الأمثلة بـ `[SAMPLE]`. افتح واحد زي `UnauthorizedAccess:IAMUser/...` واقرا الـ severity والـ resource والتفاصيل.

3. **فعّل Security Hub** وشوف الـ findings دي ظهرت هناك كمان، ومعاها الـ **security score** للحساب ضد المعايير.
4. **صنّف ليلة الهجوم:** ارجع لقايمة الخمس حاجات في أول الفصل واكتب لكل واحدة الحارس.

| الحادثة | الحارس |
| --- | --- |
| سيل طلبات DDoS | Shield (Standard تلقائي، Advanced لحماية أكبر) |
| SQL injection | WAF |
| access key بتعمل calls غريبة | GuardDuty، وبعدها Detective للتحقيق |
| مكتبة بثغرة في الـ image | Inspector |
| CSV فيه تليفونات في S3 | Macie |

🧹 **تنضيف:** عطّل (Disable) GuardDuty وSecurity Hub من الإعدادات لو كانت تجربة.

## ⚖️ قارن: الأزواج اللي بتتلخبط

| بيتلخبطوا | الفرق |
| --- | --- |
| WAF ↔ Shield | WAF = طلبات **HTTP خبيثة** (Layer 7، قواعد). Shield = **DDoS** (حجم) |
| WAF ↔ Security Group | WAF بيفهم **محتوى** الطلب. SG بيفهم **IP وport** بس |
| GuardDuty ↔ Inspector | GuardDuty = **سلوك** مريب بيحصل. Inspector = **ثغرة** موجودة في الـ software |
| GuardDuty ↔ Macie | GuardDuty = تهديدات على الحساب والموارد. Macie = **داتا حساسة في S3** |
| Security Hub ↔ GuardDuty | GuardDuty **بيكتشف**. Security Hub **بيجمّع** من كذا مصدر |
| Detective ↔ GuardDuty | GuardDuty بيقول «في حاجة». Detective بيساعدك **تحقق** في القصة |
| Shield Standard ↔ Advanced | Standard مجاني وتلقائي. Advanced مدفوع، حماية أكبر وفريق استجابة |
