## 🧠 افهم: إزاي الفاتورة بتفاجئ الناس؟

سارة جربت يوم الخميس سيرفر وload balancer عشان تتعلم. يوم الأحد لقت فاتورة ٦٠ دولار. هي عملت `Stop` للسيرفر، بس:

- الـ load balancer كان لسه شغال، وده بيتحاسب بالساعة.
- الهارد (EBS volume) لسه موجود، وده بيتحاسب حتى لو السيرفر واقف.
- عملت الـ Lab في Region، وراحت تمسح في Region تانية فمشافتش حاجة.

المشكلة مش إن AWS غالية. المشكلة إن **مفيش حد كان مراقب، ومفيش قايمة باللي اتعمل**.

<Hl c="o">قبل أول resource: اعمل Budget بتنبيه. وقت الإنشاء: حط tags. بعد الـ Lab: امسح كل حاجة في نفس الـ Region واتأكد.</Hl>

<Box type="story" icon="⚡" title="عداد الكهربا">

لما تسافر، مش كفاية تطفي النور. التلاجة والسخان والراوتر لسه شغالين وبيعدّوا. وعشان متتفاجئش، بتبص على العداد قبل ما تمشي وأول ما ترجع. الـ **Budget** هو إن العداد يبعتلك رسالة لما يعدّي رقم معين، بس **مش بيفصل الكهربا لوحده**.

</Box>

## 🔍 من جوه: الحساب والتنبيهات

### Free plan ولا Paid plan؟

لما تعمل حساب جديد دلوقتي، AWS بتخيّرك بين خطتين (الشروط بتتغير، فراجع صفحة Free Tier وقت التسجيل):

<Grid2>
<Card title="Free plan" c={1}>

للتعلم والتجربة على خدمات مختارة. مش بيتحصّل منك فلوس طول الخطة. بتخلص بعد **٦ شهور** أو لما الـ credits تخلص، أيهما أقرب، والحساب بيتقفل لو مرقّتهوش.

</Card>
<Card title="Paid plan" c={2}>

كل الخدمات متاحة، والدفع pay-as-you-go. أي استهلاك أكتر من الـ credits بيتحصّل على الكارت.

</Card>
</Grid2>

الحسابات الجديدة المؤهلة بتاخد credits في الأول (حاليًا `$100`)، وتقدر تكسب credits زيادة لما تجرب أنشطة معينة. الـ credits ليها تاريخ انتهاء ومش بتغطي كل حاجة.

### AWS Budgets

بتحط رقم (مثلًا `$10` في الشهر) وتختار إمتى تتنبّه:

- **Actual:** لما الصرف الفعلي يعدّي نسبة (مثلًا ٨٠٪).
- **Forecasted:** لما **التوقع** لآخر الشهر يعدّي الرقم. ده بينبهك بدري.

<Box type="warn" title="Budget بينبّه، مش بيقفل">

الـ Budget مش سقف بيوقف الصرف. في **Budget Actions** تقدر تعمل حاجات محددة (زي إنك تحط policy تمنع إنشاء موارد)، بس محتاجة إعداد وصلاحيات، ومش بتوقف كل حاجة. وبيانات الفواتير بتتأخر ساعات، فممكن تصرف قبل ما التنبيه يوصل.

</Box>

### Tags

كل resource تقدر تحط عليه labels بشكل `Key=Value`. لما تفعّلهم كـ **cost allocation tags** في Billing، الفاتورة تتقسم بيهم وتعرف مين صرف إيه:

- `Project=dukkan`
- `Environment=lab`
- `Owner=sara`
- `ExpiresOn=2026-11-30`

### الحاجات اللي بتفضل تتحاسب بعد Stop

| المورد | بيتحاسب وهو واقف؟ |
| --- | --- |
| EC2 instance واقفة | الـ compute لأ |
| EBS volume المربوط بيها | **أيوه** |
| Elastic IP / public IPv4 | **أيوه** (AWS بتحاسب على الـ public IPv4) |
| Load balancer | **أيوه** طول ما هو موجود |
| NAT Gateway | **أيوه** بالساعة + الداتا |
| Snapshots | **أيوه** على حجمها |

## 🛠️ طبّق: جهّز حساب دُكّان قبل أي Lab

⚠️ Budgets: أول كام budget مجانية، والباقي ليه سعر صغير. راجع الـ docs.

1. **اعمل Budget:** `Billing and Cost Management` ← `Budgets` ← `Create budget` ← اختار template `Monthly cost budget` ← المبلغ `$10` ← إيميلك.
   **المتوقع:** budget بتنبيهات عند ٨٥٪ و١٠٠٪ actual و١٠٠٪ forecasted (حسب الـ template).
2. **فعّل تنبيهات Free Tier:** من `Billing preferences` فعّل إيميلات استهلاك الـ Free Tier.
3. **اتفق مع نفسك على tags ثابتة:** أي حاجة هتعملها في الفصول الجاية حط عليها `Project=dukkan-lab` و`Owner=<اسمك>`.
4. **اعرف تدوّر:** `Resource Groups & Tag Editor` ← `Tag Editor` ← Regions = `All regions` ← tag `Project=dukkan-lab`. دي الطريقة اللي هتلاقي بيها أي حاجة نسيتها.

نفس الـ Budget بالـ CLI (للتوضيح، راجع الـ docs للـ flags):

```bash
aws budgets create-budget --account-id <ACCOUNT_ID> \
  --budget '{"BudgetName":"dukkan-lab","BudgetLimit":{"Amount":"10","Unit":"USD"},"TimeUnit":"MONTHLY","BudgetType":"COST"}' \
  --notifications-with-subscribers '[{"Notification":{"NotificationType":"FORECASTED","ComparisonOperator":"GREATER_THAN","Threshold":100},"Subscribers":[{"SubscriptionType":"EMAIL","Address":"you@example.com"}]}]'
```

🧹 **عادة التنضيف:** بعد كل Lab، افتح Tag Editor على `All regions` واتأكد إن مفيش حاجة باقية بالـ tag بتاعك. وتاني يوم بص على `Bills`.
