## 🧠 افهم: الصفحة دي بتتقري إزاي

كل كارت فيه **موقف** (زي ما هيجيلك في السؤال) و**الخدمة أو القرار**. غطّي الجزء التاني وحاول تجاوب. لو كارت وقفك، ارجع لفصله وبص على جزء 👀 تخيّل، مش التعريف.

## 🛠️ طبّق: خطة آخر ٢٤ ساعة

1. **الصبح:** غطّي الإجابات في الكروت فوق وجاوب. علّم أي كارت غلطت فيه.
2. **الضهر:** لكل كارت معلّم، افتح الفصل واقرا **👀 تخيّل** و**⚖️ قارن** بس.
3. **العصر:** حل **الاختبار التجريبي** (الفصل الجاي) في ٣٥ دقيقة.
4. **بالليل:** راجع الأسئلة اللي غلطت فيها بس. نام بدري.
5. **في الامتحان:** اقرا آخر السؤال الأول (المطلوب)، لاقي الكلمة اللي بتحسم، استبعد اتنين، وعلّم الصعب وارجعله. **مفيش خصم على الغلط**، فمتسيبش سؤال فاضي.

## ⚖️ قارن: الأرقام اللي تتسأل

| الرقم | معناه |
| --- | --- |
| **15 دقيقة** | أقصى مدة لـ Lambda |
| **5 TB** | أقصى حجم object في S3 |
| **11 nines** (99.999999999٪) | durability مصممة لـ S3 |
| **35 يوم** | أقصى retention للـ automated backups في RDS |
| **6 نسخ / 3 AZs** | تخزين Aurora |
| **15** | عدد Aurora replicas |
| **14 يوم** | أقصى retention لرسالة SQS |
| **90 يوم** | CloudTrail event history |
| **دقيقتين** | إنذار Spot قبل ما تتاخد |
| **لحد ٩٠٪** | خصم Spot |
| **١ أو ٣ سنين** | مدة Savings Plans وRIs |
| **١ يناير ٢٠٢٧** | نهاية خطط الدعم القديمة (Developer، Business، Enterprise On-Ramp) |
