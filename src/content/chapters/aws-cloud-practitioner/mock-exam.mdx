## قبل ما تبدأ

الأسئلة أصلية للتعلّم، مش certification dump. التوزيع قريب من CLF-C02: ٧ Cloud Concepts، ٩ Security، ١٠ Technology، و٤ Billing/Support. خصص ٣٥ دقيقة، وجاوب قبل قراءة الشرح.

## Cloud Concepts — ٧ أسئلة

<Quiz>
<Q n={1} q="SaaS بيستقبل registrations وقت campaign فقط، وعايز يزود السعة وقت الزحمة ويقللها بعدها. أنهي فائدة cloud أوضح؟">
`Elasticity`: السعة تتوافق مع الطلب بدل شراء peak capacity طول السنة. High availability تركز على استمرار الخدمة وقت الفشل، مش تغير الحجم.
</Q>
<Q n={2} q="شركة اشترت servers مقدمًا لخمس سنين وعايزة الدفع حسب الاستخدام. التحول المالي الأشهر؟">
من `CapEx` إلى نموذج أقرب لـ `OpEx` وpay-as-you-go. ده لا يمنع commitments اختيارية لما الحمل يبقى ثابت.
</Q>
<Q n={3} q="تطبيق لازم يفضل شغال لو data center واحد داخل Region وقع. أبسط مبدأ؟">
وزّع المكونات على أكتر من `Availability Zone`. ده يقلل اعتماد workload على failure domain واحدة.
</Q>
<Q n={4} q="مين مسؤول عن patching لنظام التشغيل على EC2؟">
العميل يدير guest OS والـ applications؛ AWS تدير البنية المادية والـ hypervisor.
</Q>
<Q n={5} q="Product team عايز يقلل تجربة فكرة من شهور لأيام. أنهي قيمة cloud؟">
`Agility`: توفير موارد بسرعة والتجربة من غير دورة شراء hardware طويلة.
</Q>
<Q n={6} q="اختيار managed database بدل database على EC2 غيّر إيه؟">
AWS أخذت مهام تشغيل engine والبنية المحددة، لكن العميل لسه مسؤول عن data وaccess والإعدادات تحت تحكمه.
</Q>
<Q n={7} q="مراجعة workload عبر الأمن والموثوقية والتكلفة والاستدامة؟">
`AWS Well-Architected Framework` وركائزه الست؛ guidance للمراجعة مش migration tool.
</Q>

## Security and Compliance — ٩ أسئلة

<Q n={8} q="EC2 محتاجة تقرأ S3 من غير access keys ثابتة؟">
اربط `IAM role` بالـ instance بأقل صلاحية؛ temporary credentials أفضل من long-term keys.
</Q>
<Q n={9} q="منع member accounts من Regions معينة حتى لو admin محلي سمح؟">
`SCP` كـ guardrail؛ تحدد أقصى صلاحية ولا تمنح permission بنفسها.
</Q>
<Q n={10} q="مين حذف security group الساعة ٣؟">
`CloudTrail` لسجل API والهوية والوقت؛ CloudWatch مش سجل API audit الأساسي.
</Q>
<Q n={11} q="محاولات SQL injection في HTTP requests؟">
`AWS WAF` بقواعد أمام خدمة مدعومة. Shield يركز على DDoS.
</Q>
<Q n={12} q="اكتشاف سلوك مشبوه في accounts وworkloads؟">
`GuardDuty`. Inspector للثغرات، وMacie للبيانات الحساسة في S3.
</Q>
<Q n={13} q="تخزين database password وعمل rotation؟">
`Secrets Manager`. KMS يدير encryption keys؛ الدورين متكاملين ومختلفين.
</Q>
<Q n={14} q="Auditor طلب تقرير compliance صادر عن AWS؟">
`Artifact`. التقرير لا يثبت تلقائيًا إن إعداد workload نفسه compliant.
</Q>
<Q n={15} q="اكتشاف بيانات شخصية حساسة داخل S3؟">
`Macie`، مع تحديد نطاق الفحص ومراجعة التكلفة.
</Q>
<Q n={16} q="الإجراء الأصح لحساب root؟">
MFA، منع الاستخدام اليومي، عدم إنشاء root access keys، وتأمين recovery.
</Q>

## Cloud Technology and Services — ١٠ أسئلة

<Q n={17} q="CSV في S3 وSQL سريع من غير cluster؟">
`Athena`. Parquet وpartitioning يقللوا scan والتكلفة.
</Q>
<Q n={18} q="معالجة صورة عند رفعها، والمهمة قصيرة وstateless؟">
`Lambda`؛ event-driven من غير server، مع مراجعة limits الفعلية.
</Q>
<Q n={19} q="Linux servers متعددة محتاجة نفس file system في أكتر من AZ؟">
`EFS`. EBS block وS3 object، فمش نفس access pattern.
</Q>
<Q n={20} q="Relational database محتاجة failover داخل Region، والقراءة مش bottleneck؟">
`RDS Multi-AZ`. Read replica أساسها read scaling.
</Q>
<Q n={21} q="Orders service تفصل نفسها عن worker وتحتفظ بالرسائل؟">
`SQS` للـ buffering والdecoupling؛ صمّم retries وidempotency.
</Q>
<Q n={22} q="Content عالمي من edge مع تقليل origin latency؟">
`CloudFront`. Route 53 DNS، مش CDN cache.
</Q>
<Q n={23} q="Oracle إلى Aurora PostgreSQL مع استمرار تغييرات المصدر؟">
`DMS` للـ data وCDC، و`DMS Schema Conversion` للـ schema، مع manual fixes واختبارات.
</Q>
<Q n={24} q="Chatbot generative AI من foundation models مُدارة؟">
`Bedrock`. SageMaker AI للتحكم الأعمق في بناء وتدريب ML.
</Q>
<Q n={25} q="Partner يرسل SFTP كل ليلة من غير تغيير برنامجه؟">
`Transfer Family` إلى S3 أو EFS؛ DataSync للـ managed bulk file/object workflows.
</Q>
<Q n={26} q="Metrics وlogs وalarm لما CPU يعدي threshold؟">
`CloudWatch`. CloudTrail للـ API audit وConfig للـ configuration history.
</Q>

## Billing, Pricing, and Support — ٤ أسئلة

<Q n={27} q="Batch يستحمل interruption ويعمل checkpoint؟">
`Spot Instances` غالبًا أكبر خصم، بشرط recovery design.
</Q>
<Q n={28} q="Architecture لسه متنفذتش وعايز estimate قابل للمشاركة؟">
`Pricing Calculator`. Cost Explorer يحلل usage حصل ويقدم forecast.
</Q>
<Q n={29} q="Alert عند توقع تجاوز ميزانية الشهر؟">
`AWS Budgets` forecasted alert؛ مش hard cap والبيانات ممكن تتأخر.
</Q>
<Q n={30} q="تحميل audit report وشراء security product من vendor؟">
`Artifact` للتقارير، و`Marketplace` لعروض vendors؛ APN للـ partners والاستشارة.
</Q>
</Quiz>
