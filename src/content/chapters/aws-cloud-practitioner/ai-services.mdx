## 🧠 افهم: عايز AI، بس قد إيه؟

دُكّان عنده أفكار AI:

- يقرا **الفواتير الورق** من الموردين ويطلّع الأرقام.
- يعرف **تقييمات الزباين** إيجابية ولا سلبية.
- **chatbot** يرد على «طلبي فين؟» بكلام طبيعي.
- **model** بيتوقع المنتجات اللي هتخلص الأسبوع الجاي من داتا دُكّان نفسها.

كل فكرة محتاجة مستوى مختلف من الشغل. مش محتاج تبني model عشان تقرا فاتورة، فيه خدمة جاهزة. بس عشان تتوقع مبيعات دُكّان بالذات ممكن تحتاج تبني.

<Hl c="u">٣ مستويات: خدمات AI جاهزة (API بتنادي عليه: صور، نصوص، صوت). Bedrock لبناء تطبيقات generative AI على foundation models جاهزة. SageMaker AI لبناء وتدريب ونشر models بنفسك.</Hl>

<Box type="story" icon="🍰" title="عايز تورتة">

- **خدمة AI جاهزة** = تشتري **تورتة جاهزة** من الحلواني. سريع وسهل، بس الطعم زي ما هو.
- **Bedrock** = تشتري **عجينة ممتازة جاهزة** وتزوّد عليها الحشو والزينة اللي تعجبك (بياناتك، تعليماتك).
- **SageMaker AI** = تعمل التورتة **من الدقيق والبيض**: تحكم كامل، وشغل ووقت أكتر.

</Box>

## 🔍 من جوه: التلات مستويات

### ١. خدمات AI جاهزة (مفيش ML محتاج تعرفه)

| الخدمة | بتعمل إيه | مثال في دُكّان |
| --- | --- | --- |
| **Rekognition** | تحليل صور وفيديو: أشياء، وشوش، محتوى غير لائق، نص في صورة | تتأكد صورة المنتج مفيهاش محتوى ممنوع |
| **Textract** | يطلّع نص **وجداول وforms** من مستندات ممسوحة | فواتير الموردين |
| **Comprehend** | تحليل نص: مشاعر، كيانات (أسماء، أماكن)، مواضيع، PII | تقييمات الزباين |
| **Translate** | ترجمة | وصف المنتجات بالإنجليزي |
| **Transcribe** | **صوت ← نص** | مكالمات خدمة العملاء |
| **Polly** | **نص ← صوت** | رسالة صوتية «طلبك في الطريق» |
| **Lex** | chatbots بالصوت والنص (نفس تقنية Alexa) | بوت «طلبي فين؟» |
| **Kendra** | بحث ذكي في مستندات الشركة | الموظفين يدوروا في السياسات |
| **Personalize** | recommendations | «ممكن يعجبك كمان» |

### ٢. Amazon Bedrock: generative AI

- منصة **fully managed** بتديك **foundation models** من Amazon وشركات تانية عن طريق API واحد، من غير ما تدير infrastructure.
- **Knowledge Bases:** **RAG** = الـ model يجاوب من مستنداتك إنت (سياسة الاسترجاع مثلًا).
- **Guardrails:** يمنع مواضيع، يفلتر محتوى، يخبّي PII.
- **Agents:** الـ model ينفّذ خطوات ويكلم APIs (يدور على الطلب في الـ database).
- داتاك **مش بتستخدم** في تدريب الـ models الأساسية (راجع الـ docs للتفاصيل).

### ٣. Amazon SageMaker AI: ابني بنفسك

منصة لكل مراحل ML: تجهيز الداتا، **تدريب** models، tuning، **deploy** لـ endpoints، ومراقبة. مناسب لما المشكلة **خاصة بداتاك** ومفيش خدمة جاهزة (توقع مخزون دُكّان، كشف احتيال). (الاسم الحالي **SageMaker AI**، والاسم «SageMaker» لوحده بقى بيشير لمنصة data وAI أوسع.)

### وAmazon Q؟

**مساعد AI جاهز** للموظفين: **Q Business** يجاوب من بيانات الشركة وأنظمتها، و**Q Developer** يساعد المطورين في الكود وAWS. الفرق: Q **منتج تستخدمه**، Bedrock **منصة تبني عليها منتجك**. (المنتجات دي بتتطور بسرعة، راجع الـ docs.)

## 🛠️ طبّق: افهم تقييمات الزباين

⚠️ Comprehend وTranslate بيتحاسبوا بعدد الحروف، وفي Free Tier للحسابات الجديدة. جملتين للتجربة تكلفتها شبه صفر.

1. **حلّل مشاعر تقييم:**

```bash
aws comprehend detect-sentiment --language-code ar \
  --text "التوصيل اتأخر ساعتين والعيش وصل بارد"
```

**المتوقع:** `"Sentiment": "NEGATIVE"` ومعاه نسب لكل نوع.

2. **جرّب تقييم إيجابي:** `"الجبنة طازة والمندوب محترم جدًا"`. **المتوقع:** `POSITIVE`.
3. **ترجم وصف منتج:**

```bash
aws translate translate-text --source-language-code ar --target-language-code en \
  --text "عيش بلدي طازة من الفرن كل يوم الصبح"
```

4. **فكّر في الـ chatbot:** عم حسن عايز بوت يجاوب أسئلة عن سياسة الاسترجاع **من ملف PDF بتاعه**. خدمة جاهزة؟ Bedrock؟ SageMaker؟ (**Bedrock + Knowledge Base**: model جاهز، بيجاوب من مستنداتك، من غير تدريب.)
5. **وتوقع المخزون؟** مفيش API جاهز يعرف دُكّان. محتاج model متدرب على داتا دُكّان ← **SageMaker AI**.

## ⚖️ قارن: التلاتة الكبار

| | خدمات AI جاهزة | Amazon Bedrock | Amazon SageMaker AI |
| --- | --- | --- | --- |
| بتعمل إيه | مهمة واحدة محددة بـ API | تطبيقات generative AI على foundation models | تبني وتدرّب وتنشر models |
| محتاج خبرة ML؟ | لأ | قليل | **أيوه** |
| بتدرّب model؟ | لأ | لأ (ممكن تخصيص) | **أيوه** |
| مثال | Textract للفواتير | chatbot من مستنداتك | توقع مبيعات دُكّان |

| بيتلخبطوا | الفرق |
| --- | --- |
| Polly ↔ Transcribe | **Polly** = نص ← **صوت** (بيتكلم). **Transcribe** = صوت ← **نص** (بيكتب) |
| Textract ↔ Rekognition | **Textract** = مستندات وجداول وforms. **Rekognition** = صور عامة (وشوش وأشياء) |
| Comprehend ↔ Kendra | **Comprehend** = يحلل النص. **Kendra** = يبحث في المستندات |
| Lex ↔ Bedrock | **Lex** = بوت بـ intents محددة. **Bedrock** = generative AI أوسع (وممكن مع بعض) |
| Bedrock ↔ Amazon Q | **Bedrock** = منصة تبني عليها. **Q** = مساعد جاهز تستخدمه |
