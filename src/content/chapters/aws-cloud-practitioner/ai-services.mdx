## جاهز ولا هتبني؟

خدمات AWS هنا تلات رفوف: خدمة API لمهمة محددة، منصة generative AI، أو أدوات تبني وتدرّب بيها model مخصوص.

<Box type="story" title="مدرس خصوصي ولا كتاب جاهز؟">

لو عايز تسمع نص بصوت، مش لازم تدرّب model من الصفر؛ استخدم خدمة جاهزة. لو المدرسة عندها نمط درجات خاص وعايزة model تتنبأ بيه، ساعتها أدوات التدريب والتجارب أهم.

</Box>

## SageMaker AI

`Amazon SageMaker AI` هو الاسم الحالي للخدمة اللي كانت اسمها Amazon SageMaker قبل ديسمبر ٢٠٢٤. بيخدم بناء وتدريب وتخصيص ونشر models للـ ML التقليدي والـ AI.

فكّر فيه لما data scientists محتاجين notebooks، training jobs، pipelines، model registry، وmanaged endpoints.

<Hl c="p">SageMaker AI للبناء والتحكم العميق؛ مش مجرد استدعاء مهمة جاهزة.</Hl>

AWS عندها دلوقتي منصة أوسع باسم `Amazon SageMaker` بتجمع data وanalytics وAI، وجواها SageMaker AI. الاسم في مواد الامتحان ممكن يكون أقصر، فاقرأ سياق السؤال.

## Amazon Bedrock

`Amazon Bedrock` خدمة fully managed وserverless لبناء generative AI apps باستخدام foundation models من Amazon ومزودين تانيين.

فيها قدرات زي Knowledge Bases للـ RAG، Guardrails، Agents، وmodel evaluation. تختارها لما عايز تبني chatbot أو تلخيص أو agent من foundation model من غير إدارة training infrastructure.

<Box type="idea" title="Bedrock ولا SageMaker AI؟">

ابدأ بـ Bedrock لتطبيق generative AI مُدار واختيار foundation models. اختار SageMaker AI لو محتاج تدريب أو customization وتحكم في الـ ML lifecycle والـ infrastructure. ممكن المشروع يستخدم الاتنين.

</Box>

## Amazon Q

`Amazon Q` مساعد generative AI جاهز للعمل. `Amazon Q Developer` يساعد في بناء وتشغيل وتحويل software والتعامل مع AWS؛ وفيه تجارب Q متخصصة لسيناريوهات business.

الفرق: Bedrock منصة المطور يبني فوقها app، بينما Q assistant جاهز للمستخدم. Q نفسه مبني باستخدام Bedrock، لكنهم مش نفس المنتج.

## صورة ومستند

`Amazon Rekognition` يحلل الصور والفيديو: objects، labels، faces، ومحتوى غير مناسب حسب الميزة والسياسة.

`Amazon Textract` يستخرج text وforms وtables من documents وscans. لو صورة فيها طالب وشنطة: Rekognition. لو صورة استمارة تقديم وعايز الخانات: Textract.

<Box type="warn" title="الوجه مش قرار">

التعرف الآلي ممكن يخطئ ويتأثر بجودة الداتا. متخليش نتيجة حساسة زي قبول طالب أو عقوبة تعتمد عليه لوحده؛ استخدم human review وسياسات الخصوصية.

</Box>

## لغة مكتوبة

`Amazon Comprehend` يستخدم NLP لاستخراج entities وkey phrases وsentiment واللغة من النص.

`Amazon Translate` يترجم النصوص بين اللغات. Comprehend يفهم خصائص النص؛ Translate يغير لغته.

## كلام وصوت ومحادثة

- `Amazon Transcribe`: speech → text.
- `Amazon Polly`: text → lifelike speech.
- `Amazon Lex`: conversational bots بالصوت أو النص.

بوابة المدرسة تستقبل سؤال منطوق: Transcribe يحوله كتابة، Lex يدير الحوار، وPolly ينطق الرد. Translate ممكن يترجم المحتوى، وComprehend يحلل المعنى أو sentiment.
