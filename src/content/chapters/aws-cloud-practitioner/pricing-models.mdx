## 🧠 افهم: نفس السيرفر، أسعار مختلفة

فاتورة دُكّان بقت كبيرة. سارة لاحظت إن الـ compute شكله كده:

- **٤ سيرفرات شغالين ٢٤ ساعة طول السنة.** ده الأساس (baseline).
- **لحد ١٢ سيرفر زيادة** بعد الفطار في رمضان. ده الـ peak.
- **تقرير الليل وتصغير الصور القديمة**: شغل لو اتقطع يكمل من مكانه.

كلهم شغالين **On-Demand** (أغلى سعر للساعة). بس AWS بتدّي **خصم** لو التزمت بسنة أو ٣، و**خصم أكبر** لو قبلت إن السيرفر ممكن يتاخد منك بإنذار قصير.

<Hl c="g">On-Demand = مرونة كاملة وأغلى سعر. Savings Plans وReserved = خصم مقابل التزام. Spot = خصم كبير مقابل إن AWS ممكن تاخده. Dedicated = سيرفر فعلي ليك لوحدك.</Hl>

<Box type="story" icon="🏨" title="حجز أوضة فندق">

- **On-Demand** = تدخل الفندق من غير حجز وتدفع سعر الليلة كامل. تمشي وقت ما تحب.
- **Savings Plan / Reserved** = **اشتراك سنوي** في الفندق بخصم كبير. بس لو مسافرتش، دفعت برضه.
- **Spot** = أوضة **فاضية الليلة دي بنص التمن**، بس لو جه نزيل حاجز، الفندق بيطلب منك تمشي خلال دقايق.
- **Dedicated Host** = تأجر **دور كامل** لوحدك. مفيش حد غيرك فيه.

</Box>

## 🔍 من جوه: كل طريقة دفع

| الطريقة | الفكرة | الخصم تقريبًا | مناسب لـ |
| --- | --- | --- | --- |
| **On-Demand** | بالثانية أو الساعة، بلا التزام | — | حمل جديد أو متغير، تجارب |
| **Compute Savings Plans** | التزام بـ **$ في الساعة** لسنة أو ٣ | لحد ~٦٦٪ | baseline، **مرن** بين EC2 وFargate وLambda والـ Regions والعائلات |
| **EC2 Instance Savings Plans** | نفس الفكرة بس لعائلة في Region | لحد ~٧٢٪ | baseline ثابت على نوع معروف |
| **Reserved Instances** | التزام سنة أو ٣ على خصائص instance | لحد ~٧٢٪ | baseline (وموجودة لـ RDS وغيره) |
| **Spot Instances** | سعة فاضية عند AWS، ممكن تتاخد بإنذار **دقيقتين** | لحد ~٩٠٪ | batch، CI، شغل stateless بيعمل checkpoint |
| **Dedicated Hosts** | سيرفر فعلي كامل ليك، وبتشوف الـ sockets والـ cores | — | licenses مربوطة بالسيرفر (BYOL)، compliance |
| **Dedicated Instances** | instances على hardware مش مشترك مع عملاء تانيين | — | عزل hardware من غير تحكم في الـ host |
| **On-Demand Capacity Reservations** | **ضمان سعة** في AZ، بسعر On-Demand | — | حدث مهم ولازم السعة تبقى موجودة |

(النسب «لحد» وبتختلف حسب النوع والمدة وطريقة الدفع. راجع صفحة الأسعار.)

### تفاصيل بتفرق

- **RI وSavings Plans خصم في الفاتورة**، مش سيرفر محجوز. لو عايز **ضمان سعة**، ده **Capacity Reservation** (أو RI zonal).
- **طريقة الدفع في الالتزام:** All Upfront (خصم أكبر)، Partial Upfront، No Upfront.
- **مدة أطول = خصم أكبر**: ٣ سنين أرخص من سنة، بس مخاطرة أكبر لو احتياجك اتغير.

### Data transfer: الفلوس اللي بتتنسي

| الاتجاه | غالبًا |
| --- | --- |
| من الإنترنت **لـ AWS** (inbound) | **مجاني** |
| من AWS **للإنترنت** (outbound) | **مدفوع** (بعد كمية مجانية شهرية) |
| بين **AZs** في نفس الـ Region | مدفوع في الاتجاهين غالبًا |
| بين **Regions** | مدفوع |
| جوه نفس الـ AZ بـ private IP | غالبًا مجاني |

CloudFront بيقلل الـ transfer من الـ origin، والـ VPC endpoints بتقلل مصاريف NAT. راجع صفحة الأسعار للمسار بتاعك.

## 🛠️ طبّق: احسب فاتورة دُكّان

الـ Lab ورقي، والأسعار **تخيلية** للتمرين.

**المعطيات:** سعر السيرفر On-Demand `$0.10/ساعة`. الشهر = ٧٣٠ ساعة.

1. **الوضع الحالي (كله On-Demand):**
   - Baseline: `4 × 730 × 0.10 = $292`
   - Peak (١٢ سيرفر × ٤ ساعات × ٣٠ يوم): `12 × 120 × 0.10 = $144`
   - Batch (٢ سيرفر × ٦ ساعات × ٣٠): `2 × 180 × 0.10 = $36`
   - **المجموع: `$472`**
2. **بعد التقسيم:**
   - Baseline على Savings Plan بخصم افتراضي ٤٠٪: `292 × 0.6 = $175.2`
   - Peak يفضل On-Demand: `$144`
   - Batch على Spot بخصم افتراضي ٧٠٪: `36 × 0.3 = $10.8`
   - **المجموع: `$330`** (توفير ~٣٠٪)
3. **فخ:** لو التزمت Savings Plan على **١٦ سيرفر** (الـ peak)، هتدفع على ١٢ سيرفر مش شغالين **٢٠ ساعة في اليوم**. الالتزام بيتعمل على الـ **baseline اللي متأكد منه**.
4. **فخ تاني:** لو حطيت سيرفر الـ checkout الوحيد على Spot، AWS ممكن تاخده وسط الفطار. Spot للشغل اللي **يستحمل**.

**في الحقيقة:** استخدم **AWS Pricing Calculator** للأرقام، و**Cost Explorer** بيقترح Savings Plans من استخدامك الفعلي (الفصل الجاي).

## ⚖️ قارن: الأسئلة اللي بتحسم

| الموقف | الاختيار |
| --- | --- |
| تطبيق جديد، الحمل مش معروف | **On-Demand** |
| حمل ثابت ٢٤/٧ لسنين، وعايز مرونة بين EC2 وLambda وFargate | **Compute Savings Plans** |
| حمل ثابت على نفس عائلة الـ instances في Region | **EC2 Instance Savings Plans** أو **Reserved Instances** |
| batch أو CI يستحمل الانقطاع | **Spot** |
| license مربوط بعدد sockets أو cores | **Dedicated Hosts** |
| لازم سعة مضمونة في AZ يوم حدث مهم | **Capacity Reservation** |
| database ثابتة على RDS لسنين | **RDS Reserved Instances** |

| | Savings Plans / RI | Capacity Reservation |
| --- | --- | --- |
| بيدّي | **خصم** | **ضمان سعة** |
| التزام | سنة أو ٣ | مفيش (بتدفع طول ما هي موجودة) |
