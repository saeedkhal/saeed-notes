## 🧠 افهم: أربع أسئلة عن الفلوس

عم حسن بيسأل عن الفلوس في أوقات مختلفة:

1. **قبل ما نبني:** «الفرع الجديد هيكلّف كام في الشهر؟»
2. **وإحنا بنصرف:** «نبّهني لو الشهر ده هيعدّي الميزانية.»
3. **بعد ما صرفنا:** «الفلوس راحت فين؟ وليه الشهر ده أعلى ٤٠٪؟»
4. **عشان نوفّر:** «في سيرفرات أكبر من اللازم؟ نشتري Savings Plan بكام؟»

كل سؤال ليه أداة. ولو استخدمت الأداة الغلط، هتاخد إجابة لسؤال تاني.

<Hl c="o">Pricing Calculator = قبل. Budgets وAnomaly Detection = أثناء (تنبيه). Cost Explorer وBills وCUR = بعد (تحليل). Compute Optimizer وTrusted Advisor = توصيات توفير.</Hl>

<Box type="story" icon="🧾" title="ميزانية البيت">

- **Pricing Calculator** = إنك تحسب مصاريف **الشقة الجديدة** على ورقة قبل ما تمضي العقد.
- **Budgets** = إنك تقول لمراتك «لو الصرف عدّى ٥٠٠٠ ابعتيلي رسالة».
- **Anomaly Detection** = البنك يبعتلك «في عملية غريبة على الكارت، مش زي عادتك».
- **Cost Explorer** = **كشف الحساب** آخر الشهر برسوم بيانية: الأكل كام، المواصلات كام.
- **CUR** = **كل إيصال** لوحده في ملف Excel.
- **Compute Optimizer** = حد يبصلك على البيت ويقولك «التكييف ده أكبر من الأوضة، هات أصغر».

</Box>

## 🔍 من جوه: كل أداة

### قبل: AWS Pricing Calculator

موقع مجاني بتحط فيه الخدمات والمواصفات والاستخدام المتوقع، ويطلّعلك **تقدير** شهري وسنوي تقدر تشاركه. **التقدير بيعتمد على افتراضاتك**: لو نسيت الـ data transfer أو الـ NAT، الرقم هيبقى أقل من الحقيقة.

### أثناء: التنبيهات

- **AWS Budgets:** تنبيه لما الـ cost أو الـ usage أو تغطية الـ Savings Plans/RI يعدّي حد (actual أو forecasted). **مش بيوقف الصرف** (فصل ١٠).
- **AWS Cost Anomaly Detection:** ML بيتعلم نمط صرفك وينبّهك على أي حاجة غريبة، من غير ما تحدد رقم.

### بعد: التحليل

- **Bills:** الفاتورة الرسمية لكل خدمة وRegion.
- **AWS Cost Explorer:** رسوم بيانية للصرف لحد ١٣ شهر لورا، **group by** خدمة أو حساب أو tag، و**forecast** لقدام، و**توصيات** Savings Plans وRI من استخدامك.
- **AWS Data Exports (CUR 2.0):** **كل line item** بالتفصيل في ملفات على S3، تحللها بـ Athena أو QuickSight. أدق حاجة، بس محتاجة شغل.
- **Cost allocation tags:** لازم **تفعّلها** في Billing عشان تظهر في التقارير، ومبتشتغلش بأثر رجعي كامل.
- **Consolidated billing** (Organizations): فاتورة واحدة لكل الحسابات، واستخدامهم بيتجمع للخصومات. **مبيدّيش صلاحيات** على الحسابات.

### التوفير: التوصيات

- **AWS Compute Optimizer:** بيحلل الـ metrics ويقول الـ EC2 أو Lambda أو EBS أو ECS **أكبر أو أصغر** من اللازم (rightsizing).
- **AWS Trusted Advisor:** فحوصات منها cost optimization (instances مش مستخدمة، EBS مش متركّب…).
- **Cost Optimization Hub:** بيجمع توصيات التوفير من كذا مصدر في مكان واحد ويرتبها بالتوفير المتوقع.

## 🛠️ طبّق: قدّر، نبّه، حلّل

⚠️ Pricing Calculator وCost Explorer (من الـ console) مجانيين. Cost Anomaly Detection مجاني. Budgets أول كام واحدة مجانية.

1. **قدّر فرع دُكّان الجديد:** افتح `calculator.aws` ← `Create estimate` ← ضيف:
   - Amazon EC2: ٢ instances `t3.small` ٢٤/٧.
   - Amazon RDS for PostgreSQL: `db.t4g.micro` Single-AZ، 20 GB.
   - Amazon S3: 50 GB Standard.
   - **متنساش** data transfer out: 100 GB/شهر.
   **المتوقع:** رقم شهري ولينك تشاركه. جرّب تغيّر RDS لـ Multi-AZ وشوف الرقم اتضاعف تقريبًا. ده تمن الـ availability.
2. **فعّل Anomaly Detection:** `Billing and Cost Management` ← `Cost Anomaly Detection` ← اعمل monitor على `AWS services` بتنبيه إيميل.
3. **حلّل في Cost Explorer:** `Cost Explorer` ← آخر ٣ شهور ← `Group by: Service`. بعدين `Group by: Tag` (لو فعّلت `Project`). **المتوقع:** تعرف أغلى ٣ خدمات.
4. **شوف التوصيات:** في Cost Explorer ← `Savings Plans` ← `Recommendations`. (لو الحساب جديد ممكن متلاقيش توصيات لسه.)

🧹 مفيش موارد مدفوعة اتعملت. امسح الـ monitor لو مش عايزه.

| السؤال | الأداة |
| --- | --- |
| «هيكلّف كام؟» قبل البناء | **Pricing Calculator** |
| «نبّهني لو عدّينا $X» | **Budgets** |
| «نبّهني لو في صرف غريب» من غير رقم | **Cost Anomaly Detection** |
| «الفلوس راحت فين؟» برسوم وforecast | **Cost Explorer** |
| «عايز كل سطر بالتفصيل في S3» | **Data Exports / CUR 2.0** |
| «كل فريق صرف كام؟» | **Cost allocation tags** + Cost Explorer |
| «فاتورة واحدة لـ ٢٠ حساب» | **Consolidated billing** (Organizations) |
| «السيرفر ده أكبر من اللازم؟» | **Compute Optimizer** |
| «فحوصات عامة للتكلفة والأمان والأداء» | **Trusted Advisor** |

| بيتلخبطوا | الفرق |
| --- | --- |
| Pricing Calculator ↔ Cost Explorer | Calculator = **تقدير قبل**. Explorer = **تحليل بعد** + forecast |
| Budgets ↔ Cost Explorer | Budgets = **تنبيه** على حد. Explorer = **تحليل** ورسوم |
| Cost Explorer ↔ CUR | Explorer = رسوم سريعة. CUR = **أدق تفاصيل** للتحليل الكبير |
| Compute Optimizer ↔ Trusted Advisor | Optimizer = **rightsizing** بالتفصيل من الـ metrics. TA = فحوصات **عامة** في كذا مجال |
