## 🧠 افهم: عم حسن عايز يفهم الأرقام

بعد سنة، عم حسن سأل أسئلة:

- «أكتر ١٠ منتجات اتباعت في رمضان؟»
- «الزباين بيسيبوا السلة في أنهي خطوة؟»
- «عايز شاشة على الموبايل فيها المبيعات **لحظة بلحظة**.»

داتا دُكّان متفرقة: طلبات في Aurora، clicks الموقع في logs، ملفات من المخزن CSV. ومش هينفع تعمل تقارير تقيلة على database الـ production (هتبطّأ الزباين).

الحل: نجمع الداتا في مكان للتحليل (غالبًا **S3 كـ data lake**)، نجهّزها، ونسألها بأداة مناسبة، ونعرضها في dashboard.

<Hl c="o">الداتا بتمشي في خط: تتجمع (Kinesis) ← تتخزن (S3) ← تتجهّز وتتفهرس (Glue) ← تتسأل (Athena أو Redshift أو EMR) ← تتعرض (QuickSight).</Hl>

<Box type="story" icon="🌾" title="من الغيط للسوبر ماركت">

- **Kinesis** = العربيات اللي بتنقل الخضار من الغيط **أول بأول**.
- **S3 data lake** = **المخزن الكبير** اللي كل حاجة بتتحط فيه زي ما هي.
- **Glue** = **عمال الفرز والتغليف**، وكمان **الدفتر** اللي مكتوب فيه كل صنف فين.
- **Athena** = إنك تسأل المخزن سؤال وتاخد الإجابة من غير ما تنقل حاجة.
- **Redshift** = **سوبر ماركت** منظّم ومرتب للأسئلة الكتير والسريعة.
- **QuickSight** = **اللافتة** اللي على الباب فيها العروض والأرقام.

</Box>

## 🔍 من جوه: كل خدمة ومرحلتها

### التجميع (ingest)

- **Amazon Kinesis Data Streams:** stream لحظي (clicks، IoT). إنت بتكتب consumers بيقروا منه في real time.
- **Amazon Data Firehose:** أبسط: بياخد الـ stream ويوصّله لـ S3 أو Redshift أو OpenSearch، وممكن يحوّل الصيغة، **من غير consumers تكتبها**.
- **Amazon MSK:** Apache Kafka مُدار، لو الفريق بيستخدم Kafka.

### التخزين والفهرسة

- **S3** هو الـ data lake: رخيص وبيشيل أي حجم وأي صيغة.
- **AWS Glue:** **ETL serverless** (يقرا، ينضّف، يحوّل)، و**Glue Data Catalog** (فهرس بأسماء الجداول والأعمدة وأماكنها في S3)، و**crawlers** بتكتشف الـ schema لوحدها.
- **AWS Lake Formation:** يبني data lake ويحط **صلاحيات دقيقة** (مين يشوف أنهي عمود).

### السؤال والمعالجة

- **Amazon Athena:** **SQL على ملفات S3 مباشرة**، serverless، بتدفع على الداتا اللي اتعملها scan. مثالي للأسئلة المتقطعة.
- **Amazon Redshift:** **data warehouse** للأسئلة الكتير والتقيلة على داتا منظمة (petabytes)، والـ BI. فيه **Redshift Serverless**.
- **Amazon EMR:** Spark وHadoop وغيرهم مُدارين، لمعالجة big data بأدوات open source.
- **Amazon OpenSearch Service:** بحث نصي وتحليل logs.

### العرض

- **Amazon QuickSight:** dashboards وتقارير BI تفاعلية (وفيه قدرات AI لأسئلة بالكلام، راجع الـ docs للاسم الحالي).

## 🛠️ طبّق: اسأل ملف مبيعات بـ SQL من غير database

⚠️ Athena بتتحاسب على الداتا اللي بتتعملها scan (ملف صغير = شبه صفر). نتايج الـ queries بتتحفظ في S3.

1. **اعمل ملف** `sales.csv`:

<File name="sales.csv">

```text
order_id,product,qty,price,city
1001,عيش بلدي,10,5,القاهرة
1002,جبنة رومي,1,120,الجيزة
1003,عيش بلدي,4,5,القاهرة
1004,زيت,2,95,إسكندرية
```

</File>

2. **ارفعه لـ S3** في فولدر لوحده:

```bash
aws s3 cp sales.csv s3://dukkan-lake-<رقم>/sales/sales.csv
```

3. **افتح Athena** ← اختار مكان للنتايج (bucket/فولدر `athena-results/`) ← واكتب:

```sql
CREATE EXTERNAL TABLE sales (
  order_id int, product string, qty int, price double, city string
)
ROW FORMAT DELIMITED FIELDS TERMINATED BY ','
LOCATION 's3://dukkan-lake-<رقم>/sales/'
TBLPROPERTIES ('skip.header.line.count'='1');

SELECT product, SUM(qty * price) AS revenue
FROM sales
GROUP BY product
ORDER BY revenue DESC;
```

**المتوقع:** جدول بالإيراد لكل منتج، والـ query بتقولك **Data scanned** قد إيه، وده اللي بتدفع عليه. لاحظ إن **مفيش database اتعملت**: الداتا لسه ملف في S3.

4. **فكّر:** لو الملفات بقت ١٠٠٠ ملف وبتتضاف كل يوم، مين يكتشف الأعمدة ويحدّث الجدول لوحده؟ (Glue crawler).

🧹 **تنضيف:** `DROP TABLE sales;` وامسح الـ bucket.

## ⚖️ قارن: الخدمات اللي بتتلخبط

| السؤال | الخدمة |
| --- | --- |
| SQL على ملفات في S3 من غير سيرفرات | **Athena** |
| data warehouse للـ BI والأسئلة التقيلة المتكررة | **Redshift** |
| تجهيز وتحويل الداتا (ETL) وفهرستها | **Glue** |
| Spark/Hadoop للـ big data | **EMR** |
| داتا لحظية محتاج تعالجها بنفسك | **Kinesis Data Streams** |
| داتا لحظية عايز توصلها لـ S3/Redshift وخلاص | **Data Firehose** |
| Kafka مُدار | **MSK** |
| بحث نصي وlogs | **OpenSearch Service** |
| dashboards | **QuickSight** |
| صلاحيات دقيقة على data lake | **Lake Formation** |

| | Athena | Redshift |
| --- | --- | --- |
| الداتا فين | في S3 زي ما هي | محمّلة في الـ warehouse (وتقدر تقرا من S3 كمان) |
| مناسب لـ | أسئلة متقطعة واستكشاف | dashboards وأسئلة كتير ومتكررة |
| الدفع | على الـ scan | على السعة أو الاستخدام (Serverless) |
