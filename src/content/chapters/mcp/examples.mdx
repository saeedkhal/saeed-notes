الصفحة بتعرض سيرفرات بتوضح قدرات البروتوكول، وبتخلي الموديل يوصل بأمان لأدوات ومصادر داتا.

## المرجعية الحالية

- **Everything**: اختبار ومرجع فيه قوالب وموارد وأدوات. استخدمه لما تجرب كلاينت جديد وعايز كل الـ <En>primitives</En>.
- **Fetch**: جلب محتوى الويب وتحويله لاستخدام أوفر مع الموديل.
- **Filesystem**: عمليات ملفات بضوابط وصول تتظبط.
- **Git**: قراءة ريبو والبحث فيه والتعديل عليه.
- **Memory**: ذاكرة دائمة على رسم معرفة.
- **Sequential Thinking**: تفكير متسلسل وتأمل على خطوات.
- **Time**: الوقت وتحويل المناطق.

ريبو الأرشيف فيه أمثلة مش متصانة، للمرجع التاريخي بس. قسم التكاملات الرسمية سيرفرات بتصونها شركات لمنصاتها. قسم المجتمع سيرفرات من بره.

## التشغيل

سيرفرات <En>TypeScript</En> عن طريق <En>npx</En>. سيرفرات <En>Python</En> الطريقة الموصى بيها <En>uvx</En>، وفي بديل تثبيت ثم تشغيل الموديول. راجع الدوكس لأن أسماء الحزم بتتغير.

<File name="mcp.json">

```json
{
  "mcpServers": {
    "memory": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-memory"]
    },
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/allowed/files"]
    }
  }
}
```

</File>

سيرفر <En>GitHub</En> محتاج توكن في <En>env</En>، ومتحطش التوكن في الكود. موارد زيادة ونقاش المجتمع في ريبو السيرفرات على <En>GitHub</En>.
