`ufw` برنامج جدار ناري على السيرفر. إنت اللي تقول له أنهي بورت يعدّي. هو مش بيختار لوحده.

على Ubuntu غالبًا مش متثبّت، أو متثبّت ومش مفعّل. التثبيت حاجة. التشغيل حاجة تانية.

## ثبّته

<File name="terminal">

```bash
sudo apt update
sudo apt install ufw
sudo ufw version
```

</File>

الأمر الأخير يطبع رقم النسخة. لو طبع رقم، الحزمة موجودة.

## فعّله بالترتيب ده

لو فعّلت الجدار الناري قبل ما تسمح بـ SSH، هتقفل على نفسك باب السيرفر.

<File name="terminal">

```bash
sudo ufw allow OpenSSH
sudo ufw allow 443/tcp
sudo ufw allow 80/tcp
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw enable
sudo ufw status verbose
```

</File>

اقرأ السطور بالترتيب:

1. اسمح بـ SSH الأول.
2. اسمح بـ HTTPS على `443`.
3. اسمح بـ HTTP على `80` عشان التحويل.
4. اقفل باقي الوارد.
5. سيّب الصادر مفتوح. السيرفر محتاج يخرج نت.
6. شغّل الجدار الناري. هيسألك تؤكد.
7. اطبع الحالة. المفروض تشوف `active`، وتشوف `80` و`443` و`OpenSSH`.

<Hl c="o">SSH الأول. التفعيل آخر حاجة.</Hl>

`ufw enable` بيفضّل شغّال بعد ريستارت السيرفر. مش هيتقفل لوحده. تقدر تطفي بـ `sudo ufw disable`.

<Box type="warn" title="بورت SSH مش دايمًا 22">

`OpenSSH` بيفتح البورت الافتراضي. لو SSH عندك على رقم تاني، اسمح بالرقم ده قبل `enable`. مثال: `sudo ufw allow 2222/tcp`.

لو الاستضافة عندها جدار ناري في اللوحة، راجع اللوحة قبل ما تشغّل UFW على الجهاز. الاتنين ممكن يتعارضوا.

</Box>

## الناتج

| البورت | من الإنترنت |
| --- | --- |
| SSH | مفتوح للإدارة |
| `80` | مفتوح عشان التحويل |
| `443` | مفتوح للموقع |
| الباقي | مقفول |

SSH يفضل تقييده على IP مكتب أو VPN لو تقدر. الموضوع هنا بيفتحه عشان متتقفلش بره.
