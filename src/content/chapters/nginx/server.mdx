## تلات مفاتيح

كل موقع بلوك `server`:

- **`listen`:** البورت اللي Nginx سامع عليه. من غيره البورت 80.
- **`server_name`:** الدومين اللي البلوك ده يخصه. Nginx يختار البلوك بالاسم، وده SNI مع SSL.
- **`location`:** مسار جوه الموقع، وده مكان قرار التوجيه.

<File name="/etc/nginx/sites-available/app">

```nginx
server {
    listen 80;
    server_name app.example.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
    }
}
```

</File>

مكان الملف بيعتمد على **مين اللي نزّل الحزمة**:

- **حزمة Ubuntu نفسها:** الملف في `sites-available`، وNginx يقرا اللي متوصل في `sites-enabled`.
- **حزم nginx.org:** مفيش `sites-enabled`. حط بلوك `server` في ملف جوه `/etc/nginx/conf.d/` وخليه يخلص بـ `.conf`.

```bash
sudo ln -s /etc/nginx/sites-available/app /etc/nginx/sites-enabled/app
sudo nginx -t
```

الوصلة دي لحزمة Ubuntu. مع حزم nginx.org يكفي الملف جوه `conf.d`. البلوك نفسه واحد.

<Box type="tip" title="default_server">

لو الطلب جه من غير دومين مطابق، Nginx يديه للبلوك المعلم `default_server` على نفس البورت. علّم بلوك واحد بس: `listen 80 default_server;`.

</Box>
