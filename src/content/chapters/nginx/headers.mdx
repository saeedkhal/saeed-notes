## التطبيق محتاج يعرف الزائر جه إزاي

من غير الهيدرز، التطبيق يشوف إن الطلب من `127.0.0.1` وعلى HTTP، حتى لو الزائر فاتح HTTPS على الدومين.

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

- **`Host`:** الدومين اللي الزائر كتبه. من غيره الكوكيز واللينكات تتظبط على اسم غلط.
- **`X-Real-IP` و`X-Forwarded-For`:** عنوان الزائر، مش عنوان Nginx.
- **`X-Forwarded-Proto`:** `https` أو `http`. التطبيق يبني لينكات صح.

## WebSocket والرفع

WebSocket بيطلب ترقية الاتصال. من غير السطرين دول الاتصال يقع بعد أول رسالة:

```nginx
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
```

وحد الرفع الافتراضي صغير. لرفع صور أو فيديو:

```nginx
client_max_body_size 20m;
```

ولو التطبيق بيطوّل، زوّد `proxy_read_timeout`. راجع الـ docs للقيمة المناسبة، لأن المهلة القصيرة بتقطع طلب سليم.
