## تلات طرق

صفحة التثبيت الرسمية بتفرّق التثبيت على النظام:

- **Linux:** حزم من nginx.org، بعد ما تضيف الريبو بتاعهم. مش نفس حزمة `apt install nginx` اللي جاية من Ubuntu نفسها.
- **FreeBSD:** يا من الحزم الجاهزة، يا من نظام الـ ports. الـ ports أبطأ وأمرن، لأنك تختار الخيارات وهو يترجّم ويثبّت.
- **من المصدر:** لو محتاج وظيفة مش موجودة في الحزم ولا في الـ ports. أمرن، وأصعب على حد لسه بادئ. التفاصيل في صفحة بناء Nginx من المصدر.

قبل أول تثبيت على جهاز جديد، الريبو يتظبط مرة. بعد كده التثبيت والتحديث من نفس الريبو.

## stable ولا mainline

ريبو **stable** هو الافتراضي: إصلاحات وأخطاء أمان على خط ثابت. **mainline** فيه الميزات الجديدة. متنزلهمش الاتنين مع بعض. أرقام الإصدارات على صفحة التحميل بتتغير، فراجعها قبل ما تثبّت.

وقت مراجعة الصفحة، التوزيعات المدعومة كانت:

| العيلة | الإصدارات | المعمارية |
| --- | --- | --- |
| RHEL وفروعه | 8 و9 و10 | x86_64 وarm64 |
| Debian | 11 و12 و13 | x86_64 وarm64 |
| Ubuntu | 22.04 و24.04 و26.04 | x86_64 وarm64 |
| SLES | 15 SP6 وما بعده، و16 | 15 على x86_64، و16 على x86_64 وarm64 |
| Alpine | 3.21 لحد 3.24 | x86_64 وarm64 |
| Amazon Linux | 2023 | x86_64 وarm64 |

فروعه RHEL المذكورة: CentOS وOracle Linux وRocky وAlma.

## Ubuntu

المتطلبات، وبعدين مفتاح التوقيع، وبعدين الريبو، وبعدين تثبيت. البصمة اللي لازم تظهر: `573BFD6B3D8FBC641079A6ABABF5BD827BD9BF62`. الصفحة كانت بتوري المفتاح صالح لحد 24 مايو 2027، وفيها مفاتيح تانية ممكن تظهر في نفس الناتج. راجع الصفحة لو التاريخ عدّى.

```bash
sudo apt install curl gnupg2 ca-certificates lsb-release ubuntu-keyring
curl https://nginx.org/keys/nginx_signing.key | gpg --dearmor \
  | sudo tee /usr/share/keyrings/nginx-archive-keyring.gpg >/dev/null
gpg --dry-run --quiet --no-keyring --import --import-options import-show \
  /usr/share/keyrings/nginx-archive-keyring.gpg
```

ريبو stable. لو عايز mainline، بدّل المسار بـ `packages/mainline/ubuntu` في نفس السطر.

```bash
echo "deb [signed-by=/usr/share/keyrings/nginx-archive-keyring.gpg] \
https://nginx.org/packages/ubuntu $(lsb_release -cs) nginx" \
  | sudo tee /etc/apt/sources.list.d/nginx.list
```

التفضيل ده عشان حزم nginx.org تكسب حزمة Ubuntu لو الاتنين موجودين. الأولوية 900.

<File name="/etc/apt/preferences.d/99nginx">

```text
Package: *
Pin: origin nginx.org
Pin: release o=nginx
Pin-Priority: 900
```

</File>

```bash
sudo apt update
sudo apt install nginx
```

Debian نفس الخطوات، مع فرقين: الحزمة `debian-archive-keyring` بدل `ubuntu-keyring`، والمسار `packages/debian` بدل `packages/ubuntu`.

## RHEL وAmazon وSLES وAlpine

على RHEL والفروع: ثبّت `yum-utils`، واعمل ملف `/etc/yum.repos.d/nginx.repo`. فيه بلوك `nginx-stable` شغّال وبلوك `nginx-mainline` مقفول. عنوان stable هو `https://nginx.org/packages/centos/$releasever/$basearch/` ومعاه `gpgcheck=1` و`module_hotfixes=true` والمفتاح `https://nginx.org/keys/nginx_signing.key`. mainline نفس الشكل تحت `packages/mainline/centos` و`enabled=0`. تشغيل mainline بأمر `sudo yum-config-manager --enable nginx-mainline`، والتثبيت `sudo yum install nginx`. لما يطلب قبول المفتاح، طابقه على البصمة `573B FD6B 3D8F BC64 1079 A6AB ABF5 BD82 7BD9 BF62`.

Amazon Linux نفس الفكرة وملف الريبو، مع `priority=9`. عنوان Amazon Linux 2 فيه `amzn2`. عنوان 2023 هو `https://nginx.org/packages/amzn/2023/$basearch/` من غير `$releasever`. mainline تحت `packages/mainline/amzn/2023` أو `amzn2`. التثبيت برضه `sudo yum install nginx` بعد `yum-utils`.

SLES: المتطلبات `curl` و`ca-certificates` و`gpg2`. الريبو بأمر `zypper addrepo` ونوعه yum، وعنوان stable هو `https://nginx.org/packages/sles/$releasever_major`. mainline تحت `packages/mainline/sles`. المفتاح يتنزّل ويتفحص بـ `gpg --with-fingerprint`، وبعدين `sudo rpmkeys --import`، والتثبيت `sudo zypper install nginx`.

Alpine: المتطلبات `openssl` و`curl` و`ca-certificates`. سطر الريبو يتضاف في `/etc/apk/repositories` بعلامة `@nginx` وعنوان `packages/alpine/v` زائد رقم الإصدار من `/etc/alpine-release` زائد `/main`. mainline تحت `packages/mainline/alpine`. المفتاح ملف `nginx_signing.rsa.pub` مش مفتاح PGP النصي. الأمر `openssl rsa -pubin -in الملف -text -noout` يطلّع modulus، وتقارنه بالنص على صفحة الحزم. بعد كده المفتاح يتتنقل لـ `/etc/apk/keys/`. التثبيت `sudo apk add nginx@nginx`. علامة `@nginx` لازمة كمان مع حزم الوحدات الديناميكية.

## وحدات مش في الحزمة الأساسية

الحزمة الأساسية فيها الوحدات اللي مش محتاجة مكتبات زيادة، عشان متجيبش اعتمادات زيادة. من 1.9.11 الوحدات دي حزم لوحدها: `nginx-module-geoip` و`nginx-module-image-filter` و`nginx-module-njs` و`nginx-module-perl` و`nginx-module-xslt`. من 1.25.3 اتضافت `nginx-module-otel`. من 1.29.1 اتضافت `nginx-module-acme`.

مصادر تغليف الحزم في ريبو منفصل. فرع `master` للتغليف بتاع mainline الحالي، وفروع `stable-*` لآخر مصادر الخط الثابت. بناء الحزم: `make` جوه `debian/` على Debian وUbuntu، أو `rpm/SPECS/` على RHEL وSLES وAmazon Linux، أو `alpine/` على Alpine. الترخيص نفس ترخيص nginx، شبه BSD من بندين.

المفتاح والحزم على نفس السيرفر، فالثقة فيهم متساوية. الصفحة بتنصح تتحقق من المفتاح بسلسلة توقيعات (Web of Trust)، مش لأنه نازل من nginx.org بس.

## من المصدر

بعد ما تنزّل الأرشيف من صفحة التحميل: `./configure` ثم `make` ثم `sudo make install`. `./configure` بيكتب `Makefile` وبيختار طريقة معالجة الاتصالات.

المسار الافتراضي `/usr/local/nginx`. الإعداد `conf/nginx.conf`، واللوج `logs/error.log`، وملف الـ pid `logs/nginx.pid`. تقدر تغيّر الإعداد وقت التشغيل بـ `nginx -c`. عامل الشغل الافتراضي اسمه `nobody`.

وحدة HTTPS **مش مبنية افتراضيًا**. عشان فصل الشهادة يشتغل من بناء بإيدك، لازم `--with-http_ssl_module` ومكتبة OpenSSL. HTTP/2 وHTTP/3 كمان مش افتراضيين، وHTTP/3 محتاج OpenSSL يدعمهم. قائمة الأعلام طويلة (مسارات، ومكتبات، ووحدات تتفتح أو تتقفل). راجع صفحة البناء من المصدر قبل ما تثبّت أعلام زيادة.

<Box type="warn" title="حزمتين بنفس الاسم">

`apt install nginx` من غير ريبو nginx.org يديك نسخة Ubuntu، وملفاتها في `sites-available`. حزم nginx.org أحدث، وملفات المواقع في `/etc/nginx/conf.d`. متخلّطش الاتنين من غير سطر الأولوية، وإلا التحديث ممكن يرجّع حزمة التوزيعة.

</Box>
