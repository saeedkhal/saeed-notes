## المطلوب

رفع وتنزيل ملفات، مزامنة بين الأجهزة، مشاركة، إشعارات، ونسخ قديمة. أهم متطلب: <Hl c="p">الداتا متضيعش أبدًا</Hl>.

## المكونات

| المكون | دوره |
| --- | --- |
| Block Servers | يقسموا الملف blocks (مثلًا ٤MB). كل block ليه hash، يتضغط ويتشفّر ويترفع على cloud storage |
| Metadata DB | بيانات الملفات والنسخ والـ blocks. Relational عشان نحتاج strong consistency (ACID) |
| Notification Service | يبلّغ الأجهزة التانية إن فيه تغيير. Long polling كفاية لأن الإشعارات قليلة ومش محتاجة WebSocket |
| Offline Backup Queue | يحفظ التغييرات لجهاز أوفلاين لحد ما يرجع |
| Cold Storage | للملفات اللي ماحدش بيفتحها — أرخص بكتير |

## Delta Sync

عدّلت سطر في ملف كبير؟ بيرتفع الـ block اللي اتغير بس، مش الملف كله. توفير ضخم في الباندويدث.

<Box type="warn" title="تعارض المزامنة">

اتنين عدلوا نفس الملف في نفس الوقت؟ اللي وصل الأول يكسب، والتاني يتعمله conflict ويتعرضله النسختين يختار أو يدمج.

</Box>

## توفير المساحة والاعتمادية

- **De-duplication:** blocks بنفس الـ hash تتخزن مرة واحدة. لو اتنين رفعوا نفس الـ PDF، الديسك يشوفه مرة.
- حد أقصى لعدد النسخ القديمة، والأولوية للنسخ الجديدة.
- الـ metadata DB والـ storage فيهم replication في كذا ريجن.
- لو notification server وقع، الـ clients يتوصلوا بسيرفر تاني.

<Box type="story" title="تشبيه">

الملف مش شنطة واحدة بتسافر كل مرة. ده صندوق مقسوم أدراج (blocks). غيّرت ورقة في درج؟ تبعت الدرج ده بس. ولو نفس الدرج موجود عند جارك، المخزن مش يشتريه تاني.

</Box>
