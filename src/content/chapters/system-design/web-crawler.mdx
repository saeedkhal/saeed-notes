## بيعمل إيه؟

روبوت بيلف على الويب: ينزّل صفحات، يطلع منها لينكات، وينزّلها هي كمان. بيتستخدم في محركات البحث، الأرشفة، والتنقيب في الداتا. المطلوب: <Hl c="o">scalable، مؤدب مع المواقع، robust، وسهل تضيف عليه</Hl>.

وبعد الـ parser: هل المحتوى ده شوفناه؟ نطلّع اللينكات، نفلترها، نشوف اللينك ده اتزار قبل كده ولا لأ، ونرجّعه للـ frontier.

- **Content seen:** قارن hash الصفحة بدل ما تقارنها حرف حرف. حوالي ٢٩٪ من الويب مكرر.
- **URL seen:** Bloom filter أو hash table عشان متزورش نفس اللينك مرتين.

## الـ Deep dive

| الموضوع | الفكرة |
| --- | --- |
| BFS مش DFS | الويب عميق جدًا، فالـ BFS أنسب. بس الـ BFS العادي ممكن يضرب نفس الموقع بريكوستات كتير |
| Politeness | طابور لكل host، و worker واحد لكل طابور مع delay بين الريكوستات |
| Priority | رتّب اللينكات حسب الأهمية: PageRank، الترافيك، سرعة التحديث |
| Freshness | أعد زيارة الصفحات حسب تاريخ تحديثها وأهميتها |
| robots.txt | احترم اللي الموقع مش عايزك تزحف عليه، وكاش الملف |
| Performance | زحف موزّع، DNS cache، سيرفرات قريبة جغرافيًا، و timeout قصير |
| Spider traps | لينكات لا نهائية زي `/a/b/a/b/...` — حط حد أقصى لطول اللينك وفلترة |

<Box type="story" title="تشبيه">

الـ crawler زي مندوب بيجيب منيو من كل مطعم في المدينة. لو دخل مطعم واحد وفضل يطلب منيو كل ثانية، هيتطرد. الأدب = طابور لكل مطعم، واستنى شوية بين الطلبات، واقرأ اللافتة اللي على الباب (`robots.txt`).

</Box>

<Box type="tip" title="كمان">

تجاهل الـ spam والإعلانات. الصفحات اللي بتعتمد على JS محتاجة server-side rendering عشان تشوف المحتوى. والباقي زي أي سيستم كبير: replication و sharding و analytics.

</Box>
