## التفاصيل المهمة

| الموضوع | الفكرة |
| --- | --- |
| Reliability | احفظ الإشعار في notification log عشان تعيد لو فشل. الـ exactly-once صعب، فاستخدم dedupe بالـ event ID |
| Templates | قوالب جاهزة بتوحّد الشكل وتقلل الغلط |
| Settings | اليوزر يختار يستقبل إيه وعلى أنهي قناة (opt-in) |
| Rate limiting | متغرّقش اليوزر، وإلا هيقفل الإشعارات خالص |
| Retry | فشل؟ يرجع للطابور. لو اتكرر الفشل، نبعت alert للمطورين |
| Security | `appKey` و `appSecret` عشان الـ clients الموثوقين بس هم اللي يبعتوا |
| Monitoring | راقب عدد الرسايل في الطابور (لو كبر، زوّد workers)، وتابع open rate و click rate |
