## المطلوب

تاخد لينك طويل وترجع لينك قصير، ولما حد يفتح القصير يتحوّل للطويل. <Hl c="y">السيستم ده قراءته أكتر بكتير من كتابته</Hl> — زي مطعم الناس بتيجي تاكل فيه أكتر ما بتطلب منيو جديد.

## الـ API ونوع التحويل

- `POST /api/v1/data/shorten` يرجّع اللينك القصير.
- `GET /api/v1/shortUrl` يعمل redirect للطويل.

## الـ hash يبقى طوله كام؟

بنستخدم حروف `[0-9a-zA-Z]` = ٦٢ حرف. ٧ حروف = `62⁷` ≈ ٣٫٥ تريليون. كفاية جدًا لمعظم الحالات.

| الطريقة | إزاي | ملاحظات |
| --- | --- | --- |
| Hash + تصادم | تعمل hash (زي SHA-1) وتاخد أول ٧ حروف. لو اتكرر، تزود حاجة وتعيد | لازم تسأل الداتابيز كل مرة. Bloom filter يساعد |
| Base62 من ID | تاخد ID فريد (من فصل المولّد) وتحوّله لـ base62 | مفيش تصادم. طوله بيتغير، والـ ID الجاي ممكن يتخمّن |
