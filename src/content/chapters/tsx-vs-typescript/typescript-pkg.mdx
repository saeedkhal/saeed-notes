## الحزمة بتدي مترجم

`pnpm add -D typescript` بيثبت أمر واحد: `tsc`. النسخة اللي اتجرّبت هنا `7.0.2`.

`tsc` بيعمل حاجتين، ومش بيعمل التالتة:

- **بيفحص الأنواع** على `tsconfig.json`.
- **يقدر يكتب JavaScript** في `dist` لو `noEmit` مش شغّال.
- **مش بيشغّل** الملف. مفيش `console.log` هيظهر من `tsc` نفسه.

## الفحص بيقف على الغلط

الملف ده فيه نوع غلط: السن متعرّف `number` والقيمة نص.

<File name="bad.ts">

```ts
const age: number = "٣٠";
console.log(age.toFixed(0));
```

</File>

`pnpm exec tsc --noEmit` وقف وطلع:

```text
bad.ts(1,7): error TS2322: Type 'string' is not assignable to type 'number'.
```

السطر التاني متتنفّذش، لأن `tsc` مش برنامج تشغيل. `--noEmit` يعني افحص بس ومتكتبش ملفات.

## الإخراج بيشيل النوع

ملف سليم:

<File name="src.ts">

```ts
export const n: number = 1;
```

</File>

مع `outDir` قيمته `dist`، الأمر `tsc` كتب `dist/src.js` بالشكل ده:

```js
export const n = 1;
```

النوع `: number` اختفى. الملف الناتج JavaScript يتشغّل بعد كده بـ `node dist/src.js`.

<Box type="tip" title="حط الحزمة في devDependencies">

`tsc` أداة بناء وفحص، مش جزء من البرنامج وهو شغّال. بعد ما `dist` يطلع، السيرفر يشغّل JavaScript بـ `node` من غير ما حزمة `typescript` تكون موجودة.

</Box>
