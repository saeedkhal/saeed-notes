## الحزمة بتشغّل

`pnpm add -D tsx` بيثبت أمر `tsx`. النسخة اللي اتجرّبت `4.23.15`، ووصفها في الحزمة: Node متعزّز بـ esbuild عشان يحمّل TypeScript.

اللي بيحصل جوه:

- **esbuild يشيل الأنواع** ويحوّل الملف لـ JavaScript بسرعة.
- **Node يشغّل** الناتج.
- **مفيش فحص أنواع.** الحزمة مش محتاجة `typescript` عشان تشتغل، بس من غير `tsc` الغلط النوعي مش هيتصاد.

أوامرها الأساسية: `tsx file.ts`، و`tsx watch file.ts` عشان يعيد التشغيل لما الملف يتغيّر، و`tsx --tsconfig` لو مسار الـ config مش الافتراضي. ينفع كمان `node --import tsx file.ts`.

## نفس الملف الغلط بيعدّي

على `bad.ts` من الفصل اللي فات، `pnpm exec tsx bad.ts` **مشتغلش الفحص**. الملف اشتغل، ووقع هنا:

```text
TypeError: age.toFixed is not a function
```

القيمة كانت النص `"٣٠"`، و`toFixed` مش موجودة على النص. `tsc` كان مسك الغلط قبل التنفيذ برسالة `TS2322`. `tsx` ساب الغلط يعدّي.

<Hl c="o">سرعة `tsx` جاية من إنها مش بتعمل شغل `tsc`.</Hl>

## ملف `.tsx` و`enum`

Node 26 بيشيل أنواع TypeScript البسيطة من ملف `.ts` لوحده، من غير حزمة `tsx`. في حاجات لسه محتاجة الحزمة:

- **الامتداد `.tsx`:** `node hi.tsx` طلّع `ERR_UNKNOWN_FILE_EXTENSION` للامتداد `.tsx`. `tsx hi.tsx` طبع الناتج عادي.
- **الـ `enum`:** `node enum.ts` طلّع `ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX` وقال إن الـ enum مش مدعوم في وضع الشيل بس. `tsx enum.ts` طبع القيمة `s`.

<File name="enum.ts">

```ts
enum Size { S = "s", M = "m" }
console.log(Size.S);
```

</File>

يعني Node لوحده مش بديل كامل لحزمة `tsx`، و`tsx` مش بديل لفحص `tsc`.
