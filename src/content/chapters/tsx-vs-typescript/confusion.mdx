## الاسم مش الوظيفة

الكلمة `tsx` بتيجي في تلات أماكن، وكل مكان معناه مختلف:

| الاسم | ده إيه | بيعمل إيه |
| --- | --- | --- |
| `.tsx` | امتداد ملف | TypeScript مكتوب فيه JSX، زي زرار React |
| `typescript` | حزمة على npm | بتثبت أمر `tsc` عشان الفحص والـ compile |
| `tsx` | حزمة تانية على npm | بتشغّل `.ts` و`.tsx` على Node |

<Hl c="y">تثبيت `typescript` مش بيدي أمر `tsx`، وتثبيت `tsx` مش بيفحص الأنواع.</Hl>

## ملف `.tsx` مالوش دعوة بالحزمة

الملف ده TypeScript عادي، بس مسموح فيه بـ JSX:

<File name="Button.tsx">

```tsx
type Props = { label: string };

export function Button({ label }: Props) {
  return <button>{label}</button>;
}
```

</File>

عشان `tsc` يفهم السطر اللي فيه `<button>`، لازم `jsx` في `tsconfig.json`. ده إعداد في حزمة `typescript`، مش الحزمة التانية.

ولو عايز **تشغّل** ملف `.tsx` بأمر `node` لوحده، Node 26 بيرفض الامتداد. ده اللي هنشوفه في فصل حزمة `tsx`.
