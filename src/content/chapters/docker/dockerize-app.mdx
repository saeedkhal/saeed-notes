## الـ instructions الأساسية

| الـ instruction | بيعمل إيه |
| --- | --- |
| `FROM` | الـ base image |
| `WORKDIR` | فولدر الشغل جوه الـ image (ويتعمل لو مش موجود) |
| `COPY` | ينسخ ملفات من الـ build context للـ image |
| `RUN` | أمر وقت البناء، بيعمل طبقة |
| `ENV` | متغيّر بيئة ثابت في الـ image |
| `EXPOSE` | توثيق للبورت اللي التطبيق بيسمع عليه (مش بيفتحه) |
| `USER` | يشغّل اللي بعده بمستخدم معين بدل root |
| `CMD` | الأمر الافتراضي لما الـ container يقوم |

## سر السرعة: الـ layer cache

كل instruction بتعمل طبقة، و Docker بيعمل **cache** لكل طبقة. لو الطبقة وكل اللي قبلها متغيّروش، بيستخدم الكاش. أول ما طبقة تتغيّر، <Hl c="o">كل اللي بعدها يتبني من جديد</Hl>.

عشان كده الترتيب مهم: الحاجات اللي بتتغير قليل (الـ dependencies) فوق، والحاجات اللي بتتغير كتير (الكود) تحت.

<Box type="story" icon="🥙" title="ساندوتش الشاورما">

لو غيّرت الصوص، مش هتعيد شوي اللحمة من الأول. بس لو غيّرت اللحمة، لازم تعيد كل اللي فوقها. حط اللحمة (`npm ci`) تحت، والصوص (الكود) فوق.

</Box>

## 🧪 Lab: API بـ Node

<File name="Dockerfile">

```dockerfile
FROM node:22-alpine
WORKDIR /app

# انسخ ملفات الـ dependencies الأول بس → الكاش يفضل شغال لما الكود يتغير
COPY package.json package-lock.json ./
RUN npm ci --omit=dev

# بعدين الكود
COPY . .

ENV NODE_ENV=production
EXPOSE 3000
USER node
CMD ["node", "src/index.js"]
```

</File>

<Box type="warn" title="الغلطة المشهورة">

لو كتبت `COPY . .` **قبل** `npm ci`، أي تعديل في أي ملف كود هيكسر الكاش ويعيد تسطيب كل الـ packages في كل build.

</Box>

ولو بتستخدم pnpm، فعّله بـ `corepack enable` جوه الـ image وانسخ `pnpm-lock.yaml` بدل `package-lock.json` (راجع الـ docs لأمر التسطيب المناسب).

## .dockerignore

زي `.gitignore` بس للـ build context. من غيره، `COPY . .` هينسخ `node_modules` بتاعتك (وممكن تكون لنظام تشغيل تاني!) و `.env` بأسرارك.

<File name=".dockerignore">

```text
node_modules
dist
.git
.env
*.log
Dockerfile
docker-compose.yml
```

</File>

## 🧪 Lab: React app بـ multi-stage

React بعد الـ build مجرد ملفات static. مش محتاج Node في الـ production خالص، محتاج web server زي nginx. هنا ييجي الـ <En>multi-stage build</En>: stage يبني، و stage تاني ياخد الناتج بس.

<File name="Dockerfile">

```dockerfile
# Stage 1: البناء
FROM node:22-alpine AS build
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci
COPY . .
RUN npm run build

# Stage 2: التشغيل — nginx بس + ملفات الـ build
FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
EXPOSE 80
```

</File>

<Flow items={[{"t": "build stage", "c": 1, "s": "node + node_modules + كود ≈ مئات الميجات"}, "→", {"t": "COPY --from", "c": 3, "s": "dist بس"}, "→", {"t": "final image", "c": 5, "s": "nginx + static ≈ عشرات الميجات"}]} />

<Box type="tip" title="SPA و nginx">

لو بتستخدم client-side routing (React Router أو TanStack Router)، nginx محتاج يرجّع `index.html` لأي مسار مش موجود، وإلا الـ refresh على `/about` هيدّي 404. ده بيتعمل بسطر `try_files` في config بتاع nginx، راجع الـ docs.

</Box>

<Box type="warn" title="متغيّرات البيئة في React">

متغيّرات زي `VITE_API_URL` بتتحط في الكود **وقت الـ build**، مش وقت التشغيل. يعني `-e` على الـ container مش هيغيّرها. لو محتاجها تختلف، مرّرها كـ `ARG` وقت البناء أو اعمل config بيتحمّل وقت التشغيل.

</Box>
