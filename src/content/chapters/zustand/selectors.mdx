السليكتور اللي يرجّع قيمة ثابتة المقارنة بـ <En>Object.is</En>: رقم، نص، أو نفس الدالة. المكوّن يعيد الرسم لما القيمة دي تتغير.

من الإصدار الخامس، كائن جديد في كل نداء يعتبر قيمة مختلفة حتى لو الحقول زي بعض. السطر ده يعمل لوب تحديث:

<File name="loop.jsx">

```jsx
const { items, add } = useCart((state) => ({
  items: state.items,
  add: state.add,
}));
```

</File>

الحل الأنضف: سليكتور لكل حقل. مفيش غلاف جديد.

<File name="split.jsx">

```jsx
const items = useCart((state) => state.items);
const add = useCart((state) => state.add);
```

</File>

## useShallow

لو محتاج كذا حقل في نداء واحد، لف السليكتور بـ <En>useShallow</En>. المقارنة تبقى على الحقول، مش على الغلاف.

<File name="shallow-pick.jsx">

```jsx
import { useShallow } from "zustand/react/shallow";

const { items, note } = useCart(
  useShallow((state) => ({ items: state.items, note: state.note })),
);
```

</File>

نفس الفكرة لمصفوفة مفاتيح بتتبني كل مرة: طالما العناصر بالمقارنة السطحية زي القديم، مفيش رسم زيادة.

<En>shallow</En> دالة المقارنة نفسها، لو حابب تمرّرها بإيدك. <En>useShallow</En> بيركّبها على السليكتور.

## مساواة على الهوك كله

<En>createWithEqualityFn</En> زي <En>create</En>، بس كل سليكتور يتقارن بالدالة اللي تديها. <En>useStoreWithEqualityFn</En> نفس الفكرة على متجر vanilla. الاتنين من مدخل <En>zustand/traditional</En>. راجع المسار في الدوكس.

ده أنسب لو أغلب القراءات بترجع كائنات. لالتقاط حقول قليلة، <En>useShallow</En> أحدّ.

## سليكتورات تتولد

المكتبة مش بتصدّر مولّد. الوصفة تمشي على مفاتيح <En>getState</En> وتعمل لكل مفتاح دالة <En>use.field</En> بتنادي السليكتور. في حزم خارجية بتعمل كده، زي <En>auto-zustand-selectors-hook</En>. الوصفة دي مش بتستبدل <En>useShallow</En> لو بترجع كائن مركّب.
