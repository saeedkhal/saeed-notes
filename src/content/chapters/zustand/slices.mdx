المتجر الواحد يتقسم دوال. كل دالة ترجع حقولها وأكشناتها، وتاخد نفس <En>set</En> و <En>get</En>.

<File name="slices.js">

```jsx
const createItems = (set) => ({
  items: [],
  add: (item) => set((state) => ({ items: [...state.items, item] })),
});

const createDiscount = (set, get) => ({
  rate: 0,
  apply: (rate) => set({ rate }),
  total: () => get().items.reduce((sum, item) => sum + item.price, 0),
});

const useShop = create((...args) => ({
  ...createItems(...args),
  ...createDiscount(...args),
}));
```

</File>

<En>get</En> في الشريحة يشوف الشرائح التانية، لأن الحالة اتلمّت قبل ما الأكشن يتنادى. عشان كده <En>total</En> يقرا <En>items</En>.

الوسيط يلف المتجر المجموع بس. لو حطيته جوه شريحة لوحدها، التخزين أو الأدوات تتطبق نص نص وتتلخبط.

في TypeScript، نوع الشريحة يتكتب كـ <En>StateCreator</En> على الحالة الكاملة. لو في وسيط، حط اسمه في خانة الـ mutators. راجع دليل الأنواع في الدوكس، لأن توقيع الدالة طويل.

## combine

<En>combine</En> ياخد الحالة الأولى، ودالة تضيف الأكشنات. النوع يتستنتج، فمش محتاج واجهة، ومش محتاج نداء <En>create</En> المقسوم لقوسين.

<File name="combine.js">

```jsx
import { create } from "zustand";
import { combine } from "zustand/middleware";

const useShop = create(
  combine({ items: [], rate: 0 }, (set) => ({
    add: (item) => set((state) => ({ items: [...state.items, item] })),
    apply: (rate) => set({ rate }),
  })),
);
```

</File>

<En>redux</En> كمان بيعمل الحالة، فنفس الفكرة: من غير القوسين الزايدين. الوسيط اللي مش بيعمل الحالة، زي <En>devtools</En> و <En>persist</En>، في TypeScript محتاج <En>create()()</En> عشان الاستنتاج يكمّل.
