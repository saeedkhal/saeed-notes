الـ <En>IDOR</En> هو أشهر شكل من <Hl c="o">Broken Access Control</Hl>، وده رقم ١ في قايمة OWASP Top 10. والسبب بسيط: الكود بيسأل "إنت مين؟" وبينسى يسأل "وده بتاعك؟".

<Grid2>
<Card title="🪪 Authentication" c={1}>

**إنت مين؟** login و session و JWT. بيتعمل مرة في الـ middleware.

</Card>
<Card title="🔑 Authorization" c={3}>

**مسموحلك بإيه؟** لازم يتعمل مع **كل record** بتقراه أو بتعدّله.

</Card>
</Grid2>

<Box type="story" icon="🔑" title="مفتاح الشقة">

البوّاب اتأكد إنك ساكن في العمارة (authentication). بس لو اديته رقم شقة ٧ وقلتله "افتحهالي" وفتحها من غير ما يتأكد إنها شقتك، تبقى دي IDOR.

</Box>

## الحل: اربط الـ query بصاحبها

<File name="invoices.ts">

```ts
app.get("/invoices/:id", requireAuth, async (req, res) => {
  // @diff -
  const invoice = await prisma.invoice.findUnique({ where: { id: req.params.id } });
  // @diff +
  const invoice = await prisma.invoice.findFirst({
    // @diff +
    where: { id: req.params.id, ownerId: req.user.id },
  // @diff +
  });
  if (!invoice) return res.sendStatus(404);   // 404 مش 403: متأكدش إن الـ ID موجود
  res.json(invoice);
});
```

</File>

<Hl c="y">الـ query نفسها هي اللي فيها الفلتر</Hl>، مش `if` بعدها ممكن يتنسي. نفس الكلام مع `update` و `delete`: استخدم `updateMany` أو `deleteMany` بنفس شرط الـ `ownerId` واتأكد إن العدد مش صفر.

<Box type="warn" title="الـ UUID مش حماية">

الـ UUID بيصعّب تخمين الـ IDs، وده كويس. بس الـ IDs بتتسرب في اللينكات والـ logs والـ screenshots. **الفحص على السيرفر هو الحماية**، والـ UUID طبقة زيادة بس.

</Box>

## أماكن بتتنسي

- **الـ body مش الـ URL بس**: `PATCH /profile` وفيه `{ "userId": 5, "role": "admin" }`. متاخدش الـ `userId` من الـ body، خده من الجلسة. وحدد الحقول المسموح تتعدل (allow-list) عشان `role` ميعديش. ده اسمه **mass assignment**.
- **الـ nested resources**: `/teams/1/members/99` اتأكد إن العضو 99 تبع team 1، وإن الـ user عضو في team 1.
- **الـ frontend مش حماية**: إخفاء زرار "حذف" في React مش authorization. أي حد يقدر يبعت الـ request من Postman.
- **الـ multi-tenant**: كل query لازم فيها `tenantId`. فكّر في Row-Level Security في Postgres كطبقة أخيرة.

<Box type="tip" title="اكتبله test">

لكل endpoint: اعمل user A وuser B، و A يطلب record بتاع B. المتوقع `404`. التيست ده بيمسك IDOR قبل الـ production.

</Box>
