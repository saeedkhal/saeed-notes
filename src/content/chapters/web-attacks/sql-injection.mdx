## الفكرة في سطر

<Flow items={[{"t": "User Input", "c": 1, "s": "نص من الفورم أو الـ URL"}, "→", {"t": "SQL Query", "c": 3, "s": "اتلزق جوه الـ string"}, "→", {"t": "Database", "c": 2, "s": "بتنفذه كأوامر"}]} />

الـ database مش بتعرف أنهي جزء من الـ query إنت كاتبه وأنهي جزء المستخدم كاتبه. لو لزقت الـ input جوه الـ string، المستخدم يقدر يكتب **SQL** مش اسم.

<Box type="story" icon="📝" title="ورقة الطلب عند الجرسون">

الجرسون بيقرا الورقة بصوت عالي للمطبخ: "طلب ترابيزة رقم ___". زبون كتب في الخانة: **"٥، وكمان هاتوا الخزنة"**. الجرسون مش بيفكّر، بيقرا اللي مكتوب، والمطبخ بينفذ.

</Box>

## الكود اللي فيه الثغرة

<File name="users.js">

```js
// ❌ الـ input اتلزق في الـ query
app.get("/users", async (req, res) => {
  const name = req.query.name;
  const sql = `SELECT * FROM users WHERE name = '${name}'`;
  const { rows } = await pool.query(sql);
  res.json(rows);
});
```

</File>

لو `name` قيمته `' OR '1'='1`، الـ query بتبقى:

```sql
SELECT * FROM users WHERE name = '' OR '1'='1'
```

الشرط بقى صح دايمًا، فرجعت **كل** المستخدمين. ونفس الفكرة ممكن تتمد لقراية جداول تانية أو تعديل داتا، على حسب صلاحيات الـ database user.

## الحل: parameterized queries

<Hl c="y">الـ input داتا، عمره ما يبقى جزء من نص الـ SQL</Hl>. بتبعت الـ query بـ placeholders، والقيم لوحدها، والـ database نفسها هي اللي بتفصل بينهم.

<File name="users.js">

```js
app.get("/users", async (req, res) => {
  // @diff -
  const sql = `SELECT * FROM users WHERE name = '${req.query.name}'`;
  // @diff +
  const sql = "SELECT * FROM users WHERE name = $1";
  // @diff +
  const { rows } = await pool.query(sql, [req.query.name]);
  res.json(rows);
});
```

</File>

دلوقتي لو حد بعت `' OR '1'='1`، الـ database هتدوّر على مستخدم **اسمه حرفيًا** كده، ومش هتلاقي.

## الـ ORM مش بيحميك في كل حتة

Prisma و TypeORM و Sequelize بيعملوا parameters لوحدهم في الـ API العادي. المشكلة في الـ **raw queries**:

<File name="prisma.ts">

```ts
// ✅ tagged template: Prisma بيحوّل ${} لـ parameters
await prisma.$queryRaw`SELECT * FROM "User" WHERE email = ${email}`;

// ❌ Unsafe: إنت اللي بتبني الـ string
await prisma.$queryRawUnsafe(`SELECT * FROM "User" WHERE email = '${email}'`);
```

</File>

<Box type="warn" title="الأماكن اللي الـ parameters متنفعش فيها">

أسماء الأعمدة والجداول و `ORDER BY` و `ASC/DESC` مينفعش يبقوا placeholders. لو المستخدم بيختار الترتيب، اعمل **allow-list**: خريطة من القيم المسموحة للنص الثابت، وأي حاجة بره الخريطة ترفضها.

</Box>

<File name="sort.js">

```js
const SORTS = { newest: "created_at DESC", name: "name ASC" };
const orderBy = SORTS[req.query.sort] ?? SORTS.newest;
const sql = `SELECT * FROM jobs ORDER BY ${orderBy} LIMIT $1`;
```

</File>

</Card>

<Box type="tip" title="نفس العيلة">

نفس الثغرة ليها أشكال تانية: **NoSQL injection** (لما object زي `$ne` يوصل لـ Mongo query)، و **command injection** (لما input يدخل في `exec`). الحل هو هو: متخليش الـ input يتفسر كأوامر. في Node استخدم `execFile` بـ array بدل `exec` بـ string.

</Box>
