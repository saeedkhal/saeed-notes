## الفكرة

الـ `shadcn` CLI مش بس بيجيب components بتاعة shadcn. تقدر تخليه يجيب **كودك إنت** من registry إنت عامله.

- الـ registry ده **نظام لتوزيع الكود**: components وhooks وصفحات وconfig وrules وأي ملفات تانية.
- الكود بيتكتب **جوه مشروع المستخدم** كملفات عادية، مش بيتسطب في `node_modules`.
- المستخدم يقدر يعدّل الملفات بعد كده براحته، لأنها بقت بتاعته.

<Hl c="g">npm بيديك صندوق مقفول، والـ registry بيديك الكود نفسه.</Hl>

## مش لـ React بس

- الـ registry شغال مع **أي نوع مشروع وأي framework**.
- السيرفر بتاع الـ registry نفسه ممكن يبقى Next أو Vite أو Vue أو Svelte أو PHP أو أي حاجة، المهم إنه يقدّم JSON على HTTP.
- أو ممكن ميبقاش فيه سيرفر خالص: **GitHub repo** فيه `registry.json` في الـ root.

## تقدر توزّع إيه؟

| النوع | أمثلة ملفات |
|---|---|
| UI | `components/ui/date-picker.tsx` |
| Helpers | `lib/format-money.ts`، `hooks/use-copy.ts` |
| Design system | `styles/theme.css`، tokens، components كاملة |
| Feature كاملة | صفحات auth + `lib/auth.ts` + الفورم |
| Rules للـ AI agents | `AGENTS.md`، `.cursor/rules/*`، `.claude/commands/*` |
| Conventions | `.editorconfig`، `biome.json`، docs |
| Testing | `vitest.config.ts`، `test/setup.ts` |
| CI | `.github/workflows/ci.yml` |
| Templates | issue templates، PR template |
| Codemods | `codemods/*`، `scripts/migrate.ts` |
| MCP config | `.mcp.json`، `.cursor/mcp.json` |

## الـ CLI بيوصل للـ item إزاي؟

في 5 أشكال للعنوان، وهتشوفهم في كل المذكرة:

<File name="terminal">

```bash
npx shadcn@latest add button                            # اسم بس = item من shadcn نفسه
npx shadcn@latest add @nile/money-input                 # namespace متعرّف في components.json
npx shadcn@latest add nile-team/ui/money-input          # GitHub: owner/repo/item
npx shadcn@latest add https://nile.dev/r/money-input.json  # URL مباشر
npx shadcn@latest add ./registry/money-input.json       # ملف local
```

</File>

- **الاسم لوحده** زي `button` معناه دايمًا الـ item الرسمي بتاع shadcn، حتى لو إنت جوه registry تاني.
- **`@nile/...`** محتاج تعريف للـ namespace في `components.json`، أو يكون الـ namespace متسجل في الـ Registry Directory.
- **`owner/repo/item`** بيقرا من GitHub على طول، من غير سيرفر ومن غير config.

## 3 طرق تقدّم بيها الـ registry

1. **ملفات JSON static:** تعمل `shadcn build` وترفع الناتج على أي hosting.
2. **Route handlers:** السيرفر يبني الـ JSON وقت الطلب من `registry.json` الأصلي.
3. **GitHub repo:** تحط `registry.json` في الـ root وخلاص.

وفي البداية خالص، shadcn عامل [registry template](https://github.com/shadcn-ui/registry-template) جاهز تبدأ منه.
