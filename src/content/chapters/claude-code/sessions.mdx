Claude Code موجود في الترمينال، وفي الـ IDE زي <En>VS Code</En> (وبيشتغل في <En>Cursor</En> كمان)، وعلى الديسكتوب، وعلى الويب، وحتى من الموبايل. طريقة الشغل واحدة في كل الأماكن دي، فمش محتاج تتعلمهم كلهم دلوقتي.

<Hl c="g">الترمينال بيوريك بوضوح Claude بيعمل إيه خطوة بخطوة. والـ extension بتاعة VS Code هي نفس الجلسة بس بواجهة أريح</Hl>. أي حاجة تعملها في واحد منهم تقدر تعملها في التاني.

## أول تشغيل

1. سطّبه من موقع Claude Code حسب نظام التشغيل بتاعك، واتأكد إنه اتسطب بـ `claude --version`.
2. اعمل فولدر للمشروع وادخل فيه، وشغّل `claude`.
3. أول مرة هيطلب منك تعمل login، وبعدين يسألك إنت واثق في الفولدر ده ولا لأ.
4. تحت هتلاقي الموديل اللي شغال، ومستوى الـ effort، وقد إيه استهلكت من الـ context، والـ mode اللي إنت فيه. `Shift+Tab` بيلف بين الـ modes.
5. `/help` بيعرضلك كل الأوامر، و `Ctrl+C` مرتين بيقفل الجلسة.

## أول مهمة: حدّد اللي عايزه واللي مش عايزه

أول برومبت في الكورس كان إنه يعمل مشروع <En>Next.js</En> بـ TypeScript و Tailwind و Better Auth و Drizzle و Postgres على Neon. المهم إنه قال بوضوح: عايز هيكل المشروع، والـ dependencies، والإعدادات، وملف `.env.example` بس. من غير أي features، ولا UI، ولا دفع، ولا deploy. الحاجات دي هتيجي بعدين.

زي `claude "اشرح هيكل المشروع"`. نفس الجلسة التفاعلية، بس بتبدأ بالمهمة دي على طول، وبتفضل مفتوحة بعدها تكمّل فيها.

</Card>

الطريقة التالتة هي `claude -p`. بينفذ مهمة واحدة، ويطبع النتيجة، ويقفل. وتقدر تبعتله input بـ pipe:

```bash
tail -n 200 app.log | claude -p "فيه حاجة غريبة في اللوج ده؟"
```

دي مفيدة جدًا في الـ automation والـ CI، لأن مفيش حد قاعد يرد عليه.

<Box type="idea" title="ترجع لشغلك إزاي؟">

`claude -c` بيكمّل آخر جلسة كنت فيها. `claude -r` بيوريك الجلسات القديمة وتختار منها. أما الجلسة الجديدة خالص، فمش بتفتكر أي حاجة من اللي قبلها، إلا اللي متسجل في `CLAUDE.md` والـ memory.

</Box>

## تدفع إزاي: اشتراك ولا API؟

الخطط والحدود بتتغير، فراجع صفحة الأسعار عند Anthropic قبل ما تختار. بس القاعدة العامة كده:

- **الاشتراك**: استهلاكه متوقع، وده الأنسب وإنت بتتعلم وبتبني مشاريع عادية. لو بتستخدمه كتير كل يوم في مشاريع كبيرة، هتحتاج خطة أعلى.
- **الـ API من الـ console**: بتدفع على كل token. ده مناسب للـ automation والـ CI، بس مش مناسب للجلسات التفاعلية الطويلة زي إنك تتابع كورس، لأن الفلوس بتتراكم بسرعة.
