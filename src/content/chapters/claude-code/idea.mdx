إنت أصلًا تقدر تفتح Claude العادي وتسأله في البرمجة وتبعتله ملفات. طب ليه محتاج Claude Code؟

<Hl c="y">لأن Claude Code بيشتغل جوه مشروعك نفسه، مش على كود إنت ناسخه ولازقه في الشات</Hl>. بيقرا الملفات، ويدوّر في الكود، ويعدّل، ويشغّل أوامر في الترمينال، ويستخدم <En>Git</En>، ويشغّل التستات، ويتأكد إن التعديل اشتغل فعلًا.

اللي بيفكر لسه هو موديل Claude نفسه. Claude Code بيدّي الموديل ده الأدوات، وسياق المشروع، والبيئة اللي يشتغل فيها. عشان كده بيسموه <En>agentic coding tool</En>، يعني أداة بتاخد خطوات بنفسها، مش بس بترد عليك.

## مثال من المتجر

<Box type="story" icon="🛒" title="السلة والمخزن">

العميل بيقدر يحط في السلة عدد أكبر من اللي موجود في المخزن. الطريقة القديمة إنك تدوّر إنت على كود السلة، وتنسخه، وتشرح للشات كل الكود اللي حواليه.

مع Claude Code تقوله جملة واحدة: "العميل بيقدر يضيف أكتر من المخزون، شوف السبب وصلّحه". هو يدوّر على كود السلة، ويبص على كود المنتجات والمخزون، ويمشي ورا الـ flow، ويعدّل، وبعدين يشغّل التستات.

</Box>

## بيعرف يعمل إيه من غير أي إضافات؟

قبل ما تضيف skills أو MCP servers أو subagents، Claude Code بيعرف لوحده:

- يقرا الملفات ويعمل ملفات جديدة ويعدّل فيها.
- يدوّر في الكود كله.
- يشغّل أوامر في الترمينال، ويفتح السيرفر، ويشغّل التستات.
- يشتغل بـ <En>Git</En>.
- يدوّر على الويب ويجيب docs.
- يستخدم أدوات فهم الكود المتاحة، زي الإيرورات والـ definitions والـ references.

ده لوحده يكفي تبني جزء كبير من التطبيق.

## هو بيشوف الكود بتاعي؟

أيوه. بيقرا الملفات اللي جوه المشروع اللي إنت فتحته عليه. البحث نفسه بيحصل على جهازك، يعني مش بيرفع المشروع كله في حتة تانية ويعمله index الأول. لكن لما يحتاج يقرا ملف عشان يفكر في المهمة، محتوى الملف ده ممكن يتبعت للموديل.

<Box type="warn" title='"شغال local" مش معناها إن كل حاجة فاضلة على جهازك'>

لو شغال على كود شركة، اعرف سياسة الداتا بتاعة الحساب اللي داخل بيه، والتزم بقواعد الشركة في استخدام أدوات الـ AI.

</Box>

## طب وملف الـ `.env`؟

بعدين في الكورس، المتجر هيبقى فيه ملف `.env` فيه رابط الداتابيز، وسر Better Auth، ومفتاح Stripe. متفترضش إن Claude فاهم لوحده إن دي حاجات حساسة وممنوع يلمسها.

Claude Code فيه نظام permissions بتحدد بيه هو يقدر يقرا إيه، ويعدّل إيه، ويشغّل إيه. الملفات الحساسة لازم إنت اللي تقفلها بنفسك وبشكل صريح. وفي فصل الصلاحيات هنقفل ملف `.env` فعلًا، ونطلب من Claude يقراه، ونتأكد إنه اترفض.
