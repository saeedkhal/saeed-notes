<Box type="story" icon="🚪" title="البواب">

`CLAUDE.md` زي إنك تقول للسكان "اقفلوا باب العمارة ورا كل واحد". ساعات حد بينسى. الـ hook زي باب بيقفل لوحده بـ spring. مش محتاج حد يفتكر.

## أهم الـ events

- **PreToolUse**: قبل ما Claude يستخدم أداة. تقدر هنا تمنع الأداة.
- **PostToolUse**: بعد ما الأداة تخلص. مناسب للـ format أو الـ lint بعد كل تعديل.
- **UserPromptSubmit**: لما تبعت رسالة، قبل ما Claude يشتغل عليها.
- **Stop**: لما Claude يخلص رده.
- **SessionStart**: أول ما الجلسة تبدأ.
- **Notification**: لما Claude يكون مستني موافقتك.

فيه events تانية، والقايمة بتزيد. راجع الـ docs.

## مثال ١: format بعد كل تعديل

الـ hooks بتتكتب في `.claude/settings.json`، جنب الـ permissions:

<File name=".claude/settings.json">

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          { "type": "command", "command": "\"$CLAUDE_PROJECT_DIR\"/.claude/hooks/format.sh" }
        ]
      }
    ]
  }
}
```

</File>

الـ `matcher` بيقول الـ hook ده لأنهي أدوات. هنا: بعد أي `Edit` أو `Write`. و Claude Code بيبعت للـ script تفاصيل اللي حصل كـ JSON على الـ stdin، ومنها مسار الملف:

<File name=".claude/hooks/format.sh">

```bash
#!/usr/bin/env bash
# بنقرا مسار الملف اللي اتعدّل من الـ JSON
file=$(jq -r '.tool_input.file_path // empty')
[ -z "$file" ] && exit 0

pnpm exec prettier --write "$file" >/dev/null 2>&1
exit 0
```

</File>

متنساش `chmod +x .claude/hooks/format.sh`.

## مثال ٢: امنع تعديل ملفات الـ migration

هنا بنستخدم `PreToolUse`، عشان نوقف التعديل قبل ما يحصل:

<File name=".claude/hooks/protect-migrations.sh">

```bash
#!/usr/bin/env bash
file=$(jq -r '.tool_input.file_path // empty')

if [[ "$file" == *"/drizzle/"* ]]; then
  # الكلام اللي على stderr بيرجع لـ Claude فيفهم ليه اتمنع
  echo "ممنوع تعدّل ملفات الـ migration بإيدك. عدّل الـ schema وشغّل pnpm db:generate" >&2
  exit 2
fi
exit 0
```

</File>

وتسجّله في نفس الملف تحت `"PreToolUse"` بـ `"matcher": "Edit|Write"`.

<Box type="idea" title="الـ exit code هو اللي بيقرر">

`exit 0` معناها كمّل عادي. `exit 2` معناها امنع، والكلام اللي على الـ stderr بيرجع لـ Claude عشان يفهم ويصلّح طريقته. أي exit code تاني بيتعرض كإيرور بس الشغل بيكمّل. وفيه كمان طريقة إن الـ hook يرجّع JSON فيه قرار أدق، راجع الـ docs.

</Box>

لاحظ الفرق: الـ deny rule بتمنع أداة على مسار. الـ hook يقدر يعمل منطق أعقد، ويقول لـ Claude يعمل إيه بدل كده.

## أفكار تانية للمتجر

- **Stop**: شغّل `pnpm typecheck` لما Claude يخلص، ولو فيه أخطاء خلّيه يكمّل يصلّحها.
- **Notification**: إشعار على الديسكتوب لما Claude يستناك، عشان متقعدش تبص على الشاشة.
- **SessionStart**: اطبع `git status` وآخر commits عشان Claude يبدأ عارف الوضع.
- **PreToolUse على Bash**: امنع أوامر خطيرة زي `rm -rf` أو `git push --force`.

`/hooks` جوه Claude بيوريك الـ hooks المتسجلة.

## خلّي بالك

<Box type="warn" title="الـ hook بيشتغل بصلاحياتك إنت">

الـ hook بيتنفذ على جهازك أوتوماتيك، من غير ما يسألك، وبنفس صلاحيات اليوزر بتاعك. فـ:

- اقرا أي hook قبل ما تشغّله، خصوصًا لو جاي في repo أو plugin من حد تاني.
- خلّيه سريع. hook بياخد 10 ثواني بعد كل تعديل هيبطّأ كل حاجة.
- جرّبه لوحده الأول: ابعتله JSON بإيدك وشوف بيعمل إيه.

</Box>
